# 공개 라이브 화면 디자인 결정 — 2026-10-26 (시안 단계)

상태: **시안 확정, 코드 미반영.** WS 운영(10/23~31) 뒤 경기 사이 배포 원칙에 따라 넣는다.
시안 원본은 Claude 프로젝트 캔버스 "Pitcheezy 라이브 화면 시안" 공개 화면 페이지(주소는 레포에 적지 않음).
작업 방식: 요소마다 시안 여러 개 → Song 선택 → 확정 시안 → 코드(`cloud/<요소>`) 순서.

## 확정

1. 머리(상단) 세 줄, 진한 바탕
   - 1줄: 왼쪽 뒤로 · 가운데 점수(CHC 0 : 2 SD) · 오른쪽 상태 표시
   - 2줄: 왼쪽 회차(누르면 타석 선택) · 오른쪽 이닝별 점수표(1~9 + R, 지금 회 강조)
   - 3줄(흰 줄): 타자 | 카운트·주자·아웃 | 투수 (B1). 360px 미만은 성만 표시
   - PC·태블릿: 점수 가운데
   - 타석 없을 때: 공수 교대는 흰 줄이 한 줄 안내, 경기 전·종료는 흰 줄 없음
   - 이전 확정(이닝별 점수표는 시트로)을 뒤집음 → 반영 시 decisions.md 한 줄 필요
2. 존
   - 회색 상자 없이 선만, 많이 빠진 공은 가장자리 화살표(지금 방식)
   - 추천: 청록 네모 1=채움 / 2=연한 채움 / 3=흰 바탕 **실선**(점선 폐기)
   - 투구 기록 무채색(G1): 볼=빈 원, 스트라이크·파울=회색 채움, 타격=진한 채움. 방금 던진 공은 진한 테두리
   - 같은 칸 추천은 네모 하나로 합침("1·2")
   - 여백 정리안(존 약 19% 확대)은 보류, 지금 크기 유지
3. 추천 후보: 구분선 한 줄 세 칸(순위 표시 + 구종). 위치·수치는 '자세히'
4. 이번 타석: 메인에서는 "이번 타석 · N구 던짐 · 펼치기" 한 줄, 펼치면 세로 목록(최근 공 위, 다음 공 줄, 끝나면 결과 줄)
5. 상태: 오른쪽 위 표시 하나가 전부 맡음(라이브 / 자료 늦음 / 연결 끊김 / 확인 중 / 추천 없음 / 추천 바뀜). 누르면 풍선 설명
   - 화면 안 안내 문장·스포일러 상자 제거. 위험 안내 줄(TV 지연)도 넣지 않음
   - 10/19·10/21 결정(스포일러 안내를 1차전 뒤 추가)을 뒤집음 → 반영 시 decisions.md 한 줄 필요
   - 연결 끊김: 존·추천 흐리게 + "마지막으로 받은 추천". 확인 중·추천 없음: 추천 칸 "—"
6. 메인에서 뺌: "직전 타석 · 분석과 기록" 카드, "경기 흐름" 칸(승리확률·점수표·최근 타석 링크)
7. 하단 메뉴: 바닥 꽉 찬 바, 아이콘+글자 4개(추천·선수·구종·기록), 상단과 같은 진한 색
8. 상세 시트 틀: 반만 열림 → 끌어올리면 전체(C). 손잡이·제목·닫기, 표는 선만
   - 추천 자세히: 표 정리(R1)
   - 투구 상세: 결과 먼저(P2) — 실제 공·작은 존(넓은 창) → 판정·좌표 → 없는 측정값 한 줄 → 던지기 전 추천 표. 제목 옆 ‹ › 로 앞뒤 공
   - 선수: 타자·투수 탭(L1). 투수 탭에 오늘 구종표(투구 수·비율·평균 구속) 추가

## 남은 순서

⑧ 나머지 시트(구종 · 경기 기록 · 이닝별 점수 · 타석 선택 · 승리확률) → ⑨ 경기 목록 → 확정 시안 → 코드.
구종 시트는 선수 시트 투수 탭과 겹치므로 메뉴 "구종"의 역할을 같이 정한다.

없는 정보 목록은 `UI-data-gaps.md`.
