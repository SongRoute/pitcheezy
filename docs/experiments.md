## 판정 규칙
- 채택: 5시드 평균 OPE가 베이스라인보다 높고 CI가 겹치지 않음
- (D22, D23 확정) 같은 평가 타석에 두 정책을 대입하므로 **짝지은 차이** Δ 의 경기 클러스터 부트스트랩 95% CI 가 0 을 제외하면 판정 (`scripts/ope_compare.py`). 따로 잰 CI 겹침보다 검정력이 훨씬 높다
- (D29) 학습에 난수가 있는 모델(arch=neural)은 학습 시드마다 짝지은 비교를 한다 (`ope_compare.py --model-seed`). 시드 3개 모두에서 CI 가 0 을 제외해야 판정. 시드 하나의 차이는 시드 운일 수 있다 (EXP-P1-003 시드 0)
- (D30·D31, 2026-09-20) 저울 해상도: 짝지은 Δ 의 95% CI 반폭은 타석 68k 에서 약 0.001~0.0025/결정. 고감도 τ·DR 로도 좁혀지지 않았다. 따라서 "구분 안 됨" 은 "효과 없음" 이 아니라 "0.002 아래" 라는 뜻. `onestep_dr`·`traj_dr` 열은 보조 기록 (궤적 DR 은 모델 내 가치에 끌려 채택 근거로 쓰지 않음)
- 기각: 그 외. 기각도 행을 남긴다
