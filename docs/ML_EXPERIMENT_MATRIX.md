# ML·확률 정책 실험 매트릭스

작성: 2026-09-24. 사전 설계 작성 당시 상태: **전 행 계획 / 미실행**. 현재 실행·판정은 [실행 보고서](reports/ML-matrix-execution-2026-09-24.md)를 우선한다. 대상은 MLB 정규시즌 선발·불펜 전체다. [전체 설계](ML_EXPERIMENT_DESIGN.md)를 실행 가능한 비교 묶음으로 나눴다. 각 `MX-*`는 계획 행 ID이며 실행 ID가 아니다. 실행 전 `docs/experiments.md`의 기존 ID와 충돌하지 않는 `EXP-P{phase}-{seq}`를 발급하고, 여러 후보가 있는 행은 후보별 config와 부모 비교군을 기록한다.

**읽는 순서:** §1 공통 비교 조건 → §2 판정 기준 → §3~§9 개별 비교 → §10 첫 실행 19회 학습안. 모든 행을 한꺼번에 실행하지 않는다. `필수`는 해당 단계에서 수행할 비교, `후속`은 앞 단계 근거가 있을 때 등록할 후보, `자료 필요`는 의도 등 외부 자료를 받은 뒤 가능한 비교다. 세부 방법을 실행·채택했다는 뜻이 아니다.

## 1. 모든 행에 적용할 공통 조건

### 1.1 고정할 것과 비교용 이름

| 이름 | 정의 |
|---|---|
| `LEGACY` | 기존 sampling·코드·features·seeds 그대로인 빈도/MLP/Transformer. 정확 재현 전용 |
| `D100` | 승인된 고정 TRAIN 기간의 전체 eligible 경기·투구 모집단. 기존 NN 표본의 100%와 다름 |
| `D25`, `D50` | D100 경기의 중첩 25%, 50%. 월·역할 구성이 유사하도록 결과를 보지 않고 선정. 경기 비율과 투구 비율을 함께 기록 |
| `C6` | 기존 TRAIN 선정 6명 DEV 코호트. ML0/ML1 연결용이며 전체 MLB의 대표 표본으로 간주하지 않음 |
| `Cpanel` | TRAIN 이력으로 선정한 선발/불펜·좌우·표본량별 개발 패널. 군집·강건 학습 비교 전에 명단/선정 규칙 동결 |
| `Cmlb` | 동결된 모델을 평가할 전체 MLB 개발 모집단. Cpanel 포함 여부와 중복 노출 기록 |
| `Fref` | ML0에서 확정한 기존 강한 MLP의 입력 명세·as-of 처리. ‘기본 피처’라는 이름으로 실행마다 변경하지 않음 |
| `H5` | 같은 타석의 직전 최대 5구, 순서·결과·관측 물리·mask. 현재 공의 실제 결과/물리는 제외 |
| `Bdata` | MX-D1 후 동결한 공통 학습 모집단. 데이터량 이외 실험에서는 같은 투구 키 목록 사용 |
| `Barch` | Bdata+공통 입력으로 다시 학습한 MLP. 모델 구조 비교의 고정 대조군 |
| `Bshare` | Bdata+연속 선수 성향, 동일 MLP의 전체 공유 모형. 군집/개인화 비교의 대조군 |
| `Bstage` | 해당 묶음 시작 전에 동결한 현 단계 기준선. 모든 행에 구체 config/hash로 치환; 결과마다 이동하지 않음 |

기존 2025 runner의 기간은 TRAIN `2023-05-15~2025-04-30`, early-stop `2025-05-01~05-15`, temperature `05-16~05-31`, blend `06-01~06-30`, DEV `07-01~09-30`이다. 이는 [코드](../experiments/pitchmdp/scripts/run_temporal_blend.py)의 재현 기준이다. ML0에서 경기 경계·manifest와 대조한다. 새 비교에 이 기간을 재사용하면 이미 노출된 DEV에서의 개발 비교다. 2024도 노출된 DEV이며 독립 최종셋으로 이름을 바꾸지 않는다.

- 공통 출력: 기존 10-class 결과 분포. 같은 평가 투구에서 같은 정답 정의로 비교한다. 원문 4/9-class·이진 점수는 별도 표다.
- 현재 공의 실제 구속·회전·도달 위치는 pre-pitch 입력 금지. 물리 조건부 모형은 동일한 TRAIN joint delivery draw 400개로 적분한다. 정확한 conditioning·draw key·난수·보정 순서를 manifest에 고정한다.
- 데이터/라벨/정보/행동 공간/학습 loss/모델 중 **그 행이 명시한 축만 바꾼다**. 효과가 있는지 볼 때 조기 종료·보정은 각 후보에 동일한 절차를 적용하며 선택된 값도 기록한다.
- hyperparameter는 TRAIN 내부 시간 분할에서 선택한다. CAL은 temperature와 blend를 나누고, DEV는 사전 등록 후보의 비교에 쓴다. 후보별 DEV 재튜닝 금지.
- 새로운 확률 예측 screen의 주 결과는 동일한 **3-seed 앙상블의 보정 후 NLL**이다. 보정 전·seed별·앙상블 전 결과도 보고한다. 최종은 5-seed 앙상블끼리 비교한다. 단일 모형 대 앙상블 효과는 MX-L6에서 분리한다.
- 학습 seeds: 재현 `{42,43,44,45,46}`, 새 screen `{0,1,2}`, 최종 `{0,1,2,3,4}`. 표본 선택 seed와 bootstrap seed는 별도로 고정한다. 첫 데이터량 실험은 한 nested manifest를 모든 학습 seed에 공유하므로 표본 선택의 전체 불확실성까지 반영하지 않는다.
- 모든 score는 공통 평가 집합으로 계산한다. 모델별 결측/지원 때문에 일부 행을 빼면 공통 집합 점수와 **전체 요청 분모의 fallback·기권률**을 모두 보고한다.
- 2026 경기 및 기존 최종셋은 개발·튜닝에 사용하지 않는다. 미개봉 확인 자료의 존재·사용 가능 여부는 MX-R0에서 확인한다. 없으면 최종 우위는 미확인으로 남긴다.

### 1.2 ‘어떤 표’를 만들 것인가

각 행의 결과표 열은 아래와 같다. 적중률 한 개로 모델을 고르지 않는다.

`후보 / 대조군 / 변경 축 / TRAIN 경기·투구·선수 수 / 평가 경기·투구 수 / NLL / ΔNLL와 CI / Brier / ΔBrier와 CI / seed별 차이 / 주요 그룹 / 지원·fallback / 시간·메모리·추론 지연 / 판정 / 근거`

정책 행은 `PA 시작 수 / 평균 ΔWE(%p/PA)와 CI / OPE 가정·ESS·가중치 / 그룹별 손실 / 행동 지원 / 시뮬레이션·관측 평가 구분`을 추가한다. **실제 구종 일치율은 정책 우위 판정에 사용하지 않는다.** 정책 확률과 결과가 발생할 확률도 다른 열이다.

## 2. 공통 판정 기준 — 수치 제안 v0

아래 숫자는 기존 논문이나 실험에서 검증된 제품 기준이 아니라 **이번 실험을 위한 출발 제안**이다. ML0에서 표본·기준선 변동·비용을 감사한 뒤, 새 후보 결과를 보기 전에 확정하거나 이유를 적고 수정한다. 후보 결과를 본 뒤 문턱을 낮추지 않는다.

| 코드 | 무엇을 통과해야 하는가 | 통과 시 할 수 있는 주장 |
|---|---|---|
| `V` 재현·유효성 | 키/라벨/분할 일치, 미래 입력 없음, 유한 확률 [0,1]·확률 합 오차 ≤1e-6, 저장 예측에서 float64 지표 재계산 오차 ≤1e-8. 재학습 오차는 별도 측정·원인 확인 | 비교 경로가 유효함. 새 모델 우위는 아님 |
| `N` 전체 예측 개선 | 후보−대조군 ΔNLL ≤−0.003 nats/구, 짝지은 95% CI 상한 <0, 같은 묶음 다중 비교 검정 통과. ΔBrier 95% 상한 ≤+0.001 | 해당 평가 모집단에서 실용적 예측 개선 |
| `G` 목표 집단 개선 | 사전 지정 집단에서 N 기준; 전체 ΔNLL 95% 상한 ≤+0.001 및 전체 Brier 기준. 주요 다른 집단의 악화도 보고 | 예: 저표본 투수용 개선. 전체 평균 개선과 구분 |
| `R` 강건성 확인 | 주요 집단 각각 ΔNLL 95% 상한 ≤+0.010, ΔBrier 상한 ≤+0.002를 제안. 대상 모집단/지원 범위를 줄여 얻은 점수는 별도 처리 | 측정 가능한 사전 지정 집단에서 허용 범위 이내. 미측정 집단까지 보장하지 않음 |
| `C` 비용상 이점 | ΔNLL 95% 상한 ≤+0.001, Brier/지원 유지, 같은 장치·배치에서 추론 p95 또는 총 학습비용 ≥20% 감소. 어느 비용을 주로 볼지 사전 지정 | 정확도 우위와 별개의 효율 개선 |
| `P` 정책 가치 | 평균 ΔWE ≥+0.01 %p/PA를 초안으로 제안; 짝지은 CI 하한 >0 및 다중 비교 통과. 공통 지원·보상·시작 상태를 사용하고 관측 OPE 주장에는 식별 조건도 충족 | 통과한 평가 방식/가정 아래 정책 개선. 모델 내부 통과와 관측 근거를 구분 |
| `E` 실행 분포 | 검토된 목표→도달 heldout의 같은 단위 NLL/분포 calibration·좌표 오차로 비교. 실제 측정 오차와 최소 개선폭을 먼저 고정 | 제구 분포의 예측 개선. 이것만으로 정책 인과 효과를 주장하지 않음 |

N/G는 screen에서 적어도 2/3 seed, 최종에서 4/5 seed의 주 지표 차이가 개선 방향인지 함께 확인하는 안이다. **각 seed를 새로운 독립 경기 표본처럼 합치지 않는다.** 판정의 주 대상은 동일 개수의 앙상블이며 seed 조건은 안정성 점검이다.

V의 재학습 재현은 같은 장치·환경·seed에서 seed별 NLL 차이의 절댓값 ≤0.001을 허용폭 초안으로 둔다. 저장 예측 재계산의 수치 오차와 구분한다. 초과하면 데이터/전처리/난수/장치 연산/보정 차이를 조사하며, 원인이 설명되지 않은 상태에서 새 baseline으로 조용히 교체하지 않는다. 정확 재현이 불가능하면 원래 점수와 환경을 바꾼 재구현 결과를 분리하고 이후 공통 대조군을 명시한다.

같은 투구의 paired loss를 경기 단위로 묶어 bootstrap 10,000회를 제안한다. NLL/Brier의 주 평균은 투구별 평균이며, 경기를 재표집할 때 해당 경기의 모든 투구를 포함해 전체 loss 합/전체 투구 수를 다시 계산한다. 경기별 평균의 단순 평균이나 선수 macro 평균과 구분한다. 묶음 내 계획한 주 비교에는 Holm α=0.05를 적용하고 단순 CI 두 개의 겹침으로 비교하지 않는다. 고정 모델 bootstrap CI가 학습/보정/선정 불확실성 전체를 담지 않는다는 한계를 명시하며 시간·seed 민감도를 별도 보고한다.

R의 기본 집단은 선발/불펜, 좌우, TRAIN 표본량 층, 2스트라이크, 주자 유/무다. 저표본은 TRAIN 선수별 투구 수의 하위 25%를 출발 정의로 하고 0건 새 선수는 별도로 둔다. 후보를 보기 전에 경계·역할 기준을 고정한다. 주 판정 집단의 최소 30경기·500구, 희귀 클래스 지표의 사건 30건은 **보고 적격성의 제안**이며 충분한 검정력을 보장하지 않는다. 미달하거나 CI가 넓으면 미확정이고, 0건 클래스를 점수 0으로 채우지 않는다. 주요 집단의 다중 비열등 판정 방법도 사전 고정한다.

| 결과 상태 | 처리 |
|---|---|
| 개선 | N 또는 G 통과 → 후속 후보. 전체 범위 채택에는 R·비용, 정책 채택에는 P가 추가로 필요 |
| 효율 개선 | C 통과 → 단순/빠른 대안 후보; 정확도 우위라고 쓰지 않음 |
| 우열 미확정 | CI가 0을 포함하거나 실용 개선폭 미달, 또는 필요한 집단 표본 부족 → 기록하고 사전 예산 내에서만 후속 |
| 악화/미채택 | 명확한 악화 또는 고정 guardrail 실패 → 다음 결합에서 제외; 모든 학습/실패 기록 보존 |
| 검증 불가 | 의도 라벨·overlap·필수 입력 등 부족 → 효과 null. 시뮬레이션 수치로 빈칸을 대신하지 않음 |

| MX-D3 후속 | 전체 기간 균등 표본 → 최근 365일의 matched 표본 | 자료의 최근성 | MLP·투구 수/경기 수 허용 오차·역할 구성·CAL·DEV | N/C; 같은 N의 비교. 경기 경계 때문에 허용 N 차이를 미리 고정 |
| MX-D4 후속 | 균등 가중 → 최근 가중(half-life 180/365일) | TRAIN loss 가중만 | 동일 투구 목록·모델·평가 분포 | N; half-life는 내부 튜닝에서 선택, 가중 ESS·보정 변화 보고 |
| MX-D5 후속 | 기존 투수 중심 표본 → 다양한 투수/역할 표본 | 학습 선수 다양성 | 같은 기간·matched N·MLP·Cpanel | N 또는 G+R; 선수 수 증가와 투구 수 증가를 구분 |

D1의 ‘고정 auxiliary’는 D100 TRAIN에서 만든 공통 빈도·선수 특징·delivery·전처리 등을 모든 규모에 공유한다는 뜻이다. 따라서 D25도 이 공통 정보를 사용한다. D2에서는 해당 의존성까지 제한하고 누수/보조 자료 사용을 별도로 감사한다. CAL/DEV 크기를 늘리는 효과는 두 행에 섞지 않는다.

Bdata는 원칙적으로 D100을 다음 기준으로 삼는다. 더 작은 자료를 택하려면 C의 비열등·비용 기준을 만족하거나 자원 제한을 명시해야 한다. 이후에는 같은 목록을 고정하며 모델마다 유리한 표본을 고르지 않는다.

## 4. ML2 — 모델 구조

이 블록의 입력은 공통 Fref와 H5다. H5가 Fref에 이미 있으면 중복 추가하지 않는다. MLP/선형/GBDT에도 **순서가 보존된 동일 5구 flatten+mask**를 제공한다. 현재 물리의 적분 여부는 전 모델 동일하다. 빈도 기준선은 더 적은 입력을 쓰는 단순 기준으로 항상 병기하되 ‘같은 정보의 구조 비교’에서 구분한다.

| ID·우선순위 | 대조군 → 후보 | 검증할 가설 | 고정 조건 | 판정·근거 |
|---|---|---|---|---|
| MX-A0 필수 | Bdata+공통 입력으로 MLP 기준선 재설정 | ML1과 ML2의 입력/표본 변경을 연결 | Bdata·H5·분할·draw·보정 | V; 같을 때만 D1 저장 결과 재사용 |
| MX-A1 필수 | Barch → 다항 선형 | 복잡한 구조가 필요한가? | 공통 원시 변수·정답·H5·평가 | N 또는 C; SmartPitch 단순 기준 |
| MX-A2 필수 | Barch → GBDT 1계열 | 표 형태 특성에서 tree가 더 유리한가? | 같은 입력·표본·HPO 한도 | N 또는 C; 계열은 profile/가용성으로 결과 전에 선택 |
| MX-A3 필수 | Barch → LSTM | 순환 상태의 이득 | 동일 H5·현재 상태·전처리·CAL | N 또는 C; H5/0 차이는 별도 F3 |
| MX-A4 필수 | Barch → GRU | 더 간단한 순환 모형의 이득 | A3와 같은 정보/학습 절차 | N 또는 C; LSTM 대비는 사전 지정 보조 비교 |
| MX-A5 필수 | Barch → Melville 자체 recurrent cell | 논문 고유 상태 갱신의 이득 | 현재 결과는 다음 공 갱신부터 사용 | N; LSTM과 별도 구현·적응 차이 기록 |
| MX-A6 필수 | Barch → Transformer | 같은 짧은 이력에서 attention의 이득 | 동일 H5; 더 긴 이력은 아직 추가하지 않음 | N 또는 C; Takamido 원문 과제와 공통 10-class adaptation 구분 |

모델별 대표 설정 1개×3 seeds로 screen한다. A1~A6 대 Barch의 6개 주 비교를 한 family로 등록한다. 개선/효율 근거와 사전 ranking 규칙으로 **최대 2계열**만 후속 HPO(각 최대 8설정)에 진입한다. HPO는 내부 분할에서 수행하고 DEV를 본 뒤 시행했다면 새 탐색 묶음으로 기록한다. 동일 DEV 재평가만으로 독립 확인을 주장하지 않는다.

## 5. ML3-G — 선수 정보 공유

첫 G 블록은 MLP로 구조를 고정하고 Cpanel을 사용한다. Bshare의 선수 연속 특성·개인 ID 사용 여부를 명시하며, 아래 비교에서는 원시 특성의 차이를 만들지 않는다. 집단별 모형은 총 파라미터/fit 수가 달라지므로 이를 비용 열에 기록한다. 좋은 선수만 평가에 남기지 않는다.

| ID·우선순위 | 대조군 → 후보 | 바꾸는 것 | 고정 조건 | 판정·필수 확인 |
|---|---|---|---|---|
| MX-G1 필수 | 전체 공유 Bshare → 개인별 MLP+league fallback | 정보 공유 단위 | 같은 관측 pool·선수 특성·개인 적격성 규칙·Cpanel | G/R; 선수별 이득과 개인 모델 학습 가능 비율. 실제 fit 수는 선수 수×seed |
| MX-G2 필수 | Bshare → 공통 MLP+투수 cluster feature | 유형 정보만 추가 | 원래 연속 특성 유지·K=4부터·동일 모델/자료 | N/G; 이득/표본 근거가 있을 때 K=8 후속 |
| MX-G3 필수 | Bshare → 투수 cluster별 MLP(K=4) | 자료 공유 범위를 군집으로 제한 | G2와 같은 군집·입력·Cpanel | G+R; 전체 공유 대비 음의 전이·희소 군집 fallback |
| MX-G4 필수 | Bshare → league→유형→개인 부분 공유 | shrinkage/개인화 학습 | 같은 원자료·연속 특성·군집 사전·Cpanel | G 우선; 저표본 NLL 개선과 전체 비열등. ID만 추가한 F2와도 대비 |
| MX-G5 후속 | G3 → 크기를 맞춘 무작위 군집의 같은 전문가 | 유형의 의미를 제거하는 위약 | 전문가 수·표본 수 분포·파라미터·예산 | 진짜 군집−무작위 군집 차이/CI. 군집 의미와 단순 용량 증가를 구분 |
| MX-G6 후속 | Bshare → 4개 전문가의 soft mixture | hard 소속을 확률 소속으로 변경 | 비교 가능한 총 용량의 shared/hard 대조를 추가 | N/G+R; G2~G4 결과에 후속 가설이 있을 때 |
| MX-G7 후속 | 연속 타자 성향 → 타자 군집/부분 공유 | 타자 정보 공유 | 투수 표현·구조·자료 고정 | G; 기존 군집 결과 재사용, 새 저표본/새 타자 가설 없이 반복하지 않음 |

G2/G3/G4는 한꺼번에 결합하지 않는다. G 블록은 먼저 전체 공유와 개인별·군집별 차이를 확인하고, 부분 공유를 다음 비교로 등록한다. 군집 적합은 TRAIN만, 신인은 당시 이력 기반 배정 또는 unknown/league fallback이다. 군집은 독립 관측 수를 새로 만드는 데이터 증강으로 세지 않는다.

## 6. ML3-F/L — 입력과 학습 방법

각 행은 묶음 시작 시 동결한 Bstage에 하나를 추가/제거한다. 최초 우선 제안은 **투수 정보 공유(G)와 긴 타자 이력(F4)**의 두 축이며, 나머지는 결과에 근거해 다음 묶음으로 등록한다. 기존에 똑같이 검증한 행은 hash·정보·표본이 같으면 재사용한다.

| ID·우선순위 | 대조군 → 후보 | 바꾸는 것 / 주 고정 조건 | 주 평가·판정 |
|---|---|---|---|
| MX-F1 근거 재사용 | 기본 상황+좌우 → 과거 연속 선수 성향 | 구조·자료·이력 고정; 표본 수/신뢰도도 명시 | N; 기존 유용성 근거 재사용, 모집단 변경 시 bridge |
| MX-F2 후속 | 연속 선수 성향 → 추가 선수 ID embedding | 정보 블록만 추가 | N/G; 새 선수 fallback와 seen/unseen 성능 |
| MX-F3 근거 재사용 | 같은 구조의 H0 → H5 | 타석 내 이력만 변경 | N; 새 backbone에서 필요할 때만. 기존 MLP 0/5 반복 최소화 |
| MX-F4 우선 | 같은 타석 H5만 → 이전 타석의 타자 과거 32/128구 추가 | backbone·H5 유지, 새 stream에서 H5와 중복된 공 제외 | N/G; 2개 후보 사전 비교. 400구는 이득/비용 근거 후 별도 등록 |
| MX-F5 후속 | Bstage → 투수의 이전 타석 과거 32구 추가 | 타자 이력·현재 상태·모델 고정 | N/G; F4와 동시에 추가하지 않음 |
| MX-F6 후속 | Bstage → 투구 수·휴식일·이전 구속 변화·타순 회차 | workload 블록만 추가 | N/R; 불펜/후반·긴 타석. 관측 변수를 실제 피로 측정으로 부르지 않음 |
| MX-F7 후속 | Bstage → 포수/심판/구장/날씨 | 가용성이 확인된 블록별 각각 1행으로 세분화 | N/R; missingness·새 환경 일반화. 현재 공 이후 정보 금지 |
| MX-F8 후속 | 물리 조건부 결과+적분 → 직접 pre-pitch head | 같은 구종 후보·과거 정보·10-class·평가 분모 | N/C; 첫 비교는 목표 라벨 없는 구종-only marginal. 실제 도달을 목표 입력으로 대체 금지 |
| MX-F9 후속 | 순서 있는 과거 stream → 순서 정보 제거 대조 | 같은 과거 공 집합·모델 용량. 순서 제거 규칙을 train/eval에 일관 적용 | 순서의 추가 이득/CI. 물리량–결과 연결은 유지; 단순 test-time 교란과 구분 |
| MX-L1 후속 | 단일 10-class softmax → 계층적 결과 head | 입력·encoder·자료·optimizer 고정 | N/R; 공통 10-class 확률 합/희귀 결과 복원, Douglas/Mott 모듈 적응 |
| MX-L2 후속 | 주 결과 loss만 → 타구 방향/속도 등의 보조 loss | 같은 이력·encoder. 보조 관측이 없는 공도 주 학습에 유지 | N/R; Kneita 아이디어. 보조 타깃별 제거 비교로 효과 확인 |
| MX-L3 후속 | 무작위 초기화 → 과거 이력 표현 사전학습 | 같은 encoder·사용 TRAIN·fine-tune. 추가 자료/계산량 기록 | N/G/C; Heaton/Mitra·선수 표현 가설. 추가 자료 사용 시 별도 대조 |
| MX-L4 후속 | ERM → 그룹 균형 가중 → 정규화된 Group DRO | 같은 사전 그룹·자료·모델; 각 후보를 ERM 및 균형 가중과 비교 | G/R; 전체 NLL 비열등. 일반 경기 원래 분포에서 calibration 평가 |
| MX-L5 공통 진단 | raw → temperature → temperature+빈도 혼합 | 같은 checkpoint·temperature CAL·blend CAL | NLL/Brier 변화. 모든 후보에 같은 절차, 유리한 모델에만 보정 금지 |
| MX-L6 후속 | seed 0 단일 → seeds 0~2 평균 → 0~4 평균 | 고정 seed 집합·같은 학습 config·각각 같은 보정 절차 | N/C; 최고 seed 선택 금지. 모형 수에 따른 품질–비용 차이 |

F/L은 구현 세부·정보 경로까지 바뀌므로 논문의 ‘충실 재현’이라고 자동 표기하지 않는다. 특히 예측 대상, 투구 시점, 현재 물리 가용성, 시간 분할의 차이를 각 결과에 남긴다.

F9에서 순서를 지웠다고 주장하려면 positional encoding과 순서를 복원할 수 있는 timestamp/경과 시간 필드의 처리도 명시한다. 공 하나의 물리량–결과 쌍은 유지하고, 순서가 남아 있는 피처를 그대로 둔 셔플은 별도 제한적 대조로 기록한다.

## 7. ML4 / ML5 — 상호작용·결합·전체 범위 검증

| ID·우선순위 | 비교 | 고정 조건 / 추가 실행 | 평가·판정 |
|---|---|---|---|
| MX-I1 필수 | MLP/Transformer × D25/D100의 2×2 | 동일 정보·보정·평가. 일치하는 이전 cell만 재사용 | 각 주 효과 + `I=(L_T100−L_T25)−(L_M100−L_M25)` CI. I<0은 데이터 증가 이득이 Transformer에서 더 큼을 뜻함 |
| MX-I2 필수 | 전체/계층 공유 × 저표본/고표본 평가 집단 | 같은 동결 모델의 두 집단을 평가; 보통 추가 fit 없음 | 그룹별 효과 차이/CI. 집단 차이는 자료량의 무작위 개입 효과와 구분 |
| MX-C1 필수 | 고정 강한 기준선 → 유망 조합 최대 2개 | Bdata·공통 분할/평가, 모두 5 seeds로 확인 | N+R 및 비용. 기존 비교와 seed 수가 다르면 기준선도 5개로 맞춤 |
| MX-C2 필수 | 조합 → 추가한 구성 하나씩 제거 | 데이터/다른 구성/예산 고정 | full−minus-one 차이/CI. 유효 구성과 중복/상쇄 기여 분리 |
| MX-T1 필수 | 동결 후보/기준선의 시간 구간별 비교 | 동일 checkpoint로 이후 가용 DEV 구간 평가. rolling refit은 별도 행 | N/R; 시간별 방향·보정·지원. 2024/25 노출 및 중복 학습 한계 기록 |
| MX-T2 필수 | 본 선수의 새 대진 / 못 본 투수 / 못 본 타자 | 사전 정의한 제외 fold가 필요하면 동일 config로 양쪽 재학습 | G/R; 학습·튜닝·CAL의 해당 선수 라벨 제외. zero-shot과 과거 관측 허용 적응을 분리 |
| MX-T3 필수 | 정상 입력 → 이력 부족·결측·센서 오차 시나리오 | 가중치 동결·사전 강도/패턴·공통 imputation | R; 성능 저하량·지원·fallback. 실제 현장 분포 검증과 구분 |
| MX-T4 필수 | Cpanel에서 동결한 후보/기준선 → Cmlb 평가 | hyperparameter·보정·지원 규칙 동결, 같은 전체 평가 분모 | N/G+R; 평균·선수 macro·역할·희귀 결과. 자료 범위 변경에 재학습이 필요하면 별도 run/version |
| MX-T5 필수·자료 확인 | 최종 동결 후보/기준선 → 미개봉 확인 자료 | 모든 선택 종료 후 1회. 확인 자료와 사용 가능 범위를 R0에서 확정 | N/R의 독립 확인. 실패 후 수정하면 기존 확인 자료는 DEV로 전환 |

조합 후보 최대 2개와 제거 대조군을 구분해 fit 수를 기록한다. 이미 동일 config/seed/hash인 checkpoint의 재사용은 가능하다. 한 구성의 이득을 다른 데이터·다른 baseline 점수 차이로 계산하지 않는다.

## 8. POL — 정책과 강화학습

예측 모델 선정 후 정책용 튜닝/개발/미개봉 확인 구간을 구분한다. 기존 ML DEV를 정책 설계에도 쓰면 그 노출을 기록한다. 모든 정책 비교는 **같은 행동 해상도, 상태/시작 PA, 보상, support mask, continuation WE**로 맞춘다. P 행의 보상은 수비 ΔWE이고, 기존 RE24 결과표와 합치지 않는다.

| ID·우선순위 | 대조군 → 후보 | 바꾸는 것 / 비교를 맞추는 방법 | 평가·진행 조건 |
|---|---|---|---|
| MX-P0 필수 | 관측 선택 빈도 → 구종 behavior cloning | 현재 시점 상태만 사용, 실제 구종 로그로 학습 | 구종 log-loss·support로 행동 모형 검증. 높은 일치율을 가치 개선으로 판정하지 않음 |
| MX-P1 필수 | 구종 BC → 한 공 가치 greedy | 공통 구종-only 행동; 구종별 위치/실행 혼합 고정 | P; 같은 PA 시작에서 비교. 단일 공 결정·이후 continuation 정책을 명시 |
| MX-P2 필수 | 한 공 greedy → 타석 전체 계획 | 같은 결과/실행/WE 모델, 계획 범위만 변경 | P; branch별 생성 결과로 이력/상태 갱신. rollout truncation/MC 오차 기록 |
| MX-P3 필수 | 결정적 타석 계획 → BC에 대한 KL 제약 확률 계획 | 같은 구종-only 공간·모델·평가기; τ는 정책 튜닝 구간에서 선택 | P; **정규화 보상 외에 동일한 원래 ΔWE**로 비교. 확률 합/unsupported 0 검사 |
| MX-P4 후속 | 동결된 구종-only 계획 기준선 → 이산 IQL | 같은 관측 trajectory·상태·행동·보상; 위치 혼합 고정 | P; learning objective/정책 추출 변경. joint 계획과 구종-only RL을 직접 우열 비교하지 않음 |
| MX-P5 후속 | 동일 기준선 → 이산 CQL | P4와 같은 자료/행동/평가·튜닝 한도 | P; 보수성 계수·support·극단 Q/가중치 감사 |
| MX-P6 자료 필요 | joint BC/계획 → joint KL/IQL/CQL | 목표 라벨 확보 후 같은 구종×목표 grid로 다시 공통 기준선 생성 | P+E; 의도 관측/측정 오차·교란·overlap 조건 충족 필요 |
| MX-P7 후속 | 고정 타자 반응 → 타자 대응을 넣은 혼합 전략 | 같은 joint 공간·WE, 타자 정보/행동 가정 명시 | 상대별 payoff·후회/가치 민감도. 상대 모형 내부 결과와 관측 정책 효과 분리 |
| MX-P8 후속 | 검증된 모델 기반 기준선 → MOPO식 불확실성 패널티 | 같은 합성 trajectory 예산·실제 로그·공통 별도 평가기 | P; 앞선 계획/RL에서 모델 착취 근거가 있을 때만 등록 |

P4/P5의 ‘동일 기준선’은 P2/P3 중 사전 정책 선정 규칙으로 고정한 비교군이며 결과마다 바꾸지 않는다. 두 RL 후보 대 기준선의 비교를 같은 family로 등록한다. 둘 다 최대 3 seeds screen 후 유망 후보만 5 seeds로 확인한다.

P1~P5의 구종-only 정책은 해당 구종 아래 관측 위치 혼합이 유지된다는 축소 가정을 가진다. 숨은 의도나 배터리 판단의 교란은 여전히 남는다. 목표 위치 로그가 없는 상태에서 실제 도달 위치를 행동 z로 간주하지 않는다.

P 판정은 `모델 내부`, `관측 OPE`, `전향적 실제 적용`으로 따로 기입한다. OPE는 행동 관측·overlap·교란 통제 등의 가정을 감사하고, sequential DR·가중치·ESS·clipping 민감도를 기록한다. 평가 정책/평가기/propensity의 학습과 확인 자료를 분리한다. 작은 ESS나 식별 불가 상태에서는 효과를 0 또는 성공으로 채우지 않는다.

## 9. E — 목표 위치·실행 분포

| ID·우선순위 | 비교 | 고정 조건 | 평가·판정 |
|---|---|---|---|
| MX-E0 자료 필요 | CV 의도 proxy → 검토 라벨/좌표 연결 감사 | 기존 IntentEstimate·검토·좌표 계약 | 실제 목표 라벨 수·범위·검토 일치/오차·구종별 분포. 개발 가상 라벨 제외 |
| MX-E1 자료 필요 | 관측 재가중 kernel → 학습한 목표→도달 분포 | 같은 목표·실제 도달 표본과 단위·선수/시점 split·결과 모델 | E; 선수별 수축·분포 보정·결측/좌표 오차. 정책 효과는 별도 P6 |
| MX-E2 후속 | 내부 3×3 → 내부+바깥 5×5 | 같은 모델·정책 알고리즘·물리 단위, 별도 grid 버전 | 공통 내부 행동 성능 + 확장 행동의 support/가치. 가정 기반 값과 실제 목표 효과 구분 |
| MX-E3 후속 | 이산 목표 grid → 연속 위치 분포 | 같은 학습/평가·지원 범위, 셀 적분으로 공통 비교 | E/P; 단위 다른 density NLL 직접 비교 금지 |
| MX-E4 후속 | 점 목표 입력 → 의도 측정 불확실성 반영 | 같은 실제 자료·평가기·정책; 오차 모형만 변경 | E/R/P; 경계 부근 정책 안정성·미검토 입력 기권 |

E0/E1 미완료여도 ML0~ML5와 구종-only 정책 개발은 진행할 수 있다. E2의 모델 내부 민감도 실험도 가능하지만 목표 위치에 대한 현실의 우위 확인과 구분한다.

## 10. 가장 먼저 실행할 작은 매트릭스

첫 묶음은 이미 노출된 **2025 C6 DEV**에 대해 아래만 실행한다. 2024는 기존 산출물 재계산으로 먼저 확인하고, 추가 재학습 필요가 드러나면 별도 예산으로 등록한다.

| 실행 셀 | 모형 | 결과 모델 TRAIN | 보조 모듈 | 학습 seed | 새 full fit 상한 |
|---|---|---|---|---|---|
| R2-MLP | 기존 MLP | LEGACY 원래 표본 | LEGACY 그대로 | 42~46 | 5 |
| R2-TF | 기존 Transformer | LEGACY 원래 표본 | LEGACY 그대로 | 42~46 | 5 |
| D1-25 | 기존 MLP 구조 | D25 | D100 공통 auxiliary | 0~2 | 3 |
| D1-50 | 같은 MLP | D50 | 같은 auxiliary | 0~2 | 3 |
| D1-100 | 같은 MLP | D100 | 같은 auxiliary | 0~2 | 3 |
| 합계 |  |  |  |  | **19** |

19는 **신경망 전체 학습 횟수**다. 빈도 모형 적합, 지표 재계산, 작은 CPU/MPS profile, 보정, 400-draw 적분 추론, 실패 재실행 시간은 별도 기록한다. 이 숫자로 전체 실행 시간을 약속하지 않는다. 먼저 R0/R1을 완료하고 profile 후 예산을 고정한다. 재현 산출물이 완전해 일부 경로를 재사용하면 실제 재학습 수와 근거를 기록한다.

D1의 공정한 비교에서는 구조/학습률/early-stop 절차·최대 epoch를 고정하고 자료량에 따른 실제 optimizer update/시간을 보고한다. 동일 학습시간 비교를 하려면 별도 compute-matched 행을 등록한다. 저장된 LEGACY MLP 점수를 D1-25/50/100의 직접 대조군으로 재사용하지 않는다.

첫 결과표에는 `D25 vs D50`, `D25 vs D100`의 점수 차이/CI, 25→50→100 학습 곡선, 선수·클래스별 변화와 비용을 넣는다. 개선이 없더라도 정해진 비교를 끝내고 이유/불확실성을 기록하면 이 묶음은 완료다. 곧바로 다른 피처·군집·RL을 섞어 성공할 때까지 반복하지 않는다.

## 11. 등록·실행 전 체크와 논문 연결

각 실행 config의 필수 값: `matrix_id`, `experiment_id`, `parent/control_id`, hypothesis, 주 비교 family, 변하는 필드, dataset/feature/label/split hash, seeds, auxiliary 출처, 모델/학습/보정 설정, 판정 문턱, 예산·중단 규칙, 결과/실패 경로. 비교쌍에서 허용한 필드 외 차이가 있으면 이유를 기록하거나 새 비교로 분리한다. 각 후보의 예측 키·확률·그룹·지원 정보를 저장해 paired 비교를 재계산할 수 있게 한다.

사양·config를 새 후보 결과 전에 커밋한다. 실제 실행은 M4 24 GiB에서 작은 profile로 시작하고 무거운 실행은 한 번에 하나다. 새 실행 공간을 사용하고 원자료·동결 모델·runtime_src·사용자 서버/DB를 보존한다. 이번 작업에서는 학습·profile·데이터 열람·실험 등록 커밋을 수행하지 않았다.

| 문헌 아이디어 | 매트릭스 대응 |
|---|---|
| SmartPitch / tabular benchmark 연구 | A1/A2/A0, P1/P2 |
| Melville / Takamido | A5/A6, F3, P7; 원문 과제/입력과 적응 차이 별도 |
| Kneita | F4/F5와 L2를 각각 비교 |
| Mott / Douglas | D3/D4, G4, L1, E1, P7의 모듈별 비교 |
| Alcorn / Heaton·Mitra | F2/G4, L3, T2 |
| Nakahara | E0/E1/P6의 의도 자료·교란/overlap 설계 |
| Park / Ahn | F9 및 긴 이력 가설 참고; 대형 LLM 직접 재현은 이번 실행 목록에서 제외 |
| Guo / deep ensembles / distribution shift / Group DRO | L5/L6, T1~T4, L4 |
| IQL / CQL / MOPO / sequential DR | P4/P5/P8 및 정책 평가 절차 |

논문 원문 링크·핵심·과제 차이는 [전체 설계 §9](ML_EXPERIMENT_DESIGN.md#9-논문별로-어떤-비교를-하는가)와 [문헌 검토](reports/ML-literature-review-2026-09-24.md)에 있다. 원문 수치와 우리 공통 과제 점수는 같은 순위표에 섞지 않는다.
