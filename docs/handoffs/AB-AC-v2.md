루트는 Astra 역할로 계약·시간 경계·분할·해석·핵심 diff를 결정/검토했다. 루트의 정확한 실행 모델 ID는 도구에서 노출되지 않았다. 명시적 모델 지정 가능한 collaboration 도구로 Sol 세 작업을 독립 worktree에서 관리했다: `b_diagnosis_v2`는 `gpt-6-sol/medium`(진단 후 공통 비교), `c_roster_v2`는 `gpt-6-sol/medium`(명단·휴식·타순), `c_inning_v2`는 `gpt-6-sol/high`(복잡한 이닝 확률 전파). 필요한 목표/파일/제약만 전달했으며 재귀 위임은 없었다. 큰 학습 없이 기존 적합 모형과 작은 빈도 표를 재사용했다. 토큰·비용 수치는 노출되지 않아 null이다. 확인 가능한 실행 시간/RSS/호출 수만 위에 기록했다.

종료 시 세 작업 모두 완료, 작업용 학습·평가·서버 프로세스 없음. 이번 작업에서 웹 서버는 시작하지 않았다. worktree와 새 결과는 감사/재현을 위해 보존했다.
