VERDICT: FAIL

## Findings

1. **blocker — Public paired-shift intervals violate the blinding contract.**  
   The design seals centers and CI endpoints and permits only widths, SEs and diagnostics publicly; the JSON explicitly exposes signed paired-shift CIs. With the baseline exception, those intervals disclose new-arm effect location and direction before the decision. This does not require assuming that a percentile-CI midpoint exactly equals the point estimate. Evidence: [design:183](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:183), [design:252](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:252), [JSON:406–409](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:406).  
   **Required fix:** Compute signed shifts, S-5 and λ/M selection inside the sealed evaluator. Publish S-5 pass/fail and permitted precision diagnostics only. Describe selection as outcome-dependent but operator-blinded, rather than literally computed without centers.

2. **major — Registration has a circular pin requirement and blocks the intended R3 fallback.**  
   Every identity null must be filled at registration, including `r1_table_sha256`, although A2-S0 creates that table only after registration. The unconditional requirement also covers the A3 hash when R3 is legitimately `NOT_RUN`. Evidence: [JSON:14–22](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:14), [JSON:420](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:420), [JSON:497–504](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:497), versus [design:161](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:161) and [design:326](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:326).  
   **Required fix:** Separate registration-time input/source pins from stage-generated output hashes. Seal the R1 table after registered S0 and before downstream use. Represent absent R3 explicitly as not applicable, with no later addition after results.

3. **major — The executable B differs from D186’s fixed threshold.**  
   D186 and the design fix **B = 1.26e-5 WE/PA**; JSON stores **1.2612e-5**. The numerical difference is small, but acceptance near the boundary differs. Evidence: [decisions.md:325](/Users/song/Projects/pitcheezy/docs/decisions.md:325), [design:353](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:353), [JSON:356](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:356).  
   **Required fix:** Use exactly `1.26e-5` for acceptance. Retain the more precise arithmetic only as explanatory derivation.

4. **major — The synthetic acceptance matrix does not completely define what is certified.**  
   Optional R3 adds another 12 pairs, but S5-X measures and S-1 still specify 12. X1/X2 omit their logging law. TAB computes both realized-reward and surrogate-reward truths, while S-3 does not identify which truth defines `bias`; separately bounding surrogate and estimator bias does not bound their sum by B. The R1 TAB clause also omits an explicit absolute value. Evidence: [design:187](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:187), [design:215–219](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:215), [design:250](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:250), [JSON:317–321](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:317), [JSON:335–344](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:335), [JSON:364–366](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:364).  
   **Required fix:** Freeze a complete setting × enabled-pair matrix, including laws, η/κ/ζ combinations, repetitions and truth definition. Test combined-arm total bias against realized-WE truth under the stated acceptance/sensitivity rules. Cover enabled R3 pairs or make them explicitly diagnostic-only.

5. **major — S-2’s first-order approximation cannot establish the claimed bias bound.**  
   The R1 bias calculation uses a first-order reference-trajectory approximation. Neither its remainder nor agreement with the CRN check has an acceptance tolerance. Requiring `|estimated bias| ≤ B` and `MC SE ≤ B/2` controls neither approximation error nor an upper confidence bound on bias. Evidence: [design:220](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:220), [design:249](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-design.md:249), [JSON:321](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:321), [JSON:365](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:365).  
   **Required fix:** Base certification on the exact policy-specific quantity or a CRN estimate with a registered uncertainty bound; alternatively include a justified approximation-remainder bound. Preserve `INCONCLUSIVE` when certification precision is insufficient.

Baseline bias can therefore be a scientific result; a 95% CI check can also fail without a programming defect. Nevertheless, the stop rule calls any baseline X0 failure a harness defect to fix, alongside a bug-fix retry allowance. Evidence: [JSON:316](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:316), [JSON:364](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:364), [JSON:460–462](/Users/song/Projects/pitcheezy/docs/pm/research/track-a/A2-ope-redesign-registration-draft.json:460); [policy_semisynthetic.py:11–13](/Users/song/Projects/pitcheezy/experiments/pitchmdp/pitchmdp/policy_semisynthetic.py:11), [policy_estimator.py:7–17](/Users/song/Projects/pitcheezy/experiments/pitchmdp/pitchmdp/policy_estimator.py:7).
