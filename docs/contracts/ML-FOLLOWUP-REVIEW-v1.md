# 후속 후보 활성화 검토 규약

2026-09-24. D1 결과 공개 후, ML2/G/F4/I1 및 정책 결과 공개 전에 기록한다. 사용자의 전체 실행 요청은 매트릭스의 필수 행과 근거가 생긴 후속 행을 끝까지 검토·실행하는 범위다. 가능한 모든 조합을 무조건 학습하거나, 아직 검토하지 않은 행을 생략 완료로 바꾸지 않는다.

실행 결과의 기준 문서는 [실행 보고서](../reports/ML-matrix-execution-2026-09-24.md)다. 이 문서는 추가 후보의 검토 순서를 정하며 아래 조건만으로 새 실험의 세부 설정이 등록된 것은 아니다. 활성화 시 후보 결과를 보기 전에 별도 config·비교 family·비용 gate를 고정한다.

## 현재 활성화한 후속

- D2: D1 D100의 N 통과와 공통 D100 auxiliary 사용 때문에 결과 모형 자료량과 전체 적합 자료량을 구분해야 한다. EXP-P6-001에 신규3fit·보존6fit·두 주 비교를 등록했다.
- P4/P5: 사용자가 강화학습 비교를 명시했고, 타석 rollout과 사전 학습한 정책의 품질·비용을 비교할 독립적인 방법론 가설이 있다. IQL/CQL과 같은 정보를 받는 neural BC를 추가한다. 정책 simulator·행동 지원·보상 확정과 실제 TRAIN 비용 profile이 선행 조건이다.

## 선행 결과로 검토할 후속

| 후보 | 검토할 근거 | 근거가 없을 때 처리 |
|---|---|---|
| D3/D4 최근 자료·최근 가중 | T1의 월별 보정/손실·지원 변화, 같은 후보의 시간 방향 불안정 | 월별 표본 부족을 drift 증거로 삼지 않는다. 해당 가설 미활성화로 기록 |
| D5 선수 다양성 | 같은 자료량에서 특정 역할/저표본/새 선수 오류가 남는지 T2/T4 확인 | 이미 D100에 여러 선수가 있다는 이유만으로 다양성 효과를 주장하거나 반복하지 않음 |
| G5 무작위 군집 | G3의 N/G 이득 또는 유망 결합에서 군집 전문가 기여가 남음 | 군집 의미에 의한 성능 향상을 주장하지 않으며 위약의 활성화 근거 없음 |
| G6 soft mixture | hard routing/fallback별 오류가 나타나고 군집 간 공유로 해결할 구체적 가설이 생김 | soft mixture가 복잡하다는 이유만으로 추가하지 않음 |
| G7 타자 군집, F2 선수 ID | 과거 결과와 다른 저표본/엄격한 새 선수 가설이 T2에서 생김 | 기존 연속 표현 근거를 유지하되 현재 모집단의 신규 비교 완료로 세지 않음 |
| F3 새 backbone의 H0/H5 | ML2에서 후속에 진입한 sequence backbone의 이득 원인 확인 | 과거 물리 H0/H5 결과를 enriched H5의 효과라고 바꾸지 않음 |
| F5/F6 투수 과거·workload | 불펜/경기 후반·반복 대진에 남는 오차와 투구 전 변수의 가용성 | 실제 피로라는 인과 해석 없이 가설·입력 부족을 기록 |
| F7 환경 | 필드 가용성과 새 환경 오류를 먼저 확인 | 없는 포수/심판/날씨 정보를 임의 생성하거나 외부 결합을 완료로 세지 않음 |
| F8 직접 pre-pitch head | 실제400draw 비용에서 비열등 품질과 추론 절약을 비교할 필요가 확인됨 | 조건부 결과 모형과 같은 모델이라고 간주하지 않음 |
| F9 순서 제거 | F4 또는 sequence backbone이 유망하고 순서 기여를 분리해야 함 | 단순 test-time 교란 T3를 재학습 순서 제거 대조로 대체하지 않음 |
| L1 계층 결과 | 희귀 결과의 충분한 사건 수와 체계적인 오차 | 사건 부족만으로 계층 head의 이득을 가정하지 않음 |
| L2 보조 과제 | 타구 보조 라벨의 관측 범위와 F4/표현 학습의 구체적 후속 가설 | 보조 라벨 결측 공을 주 학습에서 지우지 않음 |
| L3 사전학습 | 저표본/새 선수에서 표현 공유의 필요, 같은 자료/계산량 대조 가능 | 추가 학습 자료와 구조 효과를 한 차이로 주장하지 않음 |
| L4 균형 가중·Group DRO | 충분히 측정된 목표 그룹의 R 실패 또는 음의 전이 | 미측정 그룹을 실패로 바꾸지 않음. 활성화하면 ERM/균형 가중/DRO를 함께 비교 |
| L6 앙상블 크기 | C1의 고정0~4seed가 준비되면 추가fit 없이0/0~2/0~4 비교 가능 | 최고seed 선정 금지; 서로 다른 설정을 앙상블 크기 효과로 묶지 않음 |
| P7 타자 대응 | 명시할 수 있는 타자 행동·정보·payoff 가정 | 현재 고정 반응 결과를 게임 균형 해법이라고 표현하지 않음 |
| P8 불확실성 패널티 | 계획/RL의 candidate-world와 common-control-world에서 모델 이용의 취약성이 확인됨 | 단순 Q 불확실성 추정만으로 모델 악용을 단정하지 않음 |
| E2/E3/E4 위치 해상도·오차 | 목표 라벨·실행 분포 또는 명시적으로 축소한 내부 민감도 가설 | 실제 도달 위치를 목표 정답으로 대체하지 않음. E0/E1/P6의 자료 의존 유지 |

## 결합과 확인

2026-09-24 ML2 완료 후 검토: 공통 C6/D100/enrichedH5의6개 구조 후보 모두 N을 통과하지 못했다. 따라서 구조 HPO와 새 sequence backbone의 이득을 설명하기 위한 F3 H0/H5 재학습은 현재 미활성화다. 이 판단은 enriched H5가 불필요하다는 결론이 아니며 과거 물리 H0/H5 근거와도 구분한다. 필수 I1 자료량×구조 비교는 유지하고, F4가 이후 이득을 보이면 별도로 그 이력의 순서/결합을 검토한다. G/F4 결과를 아직 보지 않은 상태에서 C1 결합 또는 C2 적용 불가를 미리 확정하지 않는다.

2026-09-24 G/I1 완료 후 검토: G1~G4의 전체/저표본 N/G 통과는0개이며 G3−G2는 진단용으로만 후속에 고정했다. 군집 의미의 이득을 확인하지 못했으므로 현재 G5 무작위 군집 위약은 미활성화다. F4/다른 실제 결합에서 군집 기여를 주장하게 되면 재검토한다. G1/G4의 실제 악화는 이 후보들을 채택할 근거가 없다는 결과이며, 이 실패만으로 유지 중인 G0에 Group DRO가 필요하다고 하지 않는다. G6/L4의 추가 가설은 T2/T4의 지원·오류를 받은 뒤 검토한다. I1은 양의 방향이지만 실용 문턱 미달로 미확정이며, Transformer의 데이터 부족을 해결한다는 추가 자료/사전학습 실험의 근거로 삼지 않는다.

R의 상한이 허용폭을 넘으면 비열등을 확인하지 못한 것이며 실제 악화의 증명은 아니다. 후속 활성화는 점 추정치·양쪽 구간·지원량을 함께 검토한다. 넓은 구간만으로 음의 전이·drift·모델 악용을 선언하거나 새 알고리즘이 필요하다고 결론내리지 않는다.

C1은 유망 구성 최대2개와 같은 정보·모집단의 강한 기준선을5seed로 비교한다. C6의 구조 순위와 Cpanel의 공유/긴 이력 점수를 직접 빼지 않는다. 결합을 만든다면 공통 Cpanel 보정과 신규 기준선이 필요하다. 기존0~2seed는 설정·표본·보정·해시가 정확히 같을 때만 재사용한다.

C2는 실제 C1 결합에 추가한 구성별 제거 대조다. 결합할 유망 구성이 없으면 무효한 조합을 만들어 의무 횟수를 채우지 않고, 적용 불가 근거와 남은 한계를 명시한다. C1/C2의 구체 후보·제거 순서·주 family는 선행 결과를 받은 뒤 새 개발 비교로 등록하며 독립 최종 확인이라고 부르지 않는다.

각 family의 Holm/Bonferroni는 그 등록 family의 보장이다. 여러 family와 이미 노출된 DEV 전체에 대한 전역 오류율 보장으로 확대하지 않는다. 후속 후보의 점수는 적응적 개발 결과이며, 미개봉 확인 자료가 없는 T5는 별도 외부 의존으로 남는다.
