# 6시간 개선 실행 계획·평가 규약

착수 **2026-09-21 22:03:20 KST**, 종료 목표 **2026-09-22 04:03:20 KST**. 사용자 요청은 여섯 시간 동안 자동으로 다음 유용한 단계까지 이어가는 것이다. 첫 기능이 끝났다는 이유로 전체 작업을 종료하지 않는다. 새 결과는 SSD `runs/observer-improvement-v2`에 보존하며 v1 DB·데모·연구 번들을 덮어쓰지 않는다.

## 목적과 채택 원칙

야구팬이 그 순간의 선택을 이해하고 추천과 실제 공을 구분해서 볼 수 있는 서비스가 우선이다. 예측 지표만 좋아지는 변경보다 정보 시점·좌표·설명의 정확성과 관전 흐름을 함께 확인한다. 관측 투구 데이터에는 진짜 의도 목표가 없으므로 조건부 위치 예측과 목표 개입 효과를 구분한다. 실패·기권·지원 밖 상황도 서비스 결과의 일부다.

- Astra: 구조·입출력 계약, 시점·추천·좌표 코드, 분석·채택 판단.
- Sol: 패키지·실데이터·실험·브라우저 실행과 결과 저장. 작은 단위마다 결과·실패 원인만 공유한다.
- 기존2023–2025 승인 자료와 동결 모델을 사용한다. 선수 이름의 공식 메타데이터 및 해당 기간 공개 짧은 영상은 새로 확인하되2026 경기 자료나 현재 상태를 역사적 예측에 섞지 않는다.
- 새로운 후보는 기존과 같은 평가 표본·지원 조건에서 비교한다. 개선이 불명확하면 기존 기본값을 유지하고 후보·근거를 보존한다.

## 순서와 완료 증거

| 단계 | 작업 | 평가·산출물 |
|---|---|---|
| A 관전 경험 | 공식 선수 이름, 팀/선수/날짜 탐색, 앞뒤 타석, 지원 경기 확장, 과거 투구 수·대결 회차·구속 변화 | 실제 이름 매칭률·지원률·데이터 시점 변조 테스트, 데스크톱/모바일 검색·이동·관전 검증 |
| B 영상/라벨 | 공개 짧은 클립 확보, 투구 ID·셋업 시각·화면 좌표·품질·검토 출처 계약, 작은 라벨 도구와 ROI 추적/보정 | 출처/해시·프레임, 라벨 누락률·추적 기권, 합성 좌표 검사와 실제 영상별 판정 |
| C 위치 검증 | 기존 Gaussian 근사 진단, 독립 위치 조건부 평가기, 소수의 실행 분포 후보 | 분리된 기간의 로그손실/Brier·지원률·게임 bootstrap·정책 비교의 범위 제한 |
| D 서비스 확장 준비 | 과학 패키지 의존성 정리, 설치 재현, 이벤트 공급 계약, 관전 상태와 추론/DB 분리 | 독립 환경/장애·중복·순서·재시작 검사. 실제 라이브·외부 배포는 근거 없는 완료로 표시하지 않음 |
| E 후속 개선 | 앞 결과가 가리키는 가장 큰 미해결 문제부터 한 후보씩 | 후보 선택 이유·전후 지표·채택/보류·재현 명령 |

남은 시간은 유용한 실데이터 평가·오류 복구·포장 재현에 사용한다. 단순 시간 소모용 반복이나 같은 표본을 보고 끝없이 후보를 바꾸는 탐색을 하지 않는다. 마지막 약30분은 최종 검증·문서·서버 상태 정리에 사용한다.

## A: 정보 시점과 표본

- 확장 구간2025-08-16~09-30, 동결된6명 코호트에서 투수당 날짜순 최대3경기. 해당 투수의 지원되는 전체 타석을 사용하며 결과로 경기/타석을 선택하지 않는다.
- 지원 밖 타석·경기는 제외 이유와 분모를 manifest에 남긴다. 관전용 선별 표본을 전체 MLB 평가의 대표 표본이라고 하지 않는다.
- 타자 성향·레퍼토리·존 높이·비교 구속 기준은 경기 날짜보다 이전 자료만 사용한다. 대결 회차와 현재 경기 최근 구속은 해당 공보다 앞선 투구만 사용한다.
- 최근 구속은 현재 미공개 구종을 이용해 고르지 않고 이전에 관측한 구종별로 요약한다. 구속 변화는 관측 차이이며 피로·부상이나 교체 정답을 뜻하지 않는다.
- 이름은 표시용이며 타자 ID를 신경망 특성으로 추가하지 않는다. 검색에 미공개 결과·미래 구종·타석 최종 결과를 사용하지 않는다.

## B: 영상·목표 라벨

확인한 공식 후보는 [Webb 2025-08-17 영상](https://www.mlb.com/giants/video/logan-webb-s-seven-strikeout-performance)이다. 공개 접근 가능한 자료만 소량 확보한다. 영상이 접근 불가하거나 셋업이 잘리면 해당 항목을 기권한다. 삼진 모음은 선택된 결과에 편향된 영상이므로 일반 제구/추천 성능 평가에 쓰지 않는다.

라벨 필수 항목: 출처URL·파일해시, 게임/타석/투구 ID 또는 매칭 미확정, 프레임시각, 투구 시작 이전 여부, 좌표 프레임·해상도, 미트 ROI/점, 보정 앵커·버전, 신뢰도·가림·카메라 컷, 작성자/방법, 검토 상태. `user_manual`, `assistant_visual_estimate`, `tracker_estimate`, `unavailable`을 분리한다. AI 시각 검토를 독립된 인간 정답으로 표시하지 않는다.

실제 도달 위치에서 거꾸로 목표를 만들지 않는다. 픽셀→정규화된 화면 존 보정과 실제 홈플레이트 좌표 변환을 구분한다. 실제 라벨이 부족하면 합성 기하/추적 검사, 실클립 처리 성공·기권 사례까지만 보고한다. 실제 목표→실행 모델의 성능을 검증했다고 하지 않는다.

## C: 위치 근사의 독립 검증

현재 구역 추천은 관측 joint delivery를 Gaussian으로 재가중한 연관 모형이다. 실투구 위치를 알고 나서의 결과 예측과 투구 전 목표 선택은 서로 다른 문제다.

1. 독립 평가기: 기존 신경망/빈도 표를 재사용하지 않고2025-07-01~21의 관측 위치·구종·사전 상황으로 적합.07-22~31로 보정한다. 위치 없는 평가기를 같은 자료·구조의 비교군으로 둔다.
2. 진단/선택:08-01~07. 기본0.45ft 외 위치 근사 폭0.30/0.65ft와 한 가지 축소 후보만 비교한다. 학습·후보 선택에서 이후 날짜의 결과는 제외한다.
3. 통과 점검:08-08~15. 독립 평가기의 관측 결과 예측이 위치 없는 비교군보다 나쁘면 정책 우열 판단에 사용하지 않는다.
4. 후속 비교:08-16~09-30. 날짜/경기 단위 표본, 가능하면 선수별 최소게임 수를 확보한다. 이 자료는 기존 연구에서 일부 노출됐으므로 새로운 확인적 홀드아웃이라고 하지 않고 회고적 개선 실험으로 명시한다.
5. 지표: 로그손실·다중분류 Brier, 주자·아웃·좌우·구종·존 안/밖별 진단, 지원률·유효 표본 수·기권률, 날짜/게임 분리, 게임 단위 paired bootstrap. 충분한 표본 없는 조각은 결론을 보류한다.
6. 정책 비교는 지원 후보 교집합·동일 시작 상태·동일 독립 평가기에서 한다. 관측 위치 조건부 평가기는 의도 개입 효과를 식별하지 않으므로 '독립 모형 아래의 비교'로만 표시한다. 서비스 기본값 채택은 예측/지원/안정성 근거를 함께 본다.

구체적인 표본 수·피처·후보 변경은 실행 전에 작은 JSON 설정과 추가 기록으로 고정한다. 실패 원인을 해결하는 수리와 결과를 보고 최적 후보를 계속 찾는 탐색을 구분한다.
