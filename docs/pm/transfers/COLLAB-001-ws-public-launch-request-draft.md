# COLLAB-001 — 월드시리즈 공개 서비스: 팀원 쪽 첫 요청 (초안)

상태: 초안, 2026-10-11. 팀원에게 아직 보내지 않았다. 보낼 때는 Song이 직접 전달하거나, Song 승인 뒤 `Pitcheezy/transition-models`에 `mail` 이슈로 올린다.

보낸 쪽: Song / Claude(단일 PM) / `SongRoute/pitcheezy`
관련 계약: [공개 발행 계약 초안 v0](../service/public-publish-contract-draft.md), `docs/intent-spec.md` v1.1

## 목표

2026-10-23~31 월드시리즈 동안 주소를 아는 모든 야구팬이 접속해, 경기 중에 다음 공 추천과 실제 공 비교를 본다. **10-22까지 준비 완료.** 중계 영상은 넣지 않는다. 접속량·접속 유지 시간·피드백을 첫날부터 모아 11월 말 전시 시연에서 함께 제시한다.

## 구조 한 줄

맥미니(Song)가 경기 상태와 추천을 파일로 만들어 공개 호스팅에 올리기만 하고, 팬의 화면은 그 파일만 읽는다. 공개 호스팅과 그 위의 운영이 팀원 몫이다.

## 요청

1. **공개 호스팅과 주소** — 정적 파일(화면 빌드 + 데이터 파일)을 올릴 곳과 팬에게 알릴 주소. 진행 중 파일은 짧게, 종료 파일은 길게 캐시할 수 있어야 한다.
1-1. **호스팅이 지켜야 할 조건** (2026-10-11 화면 구현·검토에서 나온 것)
   - `v1/*.json`은 매번 원본에 다시 확인하게 한다(`no-cache` 또는 발행 간격보다 짧은 `max-age`). 종료 표시(`publish.final`)가 붙은 경기 파일만 길게 캐시해도 된다.
   - 캐시가 대신 응답할 때는 `Age`를 붙이고 `Date`를 지우지 않는다. 화면이 이 값으로 "갱신 지연"을 판정한다.
   - 화면과 `v1/`의 출처가 다르면 `Access-Control-Allow-Origin`과 `Access-Control-Expose-Headers: Date, Age`가 필요하다.
   - 없는 파일은 404로 답한다(대신 index.html을 200으로 주지 않는다).
   - 파일 삭제를 반영할 수 있어야 한다(시연 중인 경기 파일 내리기).
   - 올릴 때 파일은 통째로 바꿔치기하고, 점(.)으로 시작하는 임시 파일은 올리지 않는다.
2. **올리기 통로** — 맥미니 발행기가 데이터 파일을 올릴 방법(쓰기 권한이 좁은 인증 하나). 인증 값은 사람끼리 직접 전달하고 레포·이슈에 적지 않는다.
3. **화면 배포** — Song 레포 고정 커밋에서 빌드한 화면을 같은 호스팅에 올린다. 양쪽 커밋과 계약 버전을 배포 목록(manifest)에 적는다.
4. **이용 기록** — 접속량과 접속 유지 시간을 경기별·날짜별로 볼 수 있게. 개인을 식별하지 않는 방식으로 하고, 화면에 수집 안내 문구를 넣는다.
5. **피드백 창구** — 팬이 한두 번 눌러 남길 수 있는 짧은 의견 받기와 저장.
6. **감시** — `health.json`의 발행 시각이 멈추면 두 사람에게 알림. 화면이 열리는지도 주기적으로 확인.
7. **부하 확인** — 공개 주소에 동시 접속을 걸어 화면과 파일 읽기가 버티는지. 맥미니에는 부하를 걸지 않는다.
8. **브라우저 확인** — 공개 주소에서 폰·데스크톱 주요 브라우저 회귀 검사(기존 검사 방식 재사용).
9. **미트 표시** — 월드시리즈 각 경기가 끝난 뒤 IntentEstimate v1 JSONL과 출처 파일(sha256 포함)을 만들어 보낸다. Song 검사기를 통과한 것만 끝난 경기 화면에 붙는다. 모든 값은 "검토 전 추정"으로 표시한다.
10. **이용 조건 조사** — MLB 공개 피드를 불특정 다수 대상 서비스에 쓰는 조건을 조사해 근거와 함께 알린다. 판단은 사람이 한다.

## Song 쪽이 주는 것

- `docs/intent-spec.md` v1.1 원문과 검사기
- 맥미니 발행기(주기적으로 읽고, 표시 가능한 것만 담아, 장부에 기록한 뒤 올림)

## 합격 기준

- 공개 주소에서 실경기 한 경기를 처음부터 끝까지 영상 없이 따라 볼 수 있다.
- 맥미니 발행을 일부러 멈추면 화면에 "갱신 지연"이 뜨고 알림이 온다.
- 이용 기록과 피드백이 실제로 쌓이고 날짜별로 꺼내 볼 수 있다.
- 배포 목록에 양쪽 커밋·계약 버전·파일 sha256이 적혀 있다.

수치 기준(동시 접속 수, 지연 한도, 알림 시간)은 첫 끝-끝 연결에서 재 본 뒤 함께 정한다.
