## 정해진 것

- **D111** 존 시점 = 투수 쪽(실제 중계 화면과 같게). 그리기만 좌우 반전, 발행 파일·좌표·존 id는 포수 시점 계약 그대로.
- **D112** 월드시리즈 운영(10/23~31)은 기존 화면을 공개로 유지, v3는 미리보기로만 병행. v3 채택은 운영 뒤 다시 정한다.
- **디자인 방향 (Song 10/18)**: 박스 안에 박스, 작은 박스를 늘어놓는 표현 대신 **구분선**. 흰 바탕 한 장 위에서 영역·이웃 항목을
  가는 선(`--line`, `--line-2`)으로 나눈다. 반영 커밋 `style(web): v3 flat sections …` (cp07). 새 요소도 이 규칙을 따른다:
  - 카드 배경·둥근 모서리로 묶지 않는다. 묶음은 위 구분선 + 제목으로.
  - 나란한 항목(후보 3개, 이번 타석 공, 오늘 기록 칸, 정규/포스트 열)은 세로선으로 나눈다.
  - 탭은 밑줄형. 상태 칩(확인 중·자료 늦음 등)과 순위 배지·공 번호처럼 의미를 가진 작은 표식만 색 면을 쓴다.
  - 존 바깥 회색(볼 영역)은 그림의 일부라서 남긴다.

## 이어서 할 것 (우선순위 순)

1. **화면 다듬기 (본 작업)** — Song이 이틀 뒤 시작. 구분선 규칙을 기준으로 정보량·글자 크기·간격을 다시 본다.
   캔버스 "Pitcheezy 라이브 화면 시안"의 `구현 · ui/v3` 페이지 스크린숏은 **구분선 반영 전(cp06) 모습**이라 함께 갱신한다.
2. **시리즈 줄 값** — ALCS 결과 확정 뒤 `.env.v3`에 `VITE_V3_SERIES_TEAMS=MIL,<CLE|TB>`, `VITE_V3_SERIES_FROM=2026-10-24`
   (1차전 10/23 20:00 ET = 10/24 09:00 KST, 밀워키). 약어는 실제 발행된 경기 카드로 확인한다(미확인).
3. **로컬 후보 커밋 `1f0260fa`** — 원격 브랜치 어디에도 없음. Song 맥미니에서 `git diff --stat ui/v3 1f0260fa -- apps/observer/web`로 충돌 확인.
4. **운영 뒤** — v3 채택 결정. 채택 시 `ui/v3` → `svc/ws-static-web` 병합 전에 첫 리뷰(cp04) 이후 변경분을 **다른 모델**이 다시 검토.
5. **발행 파일에 없는 값** — 승리확률, 정규/포스트 분리 기록, 회전수·익스텐션·무브먼트, 시즌 구종 사용률. 화면은 자리만 두고 `—`.
   추가는 발행 계약 v1 "추가"이므로 팀원에게 먼저 알린다.
6. **리뷰에서 남긴 낮은 우선순위** — 720px을 넘나들면 열린 패널이 다시 그려짐(내용·포커스 초기화), 화면 오류 뒤 자동 복구 없음,
   미리보기 재생의 서버 시각이 기기 시계, `__PZ_UI__` 미사용.

## 브랜치

| 브랜치 | 내용 |
|---|---|
| `ui/v3` | 작업 줄기 (= cp07) |
| `ui/v3-cp01` … `cp07` | 체크포인트. 01 화면 세트 · 02 상태·스모크 · 03 시리즈 · 04 독립 리뷰 반영 · 05 문구 · 06 투수 쪽 기본(D111·D112) · 07 구분선 디자인 |
| `ui/v3-preset-full` | 기본 = `ui/v3` (B · 가로 한 줄 · 표 · 기본 · 투수 쪽) |
| `ui/v3-preset-lite` / `-expert` / `-catcher` | `.env.v3` 값만 다름 (필수만 / A·여러 줄 / 포수 쪽) |
| `ui/v3-preset-pitcher` | 지울 수 없어 `ui/v3`와 같게 둠. 필요 없으면 삭제 |

`ui/v3`가 바뀌면 프리셋은 `git rebase ui/v3 ui/v3-preset-<이름>` 후 강제 푸시(프리셋 커밋은 `.env.v3` 한 파일).

## 다시 시작하는 법

```sh
cd apps/observer/web
npx tsc -b
npm run build:v3 && node tests/v3-smoke.mjs        # 46개. 프리셋 브랜치에서도 그대로 돈다(.env.v3 값을 읽음)
npm run build:public && node tests/static-publish-smoke.mjs   # 기존 화면: 263 통과 / 8 '한 화면 맞춤' 실패가 기준선
npm run build:preview                               # 재생 + 시안 설정 탭 (공개 금지)
```

- 미리보기 아티팩트 "Pitcheezy 라이브 미리보기"(Song의 claude.ai, 비공개)는 `dist-preview/assets`를 올리고 `index.html`의 두 파일명을
  바꿔 다시 게시한다. 아티팩트 안에서는 주소 쿼리가 전달되지 않아 미리보기 빌드는 `#list` / `#game-<pk>`로 이동한다.
  화면 확인은 `?step=30&play=0#game-990003`(로컬) 같은 시작 지점이 편하다: 9 Bregman 5구 · 11 자료 늦음 · 21 정정 · 30 Suzuki 4구 · 32 연결 끊김 · 48 추천 없음 · 77 종료.
- Playwright가 브라우저 버전 불일치로 안 뜨면 `PLAYWRIGHT_BROWSERS_PATH`에 설치된 chromium을 기대 버전 이름으로 연결한 폴더를 준다.
