# Takamido 방식에서 확장한 첫 시퀀스 실험

2026-09-21 실행. **동일한 투구·상황 입력을 받은 MLP보다 Transformer의 투구 전
로그손실이 개선됐다.** 아직 실제 추천의 승률 개선을 입증한 결과는 아니다.
이전의 부정적인 [MLB 파일럿 결과](REVISED_PILOT.md)는 그대로 보존한다.

## 결과

MLB 선발 6명의 2025년 7–9월 자료에서 지원 조건을 만족한 **87경기, 1,902타석,
7,276구, 타자 370명**을 평가했다. 아래 점수는 낮을수록 좋다.
현재 공의 실제 위치·구속을 입력하지 않고, 선택한 구종에 대한 학습 기간의
공동 물리 분포 25개 표본을 적분했다. 관측된 구종을 선택한 뒤의 예측 평가다.

| 모델 | 로그손실 | 다중 클래스 Brier |
|---|---:|---:|
| 카운트·좌우 손 기준선 | 1.529241 | **0.733705** |
| 과거 투구 이력 없는 신경망 | 1.522544 | 0.735804 |
| 같은 6구 입력의 MLP | 1.523920 | 0.736397 |
| **시퀀스 Transformer** | **1.518155** | 0.734177 |

사전 지정한 주 비교는 **Transformer − MLP 로그손실 −0.005765**,
경기 단위 paired bootstrap 2,000회 95% 구간 **[−0.008967, −0.002542]**다.
과거 이력 없는 모델과의 차이는 −0.004389 [−0.007344, −0.001479],
카운트 기준선과의 차이는 −0.011086 [−0.018575, −0.003439]다.
**Brier에서는 카운트 기준선이 더 좋으므로 모든 지표에서 우수하다고 해석하지 않는다.**
동일 입력 비교는 정보·학습 행을 맞췄으며, 파라미터 수까지 맞춘 비교는 아니다.
또한 구종을 쓰지 않는 카운트 기준선과의 차이를 시퀀스 구조의 순수 효과로 해석하지 않는다.

온도 보정 전/후 로그손실도 모두 저장했다. 조건부 값은 실제 현재 공의 물리량을
입력한 별도 진단이고, 투구 전 값과 직접 비교해 모델 성능 순위를 정하지 않는다.

| 모델 | 조건부 보정 전 → 후 | 투구 전 적분 보정 전 → 후 |
|---|---:|---:|
| 이력 없음 | 1.051770 → 1.051493 | 1.524711 → 1.522544 |
| MLP | 1.057408 → 1.056262 | 1.526354 → 1.523920 |
| Transformer | 1.049755 → 1.048943 | 1.520789 → 1.518155 |

MLP 대비 Transformer의 차이는 보정 전에도 같은 방향이었다.
실제 현재 공의 관측 여부가 결과에 큰 차이를 만들기 때문에 두 평가를 혼용하지 않는다.

## 구현과 데이터

[Takamido & Nakamoto](https://arxiv.org/abs/2606.17345)의 물리 시퀀스와 상황 입력을
분리하는 구조를 참고한 **공통 데이터 적응 실험**이다. 원 논문의 수치 재현은 아니다.
이전 5구와 현재 후보 공을 합쳐 6개 토큰을 사용한다. 물리 입력은 유효 구속,
회전수, 회전축 sin/cos, 수평·수직 변화량, 도달 위치 x/z의 8차원이다.
Transformer는 폭 128, 4 heads, 2 layers이며 출력은 볼·스트라이크·파울·아웃·
단타·2루타·3루타·홈런·몸맞는공·병살의 10개다.

상황 입력에는 볼카운트, 아웃, 이닝, 수비 팀 점수차, 홈/원정, 각 루의 주자,
투타 좌우, 타자의 과거 성향·신뢰도·5개 유형 유사도를 넣었다.
타자 ID는 과거 기록 연결에만 사용하며 반응 신경망의 입력으로 쓰지 않는다.
타자 성향은 해당 경기일보다 이전 날짜의 기록만 이용한다.

- 학습: 2023-05-15–2025-04-30. 전체 MLB의 적격 1,252,824구 중 무작위 250,000구와
  대상 6명 자료를 합친 **275,775구**를 세 신경망에 동일하게 사용했다.
- 보정 및 epoch 선택: 2025년 5–6월 16,000구. 이 중 같은 4,000구로 투구 전
  적분 확률의 온도를 별도 보정했다. 보정 자료를 독립 성능 평가 자료로 주장하지 않는다.
- 평가: 2025년 7–9월. 실제 포함 날짜는 7월 2일–9월 28일이다.
- 고정 선수: Logan Webb, Logan Gilbert, José Berríos, Luis Castillo,
  Framber Valdez, Chris Bassitt. 팀 이동과 관계없이 같은 선수 ID로 기록을 연결한다.
- 원 표본 7,907구·88선발에서 지원 조건 적용 후 7,276구·87선발이 남았다.
  Bassitt의 2025-07-08 등판(game 777188)은 78구 모두 지원 조건 밖이었다.
- 학습/평가 기간 모두 충분한 이닝을 가진 선수를 고른 후향적 모집단이다.
  미래 출전 여부를 모르는 시점에 선정한 전향적 표본이 아니다.
- 지원 조건은 오류·특수 사건, 타석 중 주루 상태 변화, 일부 경기 종료 상황 등을
  제외한다. 타석 전체 경로를 보고 정한 제외이므로 선택 편향이 남는다.

신경망 파라미터는 이력 없음 88,170개, MLP 99,946개, Transformer 278,762개다.
모두 seed 42, 동일 학습/보정 행, 최대 30 epochs, patience 5, batch 1,024를 사용했다.
선택 epoch는 각각 20/20/18이며 학습 시간은 약 22/21/135초였다.
결정구 모델 2개를 포함한 주 실행은 **11:08:23–11:12:56 KST, 약 4분 32초**였다.
초기 본격 착수 10:23:42부터 약 49분 만에 이번 예측 결과가 나왔다.

## 경기 상황·타자 성향의 추가 효과

주 결과를 확인한 뒤 두 제거 실험을 고정해 순차 학습했다. **추가 탐색 실험**이며
독립적인 확증 결과가 아니다. 동일 Transformer 구조·파라미터 수·seed·학습 행·
물리 이력·보정 절차를 유지하고, 선택한 상황 입력만 학습과 추론 모두에서 0으로 가렸다.
볼카운트와 투타 좌우는 유지했다. 경기 상황 제거는 반응 신경망에만 적용하며,
승리 확률 계산의 법적 경기 상태를 삭제하는 것은 아니다.

| Transformer 입력 | 투구 전 로그손실 | 전체 입력 대비 악화 | 경기 bootstrap 95% 구간 |
|---|---:|---:|---:|
| 전체 입력 | 1.518155 | — | — |
| 경기 상황 7개 채널 제거 | 1.527314 | +0.009159 | [+0.006618, +0.011698] |
| 타자 성향·유형 17개 채널 제거 | 1.523423 | +0.005268 | [+0.002294, +0.008145] |

상황 7개 채널은 아웃·이닝·수비 팀 점수차·홈/원정·1/2/3루 점유다.
이 묶음이 현재 예측 모형에 도움이 됐다는 근거이며 각 요소의 독립적인 효과를
식별한 것은 아니다. 타자 성향 제거 실험은 6개 성향 통계·6개 신뢰도·5개 유형
유사도를 함께 제거하므로, 유형 군집 자체만의 효과와도 구분해야 한다.
두 제거 모델의 Brier는 각각 0.734662 / 0.735582로 전체 입력의 0.734177보다 나빴다.
**현재 설정에서는 경기 상황과 타자 성향 묶음을 모두 유지할 근거가 나왔다.**
여러 seed에서의 반복과 다른 평가 기간에서의 확인은 아직 남아 있다.

추가 실행은 11:22:19–11:27경 KST에 완료했다. 결과는 주 run 아래
`ablations-20260921T022219Z`의 `ablation_results.json`, `heldout_predictions.npz`,
`context_masks.json`, `independent_audit.json`, `sequence_ablations.png`에 있다.
독립 CPU 감사에서 8개 확률 표·4개 paired 비교를 재계산했고, 원 모델·예측·설정 등
7개 참조 파일과 소스의 불변성, 같은 표본 행과 파라미터 수도 확인했다.

## 실제 타석의 첫 추천

평가 기간에서 선수별 첫 적격 타석을 기계적으로 고른 6개 사례를 저장했다.
예를 들어 **2025-07-05 Logan Webb, 1회말, 원정 수비 팀 2–0 리드,
무사 주자 없음, 좌타자, 0–0**에서는 다음 순서가 나왔다.

| 순위 | 구종 | 목표 x/z (ft, 포수 관점) | 모델 내부 수비 팀 WE |
|---|---|---|---:|
| 1 | 체인지업 | 0.00 / 1.65 | 66.7055% |
| 2 | 체인지업 | −0.70 / 1.65 | 66.6756% |
| 3 | 커터 | 0.00 / 3.25 | 66.6674% |

후보는 훈련 표본 지지도만으로 고른 구종·목표 조합 최대 6개다. 추천을 위해
해당 실제 투구의 도달 위치나 실제 미래 투구를 사용하지 않았다.
사례당 계산 시간은 약 0.12–0.43초였다. 위 값은 가정한 반응·제구·경기 모형에서
계산한 값이며, 실제 승률이나 추천의 인과 효과 추정치가 아니다.

현재 계획기는 **후보 투구 2개까지 물리 이력과 카운트를 분기하고 이후는
별도의 카운트 기준 모형으로 타석 종료까지 계산하는 근사**다.
전체 타석에 걸쳐 5구 이력의 최적 정책을 정확히 푼 것은 아니다.
0–0에서 시작한 이번 사례는 명시적인 2구 안에 볼넷·삼진에 도달하지 않으므로
그 효과는 이후 카운트 모형을 통해 반영된다. 둘째 공은 모의 첫 공의 이력을 사용한다.

목표 제구는 각 축 표준편차 0.30 ft의 Gaussian 및 3×3 구적법을 가정했다.
위치 외 물리량은 학습 공동 표본의 평균으로 고정했다. 회전축 sin/cos 평균은
단위원 위에 있지 않을 수 있고, 이 가정은 관측 예측에 쓰는 공동 분포와 다르다.
실제 목표 위치 라벨이 없으므로 이것은 추천 파이프라인의 작동 예시다.
루트 구종 빈도로 가중한 내부 값이나 깊이별 값의 차이를 실제 정책 이득으로 보고하지 않는다.

## 해석과 남은 검증

이번 결과는 시퀀스 구조를 다음 연구의 기반으로 삼을 근거를 제공한다.
기존 작은 모델에서 새 모델로 바꾸면서 물리 입력·표본·보정도 바뀌었으므로,
이전 파일럿 대비 개선 전체를 Transformer 하나의 효과로 돌릴 수는 없다.
같은 새 입력을 쓰는 MLP와의 비교가 구조 판단의 주 근거다.

한 번의 seed와 이미 살펴본 DEV에 대한 탐색 결과다. 신뢰구간은 경기 표본의
불확실성만 포함하며 학습 초기화 불확실성은 포함하지 않는다. 기존 논문도 주자·아웃·
점수 등의 상황 입력을 포함하므로, 그 입력 자체를 새로운 기여로 주장하지 않는다.
새 요소의 기여는 제거 실험으로, 승리 확률 목적의 기여는 동일 전이에서 목적만
바꾼 비교로, 실제 추천의 효용은 별도의 정책 평가로 확인해야 한다.
