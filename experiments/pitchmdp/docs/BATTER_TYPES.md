# 타자 유사 유형: 고정 분류 대신 시점별 연속 특성과 소프트 소속도

타자 ID 임베딩은 기록이 충분한 특정 선수를 기억할 수 있지만, 신규 타자에게
전달할 공통 특성을 직접 표현하지 않는다. 이번 변경은 선수 ID를 과거 기록
연결 키로만 사용하고, 투구 결과 모델 입력에서는 제거한다. 타자 범위를 특정
유형이나 최소 표본으로 제한하지 않는다.

유형을 먼저 이름 붙여 분류하지 않는다. 각 경기일 이전 기록으로 다음 여섯
축을 만들고, 학습 기간에 비슷한 프로필의 중심 다섯 개를 추정한다.

| 축 | 분자 / 분모 | 개인 수축 강도 |
|---|---|---:|
| 컨택 | 파울·파울팁·인플레이 / 일반 스윙 | 100 스윙 |
| 스윙 성향 | 일반 스윙 / 일반 스윙·볼·콜드스트라이크 | 200 투구 |
| 볼넷 | 비고의 볼넷 / 비고의 타석 | 60 타석 |
| 삼진 | 삼진 / 비고의 타석 | 60 타석 |
| 장타 | 2루타 + 2×3루타 + 3×홈런 / 타수 | 60 타수 |
| 낮은 타구 | 발사각 10도 미만 / 발사각이 관측된 인플레이 | 60 타구 |

번트·피치아웃·고의 볼은 일반 스윙 판단에서 제외한다. 타격방해는 타석
분모에서 제외한다. 발사각 결측을 뜬공으로 처리하지 않는다. 이 낮은 타구
지표는 발사각 기반 대용치이며, 공식 타구 유형 라벨을 재현한다고 주장하지
않는다. 장타 축은 ISO의 추가 진루/타수 정의를 따른다. 현재 `stand`의 좌우
타석은 관측된 별도 범주로 유지하며 군집화하지 않는다. 스위치 타자 여부를
현재 타석의 좌우로 임의 추론하지 않는다.

각 비율은 해당 날짜 이전 리그 비율로 수축한다. 자료의 첫 날짜에 쓸 초기
평균은 순서대로 `.76, .47, .085, .225, .165, .43`, 리그 초기 가상 표본은
각 분모 기준 500이다. 이는 고정 초기 가정이며 실제 적합한 리그 추정치가
아니다. 리그 평균도 당일·미래 결과를 보지 않는다. 개인 표본이 적으면 리그
평균에 가깝고, 입력에는 축별 `n/(n+수축 강도)`도 함께 제공한다.

군집은 학습 구간의 **타자-날짜별 중복 없는 과거 프로필**로 적합한다.
현재 타석 결과, 학습 마지막 날의 선수 통계를 과거 날짜에 역으로 붙이지
않는다. 타자별 날짜 수의 역수와 평균 기록 신뢰도를 곱해 가중하므로 같은
날 투구 수가 많다는 이유만으로 군집을 더 지배하지 않는다. 센터·표준화
평균/분산·소프트 거리 폭은 학습 자료에서 고정하고 보정/개발 구간에는
변환만 적용한다. 개발 구간에서도 이미 종료된 이전 날짜의 관측 기록은
차례로 갱신한다. 이는 일별 재예측 평가이고 기간 시작에 모든 통계를
동결하는 평가와 다르다.

모델에는 표준화한 연속 비율 여섯 개, 기록 신뢰도 여섯 개, 다섯 중심에
대한 소프트 소속도를 모두 준다. 소속도는 거리 기반 유사도이지 보정된
유형 확률이 아니다. 기록이 전혀 없는 타자는 균등 소속도로 시작한다.
중심 번호는 장타 축 순서로 정렬해 표시할 뿐, 선수를 영구 분류하지 않는다.
중심의 실제 비율을 확인하기 전에는 '컨택형' 같은 이름을 붙이지 않는다.

K=5는 작은 탐색 모델의 용량 선택이지 실제 타자 유형이 다섯 개라는
가설 검증 결과가 아니다. 경기별 상대 투수·구장·구종 배합·카운트 분포의
영향은 아직 보정하지 않으며, 누적 기록은 최근 변화에 느리게 반응한다.
현재 위치별 스윙이나 추격률까지 세분화하면 표본이 빠르게 줄기 때문에
먼저 이 기본 표현의 결과를 확인한다. 유형 수·시간 가중·좌우 상대별 분해는
이번 개발 점수에 맞추어 반복 선택하지 않는다.

최초 ID 모델의 개발 결과를 본 뒤 제안된 수정이므로, 같은 개발 기간에서
개선되어도 탐색적 증거다. 연속 비율만 쓰는 표현과 소프트 군집까지 넣은
표현의 비교가 있어야 '군집 자체가 도움된다'고 말할 수 있다. 타자 ID 제거와
새 과거 비율 추가가 동시에 일어나는 단일 비교로 그 원인을 분리할 수 없다.
