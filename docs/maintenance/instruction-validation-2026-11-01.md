# 공통 지침 전환 검증 — 2026-11-01

상위: [문서 규약](documentation.md) · 변경 전: [고정 원문](instruction-history.md)

지침을 두 벌 유지하던 구조를 AGENTS 정본과 CLAUDE import로 바꿨다. 길이 측정은 Markdown 원문의 Unicode 문자 수(공백 포함)다. 변경 전 `6e2038fd`에서 AGENTS 11,665자·CLAUDE 8,433자였고, 현재 AGENTS는 3,000자 이내, CLAUDE는 11바이트다. 별도 구현·검사 안내는 필요할 때 읽는다. 하위 문서까지 포함한 전체 작업 토큰 감소를 뜻하지 않는다.

## 실제 로딩 확인

설치된 CLI의 도구 없는 짧은 읽기 전용 질의로 전후를 비교했다. 프롬프트는 로딩된 지침 제목·정확한 문장, 연구 비교 구현 보존, 미측정 표기, 무응답 소유권, 검사/보고 경로를 물었다. 각 도구 내 전후 프롬프트를 동일하게 유지했다. 자동 제공된 전역 지침·메모리는 통제하지 않았다.

- Claude(`claude-opus-5-5`) 전후 모두 정상 종료. 이후 응답에서 `CLAUDE.md`의 `@AGENTS.md`와 AGENTS의 새 제목·본문 문장을 정확히 확인했다. 본문을 질문에 직접 주입하거나 읽기 도구로 전달하지 않았다.
- Codex 전후 모두 정상 종료. 이전 응답은 미측정 표기를 미확인이라 답했고, 이후에는 **미측정**과 공통 네 줄 보고를 답했다. 비교 구현 보존과 점유 보호는 전후 모두 답했다.
- Claude 초기 이후 응답은 전역 보고 규칙을 먼저 안내했다. 이를 발견해 네 줄 보고를 AGENTS의 항상 지킬 규칙에도 명시했다. 하위 링크가 있다는 것만으로 내용이 자동 로딩됐다고 주장하지 않는다.

## 증거와 한계

로컬 작업 기록 `codex-maintenance-20261101/instructions/`에 명령·동일 프롬프트·응답 JSON/JSONL·종료 코드·측정 시간이 보존된다. baseline의 소스는 위 고정 커밋, 이후 소스는 이 PR 작업트리다. 모델이 정확한 새 문장을 답한 행동 증거이며 내부 로더 추적이나 모든 앱/버전 검증은 아니다.

도구별 원시 usage는 전역 문맥·캐시·출력 길이까지 포함한다. 단발 응답 시간이나 토큰 수로 효율 향상을 일반화하지 않는다. 실제 구현 작업의 목표 달성률·재작업률·장기 유지보수 비용은 **미측정**이다.

작성자와 다른 에이전트가 문서 범위를 검토했다. 지속 지침의 회차별 PR 허가 제거와 연구 증거 규칙 복원을 확인한 뒤 PASS_WITH_NOTES로 종결했다. 변경 문서 길이·상대 경로·정확 import·diff 검사는 별도 수행한다. 외부 URL의 HTTP 응답과 역사적 모든 anchor는 미측정이다.
