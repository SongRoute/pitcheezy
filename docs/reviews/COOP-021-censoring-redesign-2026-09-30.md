## 0. 요약

- **폭의 87%는 로깅 양성 거절 401 PA에서 나온다**(L1 폭 0.0914 중 0.0793). 다음은 무행동(자동 볼/스트라이크) 54 PA의 0.0108이다.
- **로깅 양성 노드에는 원래 미지값이 없다.** 정책 mask ⊂ BC 지원이라 두 정책 모두 그 행동에 확률 0을 준다. 그래서 참 로깅 법칙에서 ρ_k = 0이 정확하고 V_k = v_π(H_k) = Σ π(a|H_k) q̂(H_k,a)다. 지금의 [0,1] 처리는 필요하지도 않고, 추정기 docstring이 스스로 적었듯 유효 조건(검열이 H_k로 정해짐)도 만족하지 않는다.
- **추천 주 추정량 L1-R:** ① 양성 노드는 ρ=0(런타임이 그 행에서 π·q̂를 기록해야 함, 런타임 v3), ② H_k로 정해지는 거절은 자연 경과(두 정책 공유 관측 종료값), ③ 결정 뒤 정보에 걸린 검열과 미관측 종료만 기존 최악 경계로 둔다. 2026에 남는 최악 경계 폭은 ≤2025 비율로 약 0.0012다. 판정 규칙은 그대로 두고 Δ_lo만 L1-R로 바꾼다.

## 1. 문제 (D115)

v1 L1은 검열 PA의 노드 값을 정책마다 [0,1] 미지값으로 D89 재귀 안에 둔다. 그래서 PA당 Δ 폭이 Π_{t<k}ρ_c + Π_{t<k}ρ_r ≈ 2이고, 평균 폭은 검열 질량의 약 2배가 된다. 표본을 늘려도 이 폭은 줄지 않는다. S6에서 폭은 0.0914, 하한 끝점 CI는 [−0.0579, −0.0348]이었다. 등록 규칙(Δ_lo CI 하한 > 0.001, b_V를 더하면 > 0.00372)은 효과가 약 0.046보다 크지 않으면 원리적으로 통과할 수 없다.

## 3. 원인 분석

### 3.1 `_interval`은 Δ에 공유 미지값을 쓰는가

`TERMINAL_VALUE_MISSING`만 공유한다(`shared=True`: Δ 폭 = |Πρ_c − Πρ_r|). 거절(REFUSED)과 NO_TERMINAL은 정책별 독립 미지값이라 Δ 폭이 Πρ_c + Πρ_r이다. 거절 노드의 미지값은 H_k에서 **각 정책이 이어 갈 때의 값** V_k^c, V_k^r이고, 둘은 일반적으로 다르다. 공유 계수 (Πρ_c − Πρ_r)를 쓰려면 V_k^c = V_k^r여야 하는데, 이는 추정량을 "검열 뒤 공통 대체 정책" regime으로 다시 정의할 때만 성립한다. 공유 처리를 모든 거절에 적용하면 폭은 0.0035(검열 PA 평균 |Πρ_c − Πρ_r| = 0.051)로 준다. 그러나 양성 거절에는 이 regime이 성립하지 않는다(3.2).

### 3.2 로깅 양성 거절

- 런타임은 `logging[a] == 0`이면 후보 탐색 **전에** 거절한다(D93 (4), 예산 절약). 그래서 그 행에는 π·q̂ 기록이 없다.
- mask ⊂ BC 지원(어기면 `IntegrityError`)이므로 π_c(a_k) = π_r(a_k) = 0이다. 실제 로깅 법칙 b는 b(a_k) > 0이다(실제로 던졌다). 그러므로 **참 ρ_k = 0/b(a_k) = 0**이 두 정책에 정확하다. DR 단계는 V_k = v_π(H_k) + 0이 된다. 이는 `OUTSIDE_POLICY_SUPPORT`(ρ=0, 이미 평가됨)와 같은 구조다. BC-P를 재정규화하지 않는다. π̂_b에 바닥값 ε을 줘도 0/ε = 0이라 바닥 의미론은 결과를 바꾸지 않는다.
- 그런데 v1 [0,1] 경계는 "검열이 H_k로 정해짐"을 전제로 한다. 양성 거절은 로그 행동 a_k(결정 뒤 정보)로 정해지므로 v1 경계는 **형식적으로도 유효하지 않다**(docstring·계약 R6의 "위반으로 따로 셈").
- 진짜 문제는 노드 k가 아니라 **π̂_b 오지정**이다. 새 구종이 있는 투수의 π̂_b는 그 투수의 모든 결정에서 다른 구종 확률을 과대평가한다. 따라서 같은 PA의 t<k와 같은 투수의 다른 PA의 ρ도 과소평가된다. [0,1] 검열은 이것을 막지 못한다. 이 경로는 V3 오지정 민감도와 b_V가 다루고, 아래 B 민감도로 보완한다.
- PA 단위 E0 제외로 옮길 수는 없다(a_k에 의존). 투수 단위로 **이 PA 전에 이미 드러난** 새 구종만 쓰면 투구 전 정보다(설계 B).

### 3.3 무행동(자동 볼/스트라이크)

투수의 선택 대신 규칙 위반 사건이 기록된 행이다. 선택이 없고, 그 행에서 관측되며, 의도한 구종과 독립이라고 **가정**하면 H_k로 정해지는 환경 사건이다. 그 뒤 행은 sticky `MID_PA`라 ρ가 없다. 그래서 정책별 연속값은 모르지만, 추정량을 "자동 판정 이후 남은 PA는 실제 투수 행동" regime으로 정의하면 V_k = 관측 종료값 G(두 정책 공유)로 점 식별된다. 이는 D-4 투수 교체 2차 추정(`secondary_value`)과 같은 논리다. 타석 중 미지 투수, 손 불일치, 빈 지원, 이력 불일치도 H_k로 정해지므로 같은 규칙에 넣는다.

## 4. 설계 후보와 ≤2025 리허설

리허설은 봉인 `pa_values`의 정책별 (base, slope)와 원장만 쓴다. 경기 부트스트랩은 S6과 같은 10,000회·seed 3060201743이다. **양성 노드의 v_π(H_k)와 검열 PA의 관측 G는 봉인 산출물에 없다.** 그래서 R 계열은 상한 폭이다. 공유 수준 u ∈ [0,1]로 두고, 양성 노드의 정책 차 |v_c − v_r|는 평가된 38,077행의 분포로 대신한다(중앙 0.00011, q99 0.0080, q999 0.0278, 최대 0.1337). 2026 런타임 v3에서는 이 값이 정확히 기록된다.

형식: L1 Δ 경계 / 폭 / Δ_lo 95% CI / Δ_lo SE(150경기 → 2,430경기 단순 √n 투영).

- **v1 현행:** [−0.0458, +0.0457] / 0.0914 / [−0.0579, −0.0348] / 0.0059 → 0.0015
- **A 모든 거절 공유(양성 포함, 무효 regime):** [−0.0018, +0.0017] / 0.0035 / [−0.0027, −0.0010] / 0.00044 → 0.00011
- **A H_k 거절만 자연 경과:** [−0.0405, +0.0403] / 0.0808 / [−0.0525, −0.0298]
- **R 추천(자연 경과 + 양성 ρ=0, 정책 차 ≤ 최대 0.1337):** [−0.0071, +0.0070] / 0.0141 / [−0.0091, −0.0052] / 0.00099 → 0.00025
- **R(정책 차 ≤ q999 0.0278):** [−0.0029, +0.0028] / 0.0057 / [−0.0040, −0.0019] / 0.00052 → 0.00013
- **R 극한(양성 노드 v_c = v_r):** [−0.0018, +0.0017] / 0.0035 / [−0.0027, −0.0010] / 0.00044 → 0.00011
- **B 드러난 새 구종 투수 제외, 같은 경기만(정확):** E0 9,270, 남은 양성 107 / v1 경계 폭 0.0349 / CI [−0.0212, −0.0142]
- **B 경기 간 포함(순서는 (월, game_pk) 근사):** E0 8,945, 남은 양성 63(투수당 첫 노출만) / 폭 0.0256 / CI [−0.0163, −0.0098]
- **R + B(경기 간):** [−0.0019, +0.0018] / 0.0037 / [−0.0028, −0.0010]
- **C 모든 검열 노드에 공유 수준 + |V_c − V_r| ≤ δ(δ는 ≤2025 평가 행에서 보정):** δ=q99 0.0080 → 폭 0.0031, CI [−0.0024, −0.0008]; δ=q999 → 0.0049; δ=최대 → 0.0146

읽는 법:

- R 계열 폭의 대부분은 리허설용 대리값이다. 공유 수준 u ∈ [0,1]과 |Πρ_c − Πρ_r|의 곱, 그리고 δ 대리값에서 온다. 2026에서는 양성 노드의 v_π(H_k)와 H_k 거절 PA의 G가 모두 관측되므로 이 두 항이 0이 된다. 남는 최악 경계는 NO_TERMINAL과 `MISSING_ACTION_LABEL`뿐이다. ≤2025 S6 비율로는 폭 약 0.0012(NO_TERMINAL 6 PA, 라벨 없음 0)다. **정확한 ≤2025 L1-R 값은 미측정이다.** 런타임 v3로 S6을 다시 돌려야 얻는다(§6).
- B만으로는 부족하다(폭 0.026–0.035). 첫 노출 PA는 남고 폭은 여전히 n에 따라 줄지 않는다.
- C는 모형 가정(δ)에 기대므로 주 추정량이 될 수 없다. 민감도로만 쓴다.

## 5. 추천

### 5.1 주 추정량 L1-R (E0, PA당 Δ, 기존 D89 DR)

1. **로깅 양성 노드:** ρ_k = 0(두 정책, 정확). V_k^π = v_π(H_k)는 런타임이 그 행에서 기록한 π·q̂로 계산한다. 상태 이름·sticky·위반 집계(`validity_violation`)는 유지한다.
2. **H_k로 정해지는 타석 중 거절**(`NO_LOGGED_ACTION`, `UNKNOWN_PITCHER`, `PITCHER_HAND`, `EMPTY_SUPPORT`, `INCONSISTENT_HISTORY`): 자연 경과. 두 정책 모두 V_k = 관측 PA 종료값이고, 종료값이 없으면 공유 미지값 [0,1]이다. 추정량은 "π를 첫 H_k-거절까지 따르고 그 뒤 실제 행동" regime이며, 보고서에 이 이름으로 적는다.
3. **결정 뒤 정보에 걸린 검열**(`MISSING_ACTION_LABEL`), 구조 결함, NO_TERMINAL: v1 최악 경계(정책별 독립)를 그대로 둔다. TERMINAL_VALUE_MISSING은 공유 그대로다.
4. E0 정의, BC-P(전체 어휘, 재정규화 없음), G0 입력 순서, 부트스트랩·ESS 게이트는 바꾸지 않는다. 모집단 선택에 결정 뒤 정보를 쓰지 않는다(1은 값 계산, 2는 regime 정의이며, 둘 다 PA를 빼지 않는다).

### 5.2 민감도 (보고 전용, 판정 없음)

- **S-v1:** 현행 L1 최악 경계(연속성). 원리적으로 통과할 수 없음을 명시한다.
- **S-B:** 이 PA 이전(같은 경기 앞 PA와 앞선 경기)에 TRAIN 지원 밖 구종을 던진 투수의 PA를 E0에서 뺀 L1-R. 투구 전 정보만 쓰고 π̂_b 오지정 노출을 줄인다. 부호가 주 추정과 다르면 보고서 첫 줄에 적는다.
- **S-C:** 남은 최악 경계 노드에 공유 수준 + |V_c − V_r| ≤ δ. δ ∈ {q99 0.0080, q999 0.0278}은 ≤2025 S6 평가 행에서 동결한다.
- **양성 투수 층(서술):** 창 안에서 양성을 한 번이라도 일으킨 투수의 PA 비율과 그 층의 Δ. 사후 정의라 판정에 쓰지 않는다.

### 5.3 D108/D109 규칙의 재서술

- `IMPROVEMENT_SUPPORTED_STATISTICAL` ⇔ **L1-R** Δ_lo의 95% 경기 부트스트랩 CI 하한 > 0.001, ESS·무효·무결성 게이트 통과.
- `IMPROVEMENT_SUPPORTED` ⇔ 위 게이트 + CI 하한 > 0.001 + b_V(= 0.00272, D111) = 0.00372.
- 새 게이트 **G-R:** E0에서 최악 경계로 남은 검열 비율 ≤ 등록 상한(제안 0.01; ≤2025 S6은 6/10,131 = 0.0006). 넘으면 `NOT_DECIDABLE_CENSORING`이고 판정하지 않는다. 런타임 v3 양성 행에 π·q̂ 기록이 없으면 `FAILED_INTEGRITY`다.
- 해로움 판정(Δ_hi CI 상한 < 0), 대비 1개, 사후 변경 금지는 그대로 둔다.
- **통과 조건:** ≤2025 R 극한의 Δ_lo SE 0.00044(150경기)를 2,430경기로 단순 투영하면 약 0.00011이다(투영, 미측정). 남은 최악 폭 약 0.0012의 절반만큼 Δ_lo가 점추정보다 낮아진다. 그래서 STATISTICAL은 참 Δ가 대략 0.001 + 0.0006 + 1.96·0.00011 ≈ **0.0018 WE/PA**, SUPPORTED는 대략 **0.0045**를 넘어야 한다. ≤2025 L2(완료 조건부) Δ는 −0.00005[−0.00066, +0.00053]였으므로 2026 결과는 "개선 근거 없음"일 가능성이 크다. 이것은 폭 문제가 아니라 후보가 BC에 가깝기 때문이다(KL 0.0074).
