2026-09-21 사용자 추가 의견을 반영했다. 최초 LAD 실행은 [FIRST_RESULT.md](FIRST_RESULT.md)에 보존했다.

## 반영한 설계

주자 1·2·3루, 아웃, 점수차, 이닝·초말/홈원정은 결과 모델과 승률 continuation에 사용한다.
타석이 종료되면 실제 학습 자료의 진루 분포에 따라 주자·아웃·점수가 변한다.
반이닝이 바뀌어도 평가 수비 팀은 바뀌지 않는다.

타자 ID는 기록을 연결하는 키로만 사용하고 모델 입력에서 제거했다.
매 경기일 **전날까지**의 컨택·스윙·볼넷·삼진·ISO·땅볼 성향을 구하고,
기록이 부족하면 같은 날짜 이전 리그 평균으로 수축한다. 학습 기간에만 맞춘 5개 중심과의
유사도, 연속 성향, 기록 충분도를 함께 사용한다. 좌우 타석은 별도 입력이다.
한 타자를 하나의 고정 유형에 가두지 않으며, 5개는 시험용 용량 선택이다.
이 유사도는 보정된 ‘진짜 유형 확률’이 아니다. [유형 정의](docs/BATTER_TYPES.md)

평가 기간 50이닝 이상인 선발 중 **학습 기간 선발 이닝 상위 6명**을 선정했다.
팀 제한 없이 선수 ID로 이동 전후 기록을 연결했고, 새 모델 평가 전에 명단을 고정했다.
이닝 표기는 정수+분수이며, 학습 기간과 평가 기간의 길이는 다르다.

평가 기간 출장량을 선정에 사용했으므로, 이는 **두 기간에 충분히 활동한 투수의 회고적 집합**이다.
미래를 모르는 시점의 선수 선정이나 MLB 전체로 일반화하는 확증 평가라고 부르지 않는다.
6명·50이닝은 우선 파일럿 기준이다. 타자 개인 최소 기록량 제한은 없다.

## 관측 예측 평가

학습은 2023-05-15–2025-04-30의 421,994구, 보정은 2025년 5–6월의 20,000구.
평가는 **2025-07-02–09-28, 88선발/87경기, 적격 1,902타석·7,276구·370타자**다.
두 선정 투수가 맞붙은 경기가 있어 선발 수와 경기 수가 다르다. 전체 대상 7,907구 중
평가 적격은 92.02%다. 2026 원본은 읽지 않았다.

| 모델/비교 | 투구 전 log loss ↓ | Brier ↓ |
|---|---:|---:|
| 카운트·좌우 빈도 기준선 | **1.52924** | **0.73371** |
| 타자 유형 + 이력 + 상황 | 1.54797 | 0.74371 |
| 같은 조건의 타자 ID 모델 | 1.54763 | 0.74267 |
| 타자 정보 제거, 좌우 유지 | 1.54804 | 0.74345 |
| 결과 모델의 추가 경기 상황 제거 | 1.54874 | 0.74256 |
| 직전 구종 제거, 현재 카운트 유지 | 1.54480 | 0.74269 |

모든 행은 같은 6명, 같은 날짜 분할·학습 표본·5 epoch·seed를 사용했다.
상황 제거 실험에서도 실제 경기 전이와 WE 계산의 법적 상태는 유지한다.
이 표는 투구 **예측** 비교이며 정책 효과 비교가 아니다. 이 결과로 모델을 사후 선택하지 않았다.

87경기 단위 bootstrap 2,000회에서 유형 모델−단순 기준선 log loss 차이는
**+0.01873 [95% CI +0.00988, +0.02786]**로 기준선보다 나쁘다.
같은 표본의 ID 모델·타자 제거·상황 제거 대비 차이는 모두 구간이 0을 포함했다.
직전 구종을 제거한 모델은 이번 단일 시드에서 오히려 더 좋았다
(유형 Full−이력 제거 +0.00317 [+0.00071, +0.00558]).
구성요소 비교는 탐색적이며 다중 비교 보정·다중 시드 확증은 하지 않았다.

현재 위치를 아는 사후 진단 log loss는 1.09462로 훨씬 낮지만, 이는 투구 전 성능이 아니다.
위치 혼합 모델은 현재 카운트에 조건부가 아니고 고정 개수의 학습 위치 표본을 사용한다.
제구/위치 분포 및 확률 보정이 결과를 제한하는지 먼저 분리해야 한다.

## 연구 방향

사용자가 제안한 ‘선행연구에서 빠진 요소를 추가해 개선’이라는 기준을 따른다.
다만 원문을 확인하니 타자 성향·이력·상황 입력은 이미 일부 선행연구에 있다.
SmartPitch는 타자 성향을 사용하되 무주자·무사 보상을 고정하고, Melville은 타자 embedding·
배합 이력·제구를 다룬다. Takamido 공개본은 주자·아웃·점수차·이닝·초말도 입력한다.
따라서 **정보 추가 자체의 최초성** 대신 다음을 공통 조건에서 검증한다.
[4편 원문 비교와 정확한 근거](docs/RESEARCH_GAP_REVIEW.md)

1. 상황이 결과 확률을 바꾸는 **예측 효과**와, 같은 결과의 중요도를 바꾸는 **승리 가치 효과**를 분리한다.
2. 같은 결과·제구 모델에서 중립/RE/WE 목적과 1구/타석 계획을 비교한다.
3. 현재 병목인 투구 전 위치 혼합과 보정을 개선한 뒤, 타자 유형·이력·상황 기여를 다시 평가한다.
4. 독립 평가기로 추천 가치를 검증하고, 공통 데이터의 기존 연구 기반 기준선과 비교한다.

현재 결과는 ‘직관이 틀렸다’는 결론도, ‘추가하면 성능이 오른다’는 증명도 아니다.
작은 모델 한 시드가 충분한 정보를 학습하고 적분하는지부터 점검해야 한다.
목표 위치 미관측, 미지원 주루·특수 사건의 결과 기반 제외, DEV 사전 노출이라는 한계도 유지된다.
