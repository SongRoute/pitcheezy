# A S0/S1 평가 사양 v1

실험 `EXP-A-S0S1-001`, 계약 `C0-v1`, 가치 `defense-we-pa-v1`. 결과를 열기 전에 이 규칙과 `configs/EXP-A-S0S1-001.json`·선정 manifest를 커밋한다. A의 첫 묶음은 새 추천 모델 학습이 아니라 현재 서비스 재실행과 단순 기준선 평가다.

## 선정과 시간 분할

- 원자료는 승인된 `d20260911-s2325` Statcast 2023–2025, 기존 pitchmdp 전처리 경로를 재사용한다. 2026 파일은 열지 않는다. 원자료·처리자료 해시와 파일 목록은 prepare manifest에 남긴다.
- 투수는 동결 모델에서 TRAIN 선발 이닝으로 이미 정한 순위의 첫 2명, Logan Webb(657277), Zack Wheeler(554430). 이번 평가 결과로 바꾸지 않는다.
- 작은 단순 기준선 TRAIN: 2025-04-01~04-30에서 각 투수의 날짜·game_pk 순 첫 3경기. 현재 서비스는 기존 2023-05-15~2025-04-30 TRAIN 모델을 복원한다. 이 학습량 차이를 명시하며 구조만의 우열 비교라고 하지 않는다. B의 추가 요소 실험은 같은 작은 TRAIN 목록에서 동일 피처·예산으로 대조군을 새로 맞춘다.
- 기존 고정 모델의 2025-05-01~15 조기 종료, 05-16~31 temperature, 06-01~30 blend 보정 이력은 보존한다. 따라서 이 구간을 새 미열람 검증으로 사용하지 않는다.
- S1 DEV: 2025-07-01~31에서 투수별 날짜·game_pk 순 첫 3경기. 지원 여부·결과·모델 오차를 보기 **전에** 경기부터 선택한다. 선정 경기 전체 행과 투구/타석 키를 저장한다. S0는 이 DEV의 투수별 첫 경기 부분집합이며 평가 결과로 다시 고르지 않는다.
- 같은 경기/타석은 분할을 넘지 않는다. 선정 경기의 다른 선수와 미지원 타석도 데이터·분모에 남긴다. 예측 점수는 선정 투수의 완전하고 지원되는 PA의 공통 행에서만 내며, 원본→선정 전체→선정 투수→지원 PA→지원 행동 각 분모와 제외 이유를 표시한다. 동일 PA 이력을 잘라서 학습/평가하지 않는다.
- 기존 7월은 과거 독립 평가기 적합에도 쓰인 **노출된 개발 자료**다. S1은 새로운 확인적 홀드아웃이 아니다. 2026은 기존 P0/P1 OPE 열람 이력이 있으며 미열람으로 재명명하지 않는다. 이번 작업은 2026의 추가 열람·학습·튜닝·모델 선택을 하지 않는다. 최종 확인 평가셋은 이번 묶음에서 읽거나 새로 선언하지 않는다.

## 누수 차단

프로필은 경기 날짜보다 이전의 동결 04-30 스냅샷 또는 검증된 strictly_prior_date 집계만 사용한다. 사용 경로와 cutoff를 결과에 기록한다. 당일/미래 행으로 레퍼토리·존 높이를 만들지 않는다. 모델의 현재 delivery는 TRAIN joint draws를 주변화하고 실제 현재 구속·위치·회전으로 대체하지 않는다. 실투구 구종은 관측 행동에 대한 조건부 예측 점수의 인덱스로만 사용하며 추천을 생성하는 입력으로 쓰지 않는다.

PA 지원 검사에서 후속 상태·종료 행을 읽는 것은 평가 가능 범위를 정하는 회고적 검사다. 그 정보는 모델 입력에 전달하지 않고 제외 수를 보고한다. 지원 PA 밖으로 일반화하지 않는다. CV 개발 fixture는 별도 폴더이며 이 데이터 경로에 넣지 않는다.

## 실행·지표·판정

1. `--prepare`: 설정·원자료 정합성 확인 → 결과를 사용하지 않는 경기 선정 → 전체 경기/PA/투구 목록, 날짜, source hash, config hash, 코드 버전 저장. 결과 계산 전 manifest를 고정한다.
2. `--evaluate`: 준비 산출물 검증 → TRAIN 전처리 → 작은 count-conditioned 평활 결과 빈도 기준선 적합 → 별도 경로 저장/복원 → 고정 서비스 번들 복원 → 추천/예측 → 같은 DEV 행 평가. 파라미터·시드·bootstrap 횟수는 config에 고정하고 결과로 수정하지 않는다.
3. 예측: 10개 결과의 평균 NLL, multiclass Brier(클래스 합), top-label ECE10(고정 동일 폭 bins), 클래스별 표본 수. 조건부 실투구 구종에서 서비스 blend, 동결 frequency, 작은 count baseline을 비교한다. 서비스의 위치 목표 추천과 구종 주변화 확률의 평가 범위를 별도 이름으로 둔다. 위치를 알고 난 뒤의 예측 정확도를 사전 목표 추천 정확도로 표시하지 않는다.
4. 불확실성: 공통 행에서 paired 경기 cluster bootstrap 1,000회, seed=20260923, percentile 95% CI. pitch 단위 독립 bootstrap은 쓰지 않는다. 6경기 수준 CI는 탐색적이고 선수별/희귀 사건 결론은 보류한다. 사건이 없으면 해당 보정/분별 성능은 null·이유로 둔다.
5. 추천: 기존 Observer 구종×목표 추천의 실행률/기권률, 지원 후보 ESS와 내부 수비 WE·기준선 대비 %p를 별도 보고한다. 구종-only Engine과 Observer의 기준 정책이 다름을 표시한다. S0 저장/복원·추천 동일성, 확률합/NaN/합법성, ID·시간 분리, 원본 해시 불변을 확인한다.
6. 정책 가치: 의도 목표와 logging propensity가 없고 이번 소표본에서 독립적인 의도 정책 효과가 식별되지 않는다. **인과 WE 향상·target OPE·OPE ESS는 null**, 사유를 기록한다. 내부 최적화 가치가 높다는 것은 실세계 우위가 아니다. 7월로 적합한 기존 독립 judge를 같은 7월 평가에 사용하지 않는다.
7. 성능 우위 없이도 경로·분할·재현이 통과하면 S0/S1 실행 완료다. 지원 부족/미식별은 실패 수치로 채우지 않는다. 모델 채택이나 대규모 확대는 하지 않는다. B의 추가 요소 한 축 비교는 이 고정 개발 분할과 기준표에서 후속 실행한다.

## 선행연구 공통 비교 사양

기존 확인 범위와 원문 미확인 상태는 `docs/baselines.md`를 그대로 따른다. 이번 A에서 새 논문 수치를 전재하거나 전 논문을 재현하지 않는다.

| 비교 | 후속 통제 조건 | 이번 상태 |
|---|---|---|
| 단순 빈도 | 같은 정보시점, 클래스, DEV 공통 행; 작은 TRAIN 크기 표시 | 실행 대상 |
| SmartPitch류 count-only | 같은 TRAIN/DEV, 합법 행동·WE continuation, 정책 평가기·지원집합·튜닝 예산; 원문 RE와 서비스 WE는 별도 변형 | 비교 사양만; 기존 RE24 결과는 별도 보존 |
| Takamido류 sequence | 현재 물리 피처 없는 사전 정보 비교와 관측 물리 포함 예측을 분리; 동일 6구 이력/공통 행과 모델 예산; 2스트라이크 사전 지정 슬라이스 | B 후보 후 실행; 이번 재현 없음 |

## A4 사건·교체 자료 경계

선정 DEV 경기 안의 모든 홈런·삼진 종료 투구를 모델 점수와 무관하게 사건 목록에 기록한다. 목표 위치/목표 구종/사인 결정자 정답은 없다. 선정 경기 전체 PA 이력과 실제 투수 교체 경계는 보존하지만 당시 가용 불펜 명단·휴식·부상·벤치 대안은 Statcast만으로 확정하지 않는다. C는 입력이 없는 교체 반사실 가치를 미측정으로 두며 실제 결과를 보고 좋은 교체 후보를 역선정하지 않는다.
