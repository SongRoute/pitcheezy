# 인터페이스 스펙 v0

템플릿 v0. [슬롯]은 다음 설계 세션(상태 스키마 확정)에서 채운다. 스펙 변경 = 버전 업 + ADR + 태그 `spec-vN`.

## 공통 자산 0 — RE24 테이블
- 생산 A / 소비 A·B·C
- 내용: 시즌 창별 24상태(주자 × 아웃) 기대득점. Phase 1부터 결과 조회표 P(ΔRE24 | 타구 특성, 주자·아웃) 포함
- 버전: 시즌 창 + 계산 커밋
- 규칙: 한 실험 안에서 A·B·C 모두 같은 버전. 정합성 검증(성분 합 = V(추천) − ΔRE24(실제 결과))이 이 규칙에 의존

## 자산 1 — 전이 확률 텐서 (A → B)
- 축: [투수] × [상태] × [행동] × [다음 상태 ∪ 종결 결과]
  - 상태 = 카운트, 주자·아웃, 타자 군집, 맥락 피처 — 카디널리티·인코딩 [슬롯]
  - 행동 = 구종 × 로케이션 그리드 — 그리드 해상도 [슬롯]
  - 다음 상태 ∪ 종결 결과 (∪ 투구 이벤트, Phase 1) — 결과 공간 정의 [슬롯]
- 값: 확률. 행 합 = 1, 허용 오차 [슬롯]. dtype [슬롯]
- 저장 포맷: [슬롯 — npz / parquet long-format / zarr 중]
- 메타데이터: 데이터 버전, 시즌 창, 모델 구조(ⓐ/ⓑ/ⓒ), 시드, 학습 커밋, 홀드아웃 NLL·ECE
- 검증 계약: 행 합 = 1, NaN 없음, 표본 부족 셀 처리 방식 명시(스무딩 / 마스킹)
- 변경 절차: 축 추가(폭투 이벤트 등) = 스펙 버전 업 + ADR

## 자산 2 — 가치함수 (B → C)
- 내용: Q(s, a) — 상태 × 행동 그리드 전체. V(추천) = a에 대한 max, V(의도)·V(실제)는 해당 a 조회
- 추천 정책: argmax + 평가용 완화 파라미터(softmax 온도 또는 top-k)
- 단위: RE24 (득점)
- 메타데이터: 전이 텐서 버전, RE24 테이블 버전, 종결 보상 축(ⓐ/ⓑ/ⓒ), 인플레이 보상(실제 / xRE24), γ = 1
- 검증 계약: 정합성 — Σ 분해 성분 = V(추천) − ΔRE24(실제 결과), 같은 RE24 버전으로
- 미결 [다음 세션]: 기준점(GMM 성분 중심)이 그리드 밖에 놓일 때 — 스냅 vs 보간. 그리드 해상도가 C의 기준점 정밀도를 제한하므로 A·C 합의 필요
