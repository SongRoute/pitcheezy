# Pitcheezy 실험 원결과 모음

작성: 2026-10-01. 지금까지 한 실험의 수치를 한 파일에 모았다. 새로 돌린 실험은 없고, 숫자는 `results/`, `docs/experiments.md`, `docs/decisions.md`, 각 결과 문서와 봉인된 결과 파일에서 그대로 옮겼다. 예외는 4장 EXP-P11-001의 월별 표에 있는 "차이" 열 하나로, 두 값을 단순히 뺀 것이며 그렇게 표시했다. 원문과 다르면 원문이 맞다.

## 차례

1. RE24 트랙 P0·P1 (9/17~9/20)
2. 초기 파일럿 (9/21~9/22)
3. 관전 서비스 ABCD 트랙 (9/22~9/24)
4. ML 매트릭스: 투구 결과 10종 확률 예측 (9/24~9/30)
5. 정책 검증: 2025년까지 리허설과 2026 평가 (9/29~10/1)
6. 데모 사전 계산 (참고)

## 읽는 법

- 실험은 다섯 묶음이다. 묶음마다 문제·자료·지표가 달라서 **다른 묶음의 숫자끼리 순위를 매기면 안 된다.**
  1. RE24 트랙 P0·P1 (9/17~9/20): 구종×위치 추천을 "실점 억제량"으로 평가.
  2. 초기 파일럿 (9/21~9/22): 선발 6명으로 투구 결과 예측과 추천을 처음 연결.
  3. 관전 서비스 ABCD 트랙 (9/22~9/24): 웹 서비스 구현 검증과 추천 선택 진단.
  4. ML 매트릭스 (9/24~9/30): 투구 결과 10종 확률 예측. 현재 기준 모델 G0가 여기서 나왔다.
  5. 정책 검증 (9/29~10/1): G0로 만든 추천 정책을 2025년까지 자료로 리허설하고 2026 평가를 준비.
- NLL(로그손실)과 Brier는 낮을수록 좋다. ΔNLL이 음수면 후보가 더 좋다.
- OPE는 실제 경기 기록으로 "추천대로 던졌다면"을 계산하는 평가다. SNIPS·DR은 그 계산 방법 이름이다.
- "모델 내부 평가"는 우리 모델이 만든 가상 세계 안에서 잰 값이라 실제 효과의 근거가 아니다.
- "노출된 DEV"는 이미 여러 번 본 평가 자료라는 뜻이다. 여기서 좋아진 것은 독립 확인이 아니다.
- 2026 시즌 자료: 1번 묶음(P0·P1)은 당시 규칙대로 2026(9/9까지 수집본)을 OPE에만 썼다. 2~4번 묶음은 2026을 쓰지 않았다. 5번 묶음의 2026 평가는 1회 실행을 마쳤다(5.6절).

## 3. 관전 서비스 ABCD 트랙 (9/22~9/24)

이 트랙은 관전 서비스를 네 갈래로 나눠 만든 기간이다. **A**는 총괄(공통 약속·데이터 나누기·평가 기준·독립 검토), **B**는 추천(다음 공의 구종·위치 추천과 그 예측 모델), **C**는 사건·교체 분석(삼진·홈런 같은 사건의 승률 변화, 투수 교체·이닝 전망), **D**는 관전 화면(UI·API·저장)이다.
야구로 치면 A는 기록원, B는 배터리 코치, C는 경기 분석관, D는 전광판 담당이다.

공통 주의(모든 항목에 해당, 출처 각 문서):
- 평가 자료는 2025년 7월 6경기(Webb·Wheeler)로, 이미 개발에 써 본 **노출된 DEV**다. 새 최종 평가셋이 아니다.
- 승률(WE) 수치는 동결 모델이 자기 안에서 계산한 **모델 내부 값**이다. 실제 정책 효과(OPE)·인과 효과는 전부 미측정(null)이다.
- 실제 투구 의도(CV 라벨)는 없다. 2026 자료는 열지 않았다.

## 4. ML 매트릭스: 투구 결과 10종 확률 예측 (9/24~9/30)

**무엇을 했나.** 다음 공 한 개의 결과를 10종류(볼·스트라이크·파울·아웃·안타 종류 등)로 나눠, 각 결과가 나올 확률을 예측하는 모델을 여러 방식으로 바꿔 가며 비교했다. 점수는 주로 NLL(낮을수록 좋음)과 Brier(낮을수록 좋음)다. 비교는 늘 "후보 − 대조군"의 차이(ΔNLL)로 보고, 음수면 후보가 낫다.

**자료 나누기(날짜).** [매트릭스 문서](ML_EXPERIMENT_MATRIX.md) 기준.
- TRAIN(학습): 2023-05-15 ~ 2025-04-30
- early-stop(학습 멈춤 판단): 2025-05-01 ~ 05-15
- CAL(보정): temperature 05-16 ~ 05-31, blend(빈도 모델과 섞는 비율) 06-01 ~ 06-30
- DEV(평가): 2025-07-01 ~ 09-30. 이 DEV는 이미 여러 번 열어 본 자료라 "독립 확인"이 아니라 "개발 평가"다.
- 2026 자료는 쓰지 않았다.

**평가 집단 세 가지.**
- C6: 기존 선발 위주 6명, DEV 60경기·5,048구. 예전 결과와 잇기 위한 작은 집단.
- Cpanel: TRAIN 이력으로 고른 48명 패널(선발/불펜·좌우·표본량 섞음), DEV 328경기·12,334구.
- 전체 MLB: DEV 적격 311,721구·1,161경기(요청 341,941구).

**통과 기준(요약, [매트릭스 §2](ML_EXPERIMENT_MATRIX.md)).**
- N(전체 예측 개선): ΔNLL ≤ −0.003, 짝지은 95% CI 상한 < 0, 다중 비교(Holm) 통과, ΔBrier 95% 상한 ≤ +0.001. 3seed면 2/3 이상, 5seed면 4/5 이상 seed가 개선 방향.
- G(목표 집단 개선): 지정 집단에서 N 기준 + 전체가 나빠지지 않을 것.
- R(강건성): 각 주요 집단에서 ΔNLL 상한 ≤ +0.010, ΔBrier 상한 ≤ +0.002. "상한 실패"는 "나빠지지 않음을 확인 못 함"이지 "나빠짐 증명"이 아니다.
- R 그룹 12개: 선발/불펜(role), 좌/우투(hand), TRAIN 표본량 zero/low/middle/high(volume), 2스트라이크/그 외, 주자 있음/없음.

**클래스 번호 뜻.** 결과 파일에는 이름이 없어 코드 상수(`experiments/pitchmdp/pitchmdp/model.py`의 `OUTCOMES` 순서)에서 옮겼다: 0 볼, 1 스트라이크, 2 파울, 3 아웃, 4 단타, 5 2루타, 6 3루타, 7 홈런, 8 몸맞는공, 9 병살. 각 실험이 이 순서를 그대로 쓴다는 것은 결과 파일에 명시돼 있지 않다.

**공통 주의.** 모든 결과는 이미 열람한 2025 DEV에서의 개발 결과다. 독립 확인·정책 효과·서비스 교체는 없다. bootstrap 구간은 학습된 모델을 고정한 조건부 구간이라 학습·보정·선정의 불확실성은 들어 있지 않다.

### 5.7 예측기 교체 진단: G0 → 혼합 (EXP-P17-001, 2026-10-02)

**무엇을 했나.** 추천 계획기(P3)는 예측기에게 "이 구종이면 결과가 어떨까"를 물어 타석을 미리 굴려 본 뒤 구종 분포를 정한다. 그 예측기만 G0에서 혼합 모델(직접 head 1/2 + G0 1/2, D145)로 바꿨을 때 추천 분포가 얼마나 달라지는지 쟀다. 기준 정책, τ 0.1, 탐색 설정(6×12), 계획 seed 0, 결정 상태는 그대로다. 경기 결과·보상·WE 결과는 읽지 않았다. 결과 계산 전에 등록했다(D147).

**자료.** 봉인된 S3b-tau-a4(6월 2025, 150경기, 요청 43,487)가 평가한 결정 40,702개. G0 쪽 값은 봉인 원장의 계획 Q를 그대로 쓰고, 혼합 쪽만 새로 계산했다(2,459초, 최대 6.2GB).

**유효성 확인.**
- 연결 probe(S2 등록 64행): 정책 경로 예측과 봉인 평가 예측의 최대 차 — G0 1.9e-8, 직접 head 1.1e-16, 적분한 혼합 1.3e-8(허용 1e-6).
- 다시 만든 요청 43,487개의 fingerprint·mask·기준 분포·맥락 해시가 봉인 원장과 모두 일치.
- 처음 200결정을 G0로 다시 계산한 계획 Q와 봉인 값의 최대 차 0.0.

| 지표 | 값 [95% 경기 부트스트랩] |
|---|---|
| 평균 TV (두 추천 분포의 차이, 0~1) | **0.0323** [0.0303, 0.0343] |
| 1순위 구종이 같은 비율 | **92.8%** [92.1%, 93.4%] |
| TV 중앙값 / 90분위 / 99분위 / 최대 | 0.0218 / 0.0751 / 0.1865 / 0.6171 |
| TV > 0.05인 결정 | 19.9% |

**판정.** 사전에 고정한 규칙(평균 TV < 0.01 그리고 일치율 ≥ 98%이면 "같음")에 따라 **`DIFFERENT_RECOMMENDATIONS`**. 고정한 해석대로 사용자에게 보고하고, 정책 재검증(단계 C)과 검토 게이트는 사용자가 정한다. 자동으로 실행되는 것은 없다.

**읽는 법.**
- 추천이 "달라진다"는 것이지 "나아진다"는 것이 아니다. 정책 가치는 재지 않았다.
- 차이의 얼마가 예측기 때문이고 얼마가 탐색 잡음 때문인지는 **미측정**이다. 계획 Q는 구종마다 6번 굴려 본 평균이라 잡음이 있다. 봉인 G0 실행에서 계획 Q의 짝 차이 표준오차는 중앙값 0.0145·90분위 0.0448이고, 예측기 교체로 생긴 Q 차이(결정별 최대 절대 차)의 평균은 0.0199로 같은 크기다. 같은 난수를 썼지만 예측이 달라지면 굴린 경로가 갈라지므로 잡음이 섞인다.
- 혼합 정책이 기준 정책(실제 투수 흉내)에 조금 더 가깝다(평균 KL 0.00595 대 0.00734).
- 문턱 0.01·98%는 측정 근거 없는 판단값이다. 6월 자료는 τ 설계에 이미 쓴 자료다.
- 같은 모델 검토뿐이며 독립 검토 게이트는 통과하지 않았다. 정책 식별자 등록·서비스 변경 없음.
