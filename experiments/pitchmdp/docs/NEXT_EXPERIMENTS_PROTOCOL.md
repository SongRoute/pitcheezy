# 연속 후속 실험: 고정 계획

작성 2026-09-21. 사용자가 첫 결과 이후 권장 우선순위대로 후속 실험을 이어서
진행하도록 승인했다. 이미 살펴본 DEV를 사용하는 개발 연구이며 새 확증 표본은 아니다.
이 계획은 아래 새 학습을 시작하기 전에 기록한다. 이전 결과와 체크포인트는 보존한다.

## 1. 초기값에 대한 안정성

- 모델 seed를 **42, 43, 44, 45, 46**으로 고정한다. 결과가 좋은 seed만 보고하지 않는다.
- 표본 추출, 타자 유형 중심, 정규화, 공동 물리 분포와 표본은 기존 seed42 그대로다.
  바꾸는 것은 신경망 초기화·dropout·학습 순서의 seed다. 훈련 표본 자체의 불확실성을
  추정하는 실험은 아니다.
- 동일 입력 Transformer와 MLP, Transformer의 경기 상황 제거 및 타자 성향 제거를
  반복한다. seed42는 검증된 이전 산출물을 재사용하고 새 seed43–46을 순차 학습한다.
- 주 지표는 각 seed의 투구별 로그손실을 평균한 값이다. 평균 확률의 점수인
  ensemble 성능과 구분한다. Brier도 함께 보고하며 각 seed 값을 전부 보존한다.
- 주 비교는 Transformer−MLP, 제거 모델−전체 Transformer다. 양쪽 같은 seed를 짝짓는다.
- 경기 단위 paired bootstrap와 seed×경기를 함께 재표집한 crossed bootstrap를
  각각 2,000회 보고한다. 동일한 87경기를 seed 수만큼 독립 경기로 세지 않는다.
  seed5개의 한계와 기존 DEV를 본 사실을 명시한다. 월별 성능은 기술 통계로만 사용한다.
- seed42 포함 5개와 새 seed43–46의 요약을 구분한다. 중간 결과로 실행 수를 줄이지 않는다.

## 2. 모델 크기를 맞춘 비교

기존 Transformer 278,762개와 작은 MLP 99,946개는 용량이 달랐다.
MLP 폭을 파라미터 수의 산식으로 **234**로 정하면 **278,874개**로 맞출 수 있다.
이 폭은 DEV 성능으로 선택하지 않는다. 같은 ordered6구+mask+context를 사용하고
같은 다섯 seed, 학습 행, 최대 epoch, early stopping, 보정 절차를 적용한다.
계산량까지 같다는 주장은 하지 않는다. 기존 폭128 MLP 결과도 유지한다.

## 3. 군집 표현의 추가 효과

전체 Transformer의 28차원 상황 입력에서 유형 유사도 다섯 채널(23:28)만 0으로
가리고 재학습한다. 성향 통계 여섯 개(11:17), 신뢰도 여섯 개(17:23), 좌우 손,
경기 상황, 물리 이력은 보존한다. 동일 다섯 seed와 파라미터 수를 사용한다.
이 비교는 이전의 17차원 전체 타자 성향 제거와 달리 군집 요약의 추가 효과를 본다.
군집이 이득을 주지 않아도 부정적 결과를 그대로 보고하고 단순화 후보로 삼는다.

## 4. 예측 확률의 안정화

학습을 늘리지 않고 고정한 전체 Transformer 다섯 개의 산술 평균 확률을 평가한다.
그 후 학습 기간에서 만든 카운트 기준 확률과 혼합하는 가중치를 **보정 자료에서만**
선택한다. 주 혼합은 보정 로그손실 최소화, 보조 혼합은 Brier 최소화로 사전에 구분한다.
둘 다 보고하고 DEV에서 더 좋아 보이는 쪽만 선택해 보고하지 않는다.
가능하면 기존 온도 보정 4,000구를 제외한 보정 표본으로 혼합 가중치를 정한다.
이 보정 기간은 이미 epoch 선택에 쓰였으므로 독립 검증 자료라고 부르지 않는다.
앙상블은 한 모델의 구조적 우수성이나 단일 모델의 비용으로 해석하지 않는다.

## 5. 추천 가정의 민감도

고정된 실제 사례 6개와 학습 지지도로 선택한 같은 후보 6개를 사용한다.
각 축 제구 표준편차 0.15/0.30/0.45ft와 계획 깊이1/2를 비교한다.
위치 외 물리량의 기존 평균 가정과 학습 공동 표본 중 하나인 medoid를 비교한다.
후자는 대치한 값이 포함된 과거 표본이며 완전히 관측된 원자료임을 보장하지 않는다.
후보 1위·순위 변화·값의 범위를 모두 보고한다. 이를 실제 승률 개선으로 해석하지 않는다.
순위가 가정에 민감하면 긴 계획기보다 제구 모델 개선을 다음 우선순위로 올린다.

## 실행 및 판단

원본은 허용된 2023–2025 세 파일/검증 캐시만 사용한다. 2026은 읽지 않는다.
큰 산출물은 마운트된 T7 SSD에만 저장하고 학습은 한 번에 하나씩 실행한다.
신규 소스·설정·순서가 있는 표본 키·참조 파일 해시를 동결하고, 완료 모델의 재사용은
그 동일성이 확인될 때만 허용한다. 반복 실험 진행 중에도 이전 보고서는 바꾸지 않는다.

첫 단계 결과에 따라 더 긴 타석 계획, 독립 정책 평가, 시간 구간 반복 중 다음 우선순위를
정한다. 미관측 정책 효과를 최대화했다는 주장 없이 예측 성능·표현 효과·추천 민감도를
각각 구분하여 기록한다.
