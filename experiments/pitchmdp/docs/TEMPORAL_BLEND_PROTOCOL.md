# Temporal retraining and matched blends — frozen before fitting

Created 2026-09-21. Exploratory rolling-origin replication; historical 2024/2025 data have already been inspected in earlier experiments. No untouched confirmatory-test claim.

- Two fresh folds: TRAIN 2023-05-15 through April30 of 2024 or 2025. Evaluation July1–September30 of the corresponding year (available regular-season rows only). Reset old split labels before any fitted preprocessing.
- Select six starters by TRAIN recorded outs, then TRAIN starts, then ascending pitcher ID. No future availability, innings, outcome, team or performance filter. Keep selected members with zero evaluation exposure; report raw and eligible coverage for all six, and uncertainty of reconstructed innings.
- TRAIN neural sample: deterministic250000 league eligible pitches plus every selected-starter eligible TRAIN pitch, deduplicated. Same sample, physical normalization, TRAIN-fitted context/style clusters and delivery vectors for both architectures/all seeds. Frequency hierarchy and delivery use full eligible TRAIN. Physical normalizer uses all TRAIN rows, including unsupported rows, as in the original design.
- Disjoint CAL periods: May1–15 league eligible sample up to16000 for conditional early stopping; May16–31 all selected-starter eligible pitches for integrated temperature; June all selected-starter eligible pitches for convex blend weight. No replacement based on results; stop on empty aggregate partition. Individual unavailable pitchers remain in cohort. Style histories update using strictly prior dates, including earlier evaluation dates, reflecting online information availability; learned parameters stay frozen.
- Neural architectures: original Transformer128 (two layers, four heads), ordered flattened MLP128; seeds42–46; maximum30epochs, patience5, AdamW lr0.0005/batch1024. Same observed features including5previous physical pitches, hypothetical current physical vector, game context, prior batter styles/reliabilities and5soft type similarities. Batter/player IDs are not neural inputs. Different parameter counts are disclosed: this compares practical model pipelines, not isolated architecture at equal capacity.
- Pre-pitch known-type evaluation: replace observed CURRENT physical vector by shared TRAIN joint delivery draws400, seed42; same vectors/tiers for every neural model. Actual previous pitches are observable. Pools are empirical, finite, nonnested relative to earlier25/100draw runs;400is not exact integration. No inference/model/temperature from previous runs reused.
- One fixed strong frequency model, chosen by prior experiment design: global→count/hand(strength50)→pitch type(strength50)→outs/bases(strength100). No new baseline search. Fit temperature on the same May16–31 sample, range0.5–2.5. Each neural seed uses that sample for integrated temperature. Five-seed probability ensemble then receives its own scalar convex blend with the SAME frequency forecast, fitted on June log loss including exact weight endpoints.
- Primary comparison: Transformer blend minus MLP blend held-out log loss. Both blends versus frequency are also retained. Secondary: Brier, unblended ensembles, individual seed and pitcher metrics. Lower log loss/Brier is better. Paired2000whole-game bootstrap within each year, conditional on fitted ensemble and calibration choices; excludes training/weight-estimation uncertainty. No treating seeds as independent games, no tuning on evaluation, no choosing a favorable year. Report each year; no pooled independence claim for nested-training folds.

Known observed pitch type is conditioned on; this is not a direct test of recommending alternative actions or improvement in win probability.
