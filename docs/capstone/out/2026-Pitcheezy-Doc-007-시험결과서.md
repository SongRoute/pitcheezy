1. 프로젝트 개요 

1.1 시스템명

AI 투구 추천 야구 관전 보조 시스템(Pitcheezy)

1.2 시스템 개요  

시스템은 MLB Statcast 투구 기록과 MLB 공식 경기 피드를 바탕으로, 투구 전 상황(볼카운트·주자·아웃·투수·타자)에서 수비 팀의 기대 승리확률을 가장 높이는 구종과 목표 구역 상위 3개를 추천한다.

사용자는 중계를 보면서 보조 화면(‘두 번째 전광판’)으로 추천을 확인하고, 실제 투구(구종·구속·도착 위치·판정)와 추천의 차이를 비교한다.

시스템은 추천 근거(선택 비중, 지원 여부, 추천 출처)를 함께 표시하고, 지원하지 않는 투수·상황은 숨기지 않고 ‘미지원’으로 알린다.

예측 성능(결과 확률 모델의 NLL·보정)과 추천 정책 효과(오프라인 정책 평가)는 분리해 검증하며, 2026 시즌 자료는 사전 등록한 정책 평가에만 쓴다.

2. 테스트 개요

2.1 테스트 범위 

시험 단계 : 시스템 시험. 단위·통합 시험은 저장소의 자동 테스트(계약·누수 방지·정책 평가·감독기)로 대신하고, 최종 시스템에 대해 기능 시험과 실경기 시험을 수행한다.

시험 범위 : 프로덕트 백로그(2026-Pitcheezy-Doc-004)의 주제 T-01~T-10 전체. 자동 테스트 3묶음(정본 저장소 tests/, 연구 코드 experiments/pitchmdp/tests, 출시 후보 백엔드·운영·웹 smoke), 실경기 리허설 5경기(849844·849831·849809·849817·849815)·시연 1회(813031), 월드시리즈 1~4차전 비공개 무인 운영(849805·849802·849804·849803, 10/24~10/28)을 근거로 삼는다.

제외 : 사건 기여도 요인 분해(E-11, 출시 제외·WS 뒤 내부 그림자부터 D178), 공개 서비스(월드시리즈 전체 비공개 라이브 D181, 공개 이용자 0명), 실기기(iPhone Safari) 확인, 팬 사용성 평가(0회), CV 의도 화면 연결·물리 정확도. 제외 항목은 6장 결과표에 ‘N’으로 남긴다. 공개 호스트 공동 시험은 10/26 1회 수행해 결과표에 F로 기록했다.

시험 시각 : 자동 테스트는 2026-10-20 HEAD 5dd881b3에서 재실행했고, 출시 후보 영수증은 2026-10-19 기록값을 인용한다(docs/pm/integration/handoffs/2026-10-19-ws-launch-blockers.md). 월드시리즈 운영 수치는 2026-10-28에 맥미니 운영 기록(pm-jobs/ws-ops/runs/의 PRESTART·END·status·발행 game 파일)에서 집계했다.
