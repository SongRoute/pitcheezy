# 결과 요약

숫자는 README와 같습니다. 각 숫자가 어디서 나왔고 이 레포에서 다시 만들 수 있는지를 적습니다.

## 다시 만들 수 있는 것 (저장된 확률이 있으면)

- `rescore/table1-rescored.json`, `.csv` — 31경기·8,943구 9줄 표(NLL·1순위·3순위)와 경기 단위 부트스트랩 차이 구간. `scripts/rescore_table.py` 출력.
- `figures/` — 그림 0~4, 표 1~3. `scripts/make_structure_figure.py`, `scripts/make_figures.py` 출력.
- `final-mix-weights.json` — 최종 모델의 성분·비중·온도(원래 실행 산출물에서 경로만 빼고 옮김).

## 요약만 있는 것 (입력이 레포에 없음)

- `wildcard-8games.md` — 와일드카드 8경기 1회 확인: −0.0059 [−0.0103, −0.0023], 8경기 중 7경기에서 최종 모델이 낮음.
- `design-experiments.csv` — 표 3(설계 실험). 앞선 실행들이 보고한 값을 옮긴 것이고 여기서 다시 계산하지 않습니다. 아래 세 줄은 9월 경기 기준이라 31경기 값과 나란히 비교하지 않습니다.
- 실제 경기 운영(2026 월드시리즈 1~5차전, 비공개 발행)
  - 발행한 공 수: 263·341·294·367·255구
  - 예측이 뜬 공 수: 180·0·274·301·157구(4경기 912구). 정의: 발행본에서 공마다 직전 예측 상태가 준비됨이고, 같은 입력으로 공 전에 기록된 것과 짝이 맞은 공. 5차전 장부의 기록 건수(199건)와는 다른 값입니다.
  - 외부 이용자는 없었습니다.
- 전시 부스(11/24): 5차전을 실제 속도로 한 경기 끝까지 재생, 경보 0, 업로드 실패 0. 전날 밤 완주 시험의 공식 판정은 FAIL(판정 대상이 아닌 첫 회차 표본 하나가 판정 창에 들어감).
- 추천대로 던졌을 때의 효과: −0.12~+0.09%p, 0을 포함합니다. 추천이 도움이 된다는 근거는 없습니다. 계산 코드는 보관 중인 원래 레포에 있습니다.
- 설문: `../docs/survey-summary.md` (집계만).

## 한계

- 31경기는 모델을 고르는 과정에서 여러 번 채점했습니다. 그래서 와일드카드 8경기 확인을 따로 했습니다.
- 부트스트랩 구간은 경기 표본의 흔들림만 담고, 학습 seed의 흔들림은 담지 않습니다.
- 검증한 것은 구종 확률입니다. 화면의 목표 위치와 퍼센트 표시는 검증하지 않았습니다.
