## 독립 확인 범위

사용 이력 근거 63개 경로의 메타데이터 바이트/해시와 인용 545행이 일치했다. 이 중 56개는 기준 `522339e`의 Git blob, 7개는 알려진 외부 텍스트 메타데이터다. 20개 과거 OPE(12 P0+8 P1)와 3개 2025 모듈 평가를 구분했다. 원자료 해시는 기존 manifest의 기록일 뿐 이번에 payload를 검증하지 않았다. 현재 저장소 문서가 D87로 갱신돼도 근거 해시는 당시 스냅샷을 가리킨다.

과학 검토는 다음 경계를 확인했다.

- 실제 도달 위치를 의도 목표로 대체하지 않는다. 목표 위치 ARM-A는 식별 보류이며 ARM-B도 자동 활성화하지 않는다.
- 관측 행동 대입·가중치 1로 미지원 사례를 처리해 전체 모집단 효과를 주장하지 않는다. 인과 식별과 수치 overlap을 구분한다.
- 기본적으로 2026 nuisance 적합은 금지한다. 이미 시행된 과거 평가 예외를 소급 위반으로 단정하거나 새 작업 허가로 확대하지 않는다.
- 기존 RE24와 초기 수비 팀의 PA 종료 WE를 분리한다. ARM-B 제안 DR은 정책별 q/v·투구 전 이력·타석 내 재귀와 짝지은 대비를 명시한다.
- 실제 위치로 ABS 경계 투구를 빼지 않는다. 규칙 변화의 가능성과 미측정 효과·스키마를 구분한다.
- 자료 접근 전 과학/수집 계획 등록 → 별도 승인된 격리 스냅샷 → 실제 자료핀을 포함한 최종 실행 등록 → 별도 실행 승인 순서다.

Root는 검토된 두 작성 커밋을 `2c0b3fd`·`1b5c1db`로 통합했다. 이후 변경은 통합 대기 표시 제거, Sol 근거 작성자 표기, 공식 ABS 출처 링크, 준비도 보고서의 검토 상태/링크다. 수치 제안·추정량·실행 설정은 바꾸지 않았다. 최종 소스 식별은 작성 커밋 핀과 통합 파일 핀을 함께 따른다.

이번 작업은 새 수집·parquet 헤더·NPZ/NPY/pickle·모델 payload 열람/해시, fit·추론·OPE·채점을 수행하지 않았다. 문서/JSON만 변경했으므로 새 실험이나 전체 코드 테스트를 실행하지 않았다. JSON 파싱·문서/설정 일치·링크·diff 검증을 사용한다.
