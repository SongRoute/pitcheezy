# 연구 PM 현재 상태

갱신: 2026-11-01 · 범위: 기존 문서의 탐색 안내. 새 자료 열람·fit·재채점·모델 선택·승격을 수행하지 않았다.

## 현재 방향과 정본

[10/31 인계 §2·§5](../../handoffs/CODEX-resume-2026-10-31.md)에 따라 전시 G0는 동결하고 모델 개선은 별도 작업으로 다룬다. **2026 자료를 학습·튜닝·모델 선택에 쓰지 않는다.** 과거 WS 적응 권한을 이번 작업의 실행 허가로 가져오지 않는다.

- 작업·소유권은 [큐 #37](https://github.com/SongRoute/pitcheezy/issues/37)의 전체 최신 댓글과 [절차](../work-queue.md)로 확인한다. 기존 연구자의 파일·결과 범위를 문서 정리로 반환 처리하지 않는다.
- 예측 연구는 [실험 매트릭스](../../ML_EXPERIMENT_MATRIX.md), [연구 인계](../../handoffs/ML-experiments-next-session.md), [결정 D184~D197](../../decisions.md)을 함께 읽는다. 인계의 날짜별 실행 중 문장은 과거 관측이다.
- G15 연구 대조군과 서비스 G0를 구분한다. P48 B1의 [arm C 동결 목록](prospective-2027/arm-C-B1-freeze-list.md)은 예측기 후보 기록이며 정책 식별자 완성·서비스 교체가 아니다(D188). 봉인 결과와 기존 비교군을 덮지 않는다.

## 실행 전에 보존할 조건

- **RS-01/RS-02 열람 경계:** D179의 열람일은 `2026-11-06T00Z`다. 기존 연구 state 끝의 RS-02 봉인 기록은 그 이후 **1회** 사후 as-of 재생 채점과 RS-01 저장소 백업 사본 사용을 정한다. 새 수집·fit·튜닝·선택·OPE·서빙은 포함하지 않는다. 날짜 도달만으로 미충족 등록·소유권·독립 검토 조건이 사라지지 않는다.
- **RS-01 봉인:** D194의 G3+G5 집합과 runner는 불변이다. T_FINAL identity 오류 대응은 향후 등록용이며 봉인 실행에 소급하지 않는다. 과거 종료·오류 기록을 지우지 않는다.
- **트랙 A:** D192는 설계값 확정이며 등록·실자료 실행 승인이 아니다. 지정된 독립 검토·G-CODE·등록·실행 조건을 해당 설계에서 확인한다. D197의 계획 예산 확대 실험은 열지 않으며 설계만 보존한다.
- 새 실자료 작업은 자료 역할·as-of·노출 장부·분할·지표·비교/분모·seed·source/config·예산을 먼저 고정하고 독립 검토한다. [공통 계약](../contracts.md), 봉인/OPE 접근 경계와 [자원 규칙](../resources.md)을 유지한다. 문서 링크는 payload 접근 허가가 아니다.

## 과거 증거의 의미

[변경 전 전체 원문](https://github.com/SongRoute/pitcheezy/blob/9eddc42fa3a9f33c28e1d2d0a1a2585c323215d4/docs/pm/research/state.md)에 fullseason OOF·T_FINAL·K2·RS-01 준비·postseason 회고·RS-02 노출 장부와 이전 체크포인트를 보존한다. EXPOSED DEVELOPMENT를 독립 TEST나 전향 확인으로 바꾸지 않는다. 첫 로컬 수신 전 기록은 실제 투구 전 물리 시각 증명이 아니며, 저장 집계 재현은 원천 라벨·모델·프로필 재계산과 다르다. 과거 연구/서비스 계보와 서로 다른 경기·모델의 분모를 합치지 않는다.

현재 결과 payload·동기화·GPU 점유·새 실험 비용은 이번 정비에서 **미측정**이다. 수치·해시·수용 범위는 원문과 고정 산출물에서 확인한다.
