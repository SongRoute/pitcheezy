# 서비스 PM 상태·실행 큐

갱신: 2026-11-01 · 범위: 현재 전시 안내와 과거 운영 기록의 분리. 새 빌드·배포·프로세스 조작은 하지 않았다.

## 전시 준비의 출발점

[10/31 인계 §2·§5](../../handoffs/CODEX-resume-2026-10-31.md)는 UI-1026 관전 본체와 G0 동결, 11/24 전시 방향을 정한다. 현재 파일·발행 자원 소유권은 [작업큐 #37](https://github.com/SongRoute/pitcheezy/issues/37)의 전체 최신 댓글과 [절차](../work-queue.md)로 확인한다. 기존 Claude 작업과 통합 책임은 명시 인계 없이 가져오지 않는다.

- 모니터 1: 발행기 재생 → v1 파일 → 공개 고정 빌드, 참고 카드 포함.
- 모니터 2: 849843 경기 영상. 풀 중계를 우선하고 공식 클립 체인을 대비한다. 영상 소스 확정 여부는 인계 이후 증거로 확인한다.
- 관람객 폰: QR → 팀원 Cloudflare 호스트의 pitcheezy.com 고정 빌드. 문서에 경로가 있다는 것만으로 DNS·호스트·실기기 연결 완료를 주장하지 않는다.

## 재현 근거와 남은 작업

[전시 고정 빌드 기록](exhibition-build-2026-10-31.md) §2는 보관 피드 발행, §6은 재생·참고 카드 확인 경로다. 빌드 커밋·ZIP SHA·분모·한계는 이 원문에 둔다. 최신 코드로 실행할 때에는 해당 작업의 고정 커밋·환경·빈 포트·새 store/출력 경로를 별도 확인한다. 기록의 명령을 기존 운영 자원에 바로 실행하지 않는다.

10/31 인계의 독립 검토·DOM 스모크 포팅·live-replay 도장 수정·런북·폰 검수는 각 PR/종료 근거로 완료 여부를 대조한다. 이 문서 정비는 그 작업들의 완료 증거가 아니다. 합성 스모크와 보관 피드 재생은 실호스트·폰·공동 연결시험을 대신하지 않는다. 현재 배포·연결·실기기 상태는 **미측정**이다.

## 표시·자료·운영 경계

미지원/확인 중 상태·정정/중복/재연결·표시 게이트를 문서 정리로 바꾸지 않는다. 모델 예측, 추천 정책, 참고용 통계를 구분한다. 과거 fullseason/shadow 집계는 실제 투구 전 예측·추천/WE 정책·팬 화면 성능 증거가 아니며 운영 모델 교체도 아니다. 자료 열람·봉인 결과·2026 학습/튜닝/선택 금지와 [공통 계약](../contracts.md)을 유지한다.

기록기·수집 프로세스에 신호를 보내지 않고 포트·DB·발행기·tmux·SSD는 [자원 규칙](../resources.md)과 실제 소유권을 따른다. 과거 스위치 설정·PID·포트·롤백 커밋을 현재 유효한 값으로 가정하지 않는다. 기존 실행/봉인 원문·실패 증거는 보존한다.
