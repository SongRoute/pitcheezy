## 실행과 두 저장 실패

A5000 서버 **CPU1thread, CUDA사용0**으로 계산했다. GPU0/1은 사용자 배정 의도를 기록했으나 타 compute 프로세스가 관측됐고 소유자는 현재 namespace에서 UNKNOWN이다. 타 프로세스·물리GPU lock을 건드리지 않았고 실제 GPU실험은 소유조정 전 대기다.

1. attempt001: 실제1fit/점수계산 후 provenance 경로 오류, rc1·빈 출력. 점수 열람 전에 국소수정/독립검토했다.
2. attempt002: 동일 설정으로 실제1fit 후 tree.leaves numpy.int64 직렬화 오류, rc1. 완전한 예측parquet/제외원장과 partial metrics를 보존했다.
3. 독립검토한 no-fit 복구: 동일raw17열 prepare-only로 저장키/라벨/입력/지원수/원장을 대사하고 동결확률에서 점수/구간을 재계산했다. 완결된 기존 집계와 정확히 일치했고 **복구 job rc0, 추가fit0**이다. 원래 두 job의 실패를 성공으로 바꾸지 않았다.

누적 실제fit는 **2회(같은 고정후보, 저장실패 재시도)**다. 후보/시드/설정 탐색2회가 아니다. 실제 evaluate_frame 전체 JSON 직렬화와 완전복구 경로 회귀를 추가해 mocked-only 검사의 빠진 경계를 보완했다.
