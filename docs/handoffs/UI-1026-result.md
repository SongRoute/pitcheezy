## 바뀐 것 (디자인 ①~⑧)

- ① 머리: 뒤로 · `CHC 0 : 2 SD` · 상태 표시 / 회차 버튼 · 이닝별 점수표(1~9·R, 지금 회 강조, 없는 칸은 빈칸) / 타자 | 카운트·주자·아웃 | 투수(타자는 늘 왼쪽). 360px 미만과 이름이 칸을 넘을 때는 성만. 공수 교대는 한 줄, 경기 전은 `HH:MM 시작`, 경기 종료는 최종 점수와 `경기 종료`(3줄 없음). 점수표를 누르면 지금의 이닝별 기록 시트.
- ② 존: 회색 창 없이 선만, 추천 네모 1 채움·2 연한 채움·3 흰 바탕 실선, 같은 칸은 가장 높은 순위 모양. 실제 투구는 무채색 G1(볼/스트라이크·파울/타격, `description`으로 나눔, 없으면 '결과 미확인' 점선), 그 타석 가장 최근 공에만 바깥 링. 같은 좌표에 결과가 다른 공은 같은 중심의 쐐기로 나누고 번호는 결과별 배지로. 존 크기·좌표 반전·가장자리 화살표·groupTargets는 그대로(존 상자 폭이 기준과 같은 137/135/95/100px).
- ③ 추천: 구분선 한 줄 세 칸(순위 네모+구종), 보여 줄 수 없으면 세 칸 `—`(이유는 화면 읽기용으로만), 연결 끊김은 `마지막으로 받은 추천 · N구`와 흐리게.
- ④ 이번 타석: 한 줄 + `펼치기 ▾`, 펼치면 그 자리에서 다음 공(또는 타석 결과) → 최근 공부터.
- ⑤ 뺀 것: 스포일러·한계 문구, 경기 흐름 칸, 직전 타석 카드, 다음 타자 줄. 승리확률 시트는 내용·조건 그대로 두고 `기록` 시트 머리의 `승리확률`에서 연다(디자인 미정, 메인 카드 없음).
- ⑥ 상태: 오른쪽 위 표시 하나 + 풍선(제목·지금 쓰는 문장·연결 문제일 때 `다시 확인`). 우선순위 연결 문제 → 자료 늦음 → 추천 바뀜(서버 정정 또는 화면 자체 D1 감지) → 나머지. 종료는 표시 없음.
- ⑦ 하단 바: 꽉 찬 어두운 바, 선 아이콘 4개.
- ⑧ 시트 틀 C: 반 → 전체(손잡이 끌기, 손잡이 버튼 Enter/Space, 본문 스크롤), 모든 폭에서 어둡게 덮는 모달, 포커스 가둠·Esc·포커스 복귀. 추천 자세히(R1), 투구 상세(P2, ‹ ›, 창이 선택한 공을 담도록 넓어짐), 선수(L1, 타자|투수 탭, 투수 탭 오늘 구종), 구종(G3, 반=표만·전체=위치 지도). 미정 시트(경기 기록·이닝별·타석 선택·승리확률·기준과 한계)는 틀만 바꾸고 내용 그대로. 경기 목록은 바꾸지 않았다(목록 정보 시트는 예전 틀 유지).

## 디자인 가정과 구현 해석

★ 표시 1번만 디자인 가정으로 남는다(Song 확인 거리). 나머지는 범위 안 구현 해석으로 Root 검토에서 수용됐다.

1. ★(다음 디자인 때 확인할 거리, 막는 문제 아님) `waiting`·`ledger_unavailable`은 `확인 중` 모양(회색 점)에 서버 문구를, `unavailable`은 `추천 없음` 모양(빈 원)에 서버 문구를 쓴다. 공수 교대(`waiting/between_innings`)는 그림 09대로 `라이브`.
2. 디자인 문서의 "정정(Receipt.corrected) → 추천 바뀜"은 추천이 바뀐 경우(display_state.correction, 화면 자체 D1 감지)로 구현했다. 투구 기록 자체의 정정은 이번 타석 목록과 투구 시트의 `정정됨` 표시로 남는다.
3. 그림 01/12/13은 가장 최근 공에 링이 없고 그림 14와 검토 지시는 링을 요구한다. 문서 문구("방금 던진 공")와 지시에 따라 그 타석 가장 최근 공에 링을 단다.
4. 그림 13·14는 한 타석의 모든 공을 존에 그린다. 예전 "최근 3구" 제한과 `전체 보기`를 없앴다.
5. `오늘 첫 타석`은 첫 타석을 증명하는 자료가 없어 `오늘 0타수 0안타`처럼 숫자로 보인다. 공수 교대 다음 첫 타자도 증명된 자료가 없어 `—`(UI-data-gaps.md에 두 줄 추가).
6. 경기 종료 머리는 최종 점수를 보이고, 메인 본문은 지금처럼 선택된 지난 공(처음엔 1구)을 보여 준다.
7. 팀 짧은 이름은 기존 규칙(`SD` → 샌디에이고)이라 선수 시트에 `파드리스` 대신 `샌디에이고`가 보인다.
8. 실시간 경기에서 추천 입구(칸·자세히·하단 추천)는 지난 공을 봤더라도 지금 추천을 연다. 지난 공 시트를 열어도 상태 표시는 바뀌지 않는다(예전 `딜레이` 표시 규칙 제거).
