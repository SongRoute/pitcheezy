# 최소 추천 서비스 실행 범위 — 2026-09-21

사용자의 남은 사용량과 오늘의 목표에 맞춰 기존 로드맵을 축소한다. 완료 기준은 실제 요청에서 구종 추천을 반환하는 로컬 API, 기존 예측 성능의 재현, 작은 정책 비교 결과의 저장이다. 독립적인 정책 효과 검증은 후속 작업으로 남긴다.

- Astra: 설계와 코드. Sol: 테스트, 실제 실행, 결과 저장.
- 승인된 2023–2025 자료, 기존 가상환경, T7 Shield만 사용한다. 신규 신경망 학습과 추가 설정 탐색은 하지 않는다.
- 고정 모델: 2025 continuous_h0의 seed42–46 MLP와 보정된 빈도 기준선의 기존 혼합. 타자 연속 성향·신뢰도와 주자·아웃·카운트·점수·이닝·홈원정 유지. 개인 ID는 프로필·구종·분포 조회용이다.
- 지원 행동: TRAIN에서 50구 이상 관측된 선정 투수의 구종. 목표 위치는 추천하지 않는다. 현재 투구의 실제 물리값 대신 기존 TRAIN 조건부 400개 벡터를 평균낸다.
- WIN/진루/RE 가치만 2025 fold TRAIN으로 가볍게 적합한다. WE의 DEV Brier가 TRAIN 상수 확률보다 좋아야 다음 단계로 진행한다. 이는 최소 점검이고 보정·진루 품질의 포괄 검증은 아니다.
- 정책 비교: RE/WE × 첫 구만 선택 후 빈도 정책 복귀/전체 타석 계획. 모든 비교는 같은 입력, 행동, 예측 확률 및 TRAIN 구종 빈도 기준선을 쓴다.
- 사례: 적격 DEV 타석의 0–0 첫 구에서 투수·경기당 하나. 5회 이후·2점차 이내·주자 있음, 5회 이후, 그 외 순으로 우선한다. 투수당 날짜순 최대 12경기. 선정은 투구 전 상황만 사용하나 기존 적격 타석 필터의 사후 선택 한계는 남는다.
- 정책 평가는 같은 혼합 예측기 및 빈도 예측기로 각각 계산한다. 빈도 예측기는 같은 TRAIN/WE를 공유하므로 독립 평가기가 아니다. 경기 bootstrap 2,000회 구간은 고정 모델에서의 기술적 요약이며 다중 비교 보정·인과적 승률 검증이 아니다.
- 관측 예측 성능은 기존 2025 DEV 5,048구 결과를 재계산한다. 실제 서비스 추론을 일부 관측 구종에 재적용하여 저장된 확률과 최대 오차 1e-5 이내인지 검사한다. 서비스의 불가능한 병살 확률 제거·재정규화는 예측 점수 원본과 구분한다.
- 서비스는 역사 모델과 TRAIN 프로필 스냅샷을 제공한다. 실시간 데이터 연동·목표 위치·추천 안정성·신규 독립 정책 평가·재학습 자동화는 이번 완료 기준에 포함하지 않는다.

실패하면 구현 오류만 수정한다. 평가 결과가 불리하다는 이유로 사례·모델·목적을 다시 선택하지 않는다. 결과와 한계를 함께 저장한다.
