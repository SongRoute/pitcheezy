## 관측 자료에서 확인한 예측 성능

낮을수록 좋다. 투구 결과 Brier는 10개 결과의 제곱 오차를 합산한 값이다.

| 평가 | N | Log loss | Brier |
|---|---:|---:|---:|
| 투구 전: 구종별 도달 위치 분포를 적분한 모델 | 2,365 | 1.45567 | 0.72291 |
| 카운트·좌우 빈도 기준선 | 2,365 | 1.45520 | 0.72157 |
| 실제 현재 도달 위치를 아는 **사후 진단** | 2,365 | 1.05878 | 0.53759 |

27경기 단위 짝지은 bootstrap 2,000회에서 Full−기준선 log loss 차이는
**+0.00047, 95% 구간 [−0.00730, +0.00898]**다. 개선 근거가 없다.
Brier 차이도 +0.00135 [−0.00354, +0.00683]로 0을 포함한다.
이 구간은 경기 표본 변동만 나타내며 모델 학습·교란·선택 편향을 모두 포함하지 않는다.

별도로 실제 경기 승패를 학습한 WE continuation은 이후 1,161경기의 30,000개
타석 시작 상태에서 log loss **0.45909**, 이진 Brier **0.15394**였다.
공급자 WE를 정답이나 입력으로 사용하지 않았다. 한 경기의 승패 라벨은 그 경기의 여러
상태에 반복되므로 30,000개 독립 경기라는 뜻은 아니다.

## 실제 타석의 첫 추천

사용자 추가 요청의 주자·아웃·점수차·홈/원정은 이미 결과 모델과 WE에 포함되어 있다.
이닝·초/말, 카운트, 타자 과거 통계, 직전 구종도 사용한다.
첫 버전의 타자 ID 임베딩은 이후 **유형 기반 모델로 바꾸는 별도 실험**을 진행한다.

대표 사례는 성능을 보고 고르지 않고 선수별 최초 적격 DEV 타석으로 정했다.

측정치는 추천 시 미리 사용하지 않는다. 타자의 실제 의도된 목표 위치가 기록된 자료는 없다.

경기당 사전 고정 seed로 최대 3타석, **81타석/27경기**에서 모델 내부 기준 정책 대비

기준 정책은 학습 기간 구종 사용 비중 × 지원 목표 셀 균등 분포다.
**동일 모델을 최적화한 뒤 동일 모델로 평가한 값이므로 실제 승률 개선의 증거가 아니다.**
한 구만 최적화한 뒤 기준 정책으로 돌아가는 myopic과 첫 추천이 달랐던 비율은 55.6%였다.

## 제구 민감도와 현재 판단

목표 주변 독립 Gaussian 제구 오차 σ=0.30ft를 가정했다. 0.20/0.45ft로 바꾸었을 때
야마모토의 첫 추천은 유지됐지만, 글래스노우는 σ=0.45ft에서
CU (0.00, 3.25) → CU (−0.70, 2.45)ft로 이동했다. 목표 추천의 제구 의존성을 확인했다.

현재 판단은 **계산 경로는 검증됐고, 예측·제구 모델 개선이 우선**이라는 것이다.
사후 위치 조건부 성능이 좋아도 투구 전 성능으로 이어지지 않았으므로 더 복잡한 정책
최적화가 먼저라고 판단할 근거는 없다. 현재 도달 위치 혼합은 카운트 조건을 사용하지 않아
이를 추가하는 것이 다음 가설 중 하나다. DEV를 보고 고른 변경은 후속 탐색이라고 표시한다.
