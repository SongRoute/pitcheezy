# B002 TRAIN 선택과 조건부 DEV 실행

2026-09-23. 사용자의 ‘다음으로’ 지시에 따라 `901d3ed`에서 시작한다. 설계는 `d75fe92`의 `configs/EXP-B-PAHISTORY-002.json` 및 `docs/contracts/B-next-experiment-v2.md`를 그대로 따른다. 기존 config의 `frozen_not_run`은 설계 당시 상태이며 실제 실행 상태는 이 문서와 별도 결과에 기록한다.

## 실행 순서와 판정

1. 구현과 합성 검사를 검토하고 소스 커밋을 먼저 만든다.
2. 동일한 4월 TRAIN만 읽어 두 시간순 블록의 모든 고정 alpha를 비교한다. pooled NLL을 투구 수로 가중하고, 1e-10 이내 동률은 작은 alpha를 고른다. pooled 개선과 두 블록 각각 비악화를 함께 만족하지 못하면 alpha=0이다.
3. 전체 TRAIN에 한 번 적합한 최종 표의 저장/복원과 정확한 부모 복귀를 확인하고, 선택 결과·체크포인트·hash를 커밋한다.
4. alpha=0이면 새 DEV 계산을 생략한다. nonzero일 때만 커밋된 선택을 검증한 뒤 동일한 노출된 7월 DEV를 한 번 평가한다. 결과에 따른 alpha 재선택이나 채택은 하지 않는다.

첫 공에는 과거 정보가 없으므로 부모 분포를 그대로 사용한다. 현재 구종은 알려진 행동이라는 조건이며 현재 공의 위치·속도·결과는 특징이 아니다. 검증 블록 내의 직전 공 구종은 같은 타석에서 이미 관측된 정보로만 쓴다. 미래 공이나 다른 타석에서 이력을 가져오지 않는다. 적합 표는 해당 블록보다 엄격히 앞선 경기만 사용한다.

기존의 완료/지원 타석 필터를 유지하므로 결과는 그 조건을 만족한 작은 코호트에 한정된다. 이미 노출된 TRAIN/DEV에 기반해 설계한 탐색 실험이며 독립적인 최종 확인이나 정책 효과 평가가 아니다. 추천 서비스·가치 계약·C 이닝 결과는 이번 후보로 바꾸지 않는다. CV, 2026 경기 자료, 최종 평가셋, S2 확장은 제외한다.

## 역할과 자원

루트는 Astra 역할로 고정 사양·누수 경계·선택 결과·채택 제한을 검토한다(정확한 런타임 모델 ID는 미노출). `b002_implementation`에 `gpt-6-sol`, `medium`을 명시해 새 실행 스크립트와 합성 검사만 위임했다. 전체 대화 상속과 재귀 위임은 없다. 토큰/비용은 도구에서 제공되지 않아 미측정이다. 기존 처리자료·계층 빈도 모형·평가 함수를 재사용하고 큰 학습을 실행하지 않는다.
