- 16:10 확인: 8771 `/api/watch/849843/setup` 실제 응답은 39행/좌표27/기권12. 출처는 `9f62b7781b188d5a7abaad9018b09ead2413c1c2`, `docs/results/mlb_p0/game_849843_intent_v0.jsonl`, SHA256 `12c11e1d2976992d39a1c4e126ba192291cd6f90edd7d82c6a9be3412dd17d0b`. 이후 최종 커밋1687c1e의 동일 경로를 GitHub API로 읽어 SHA256 일치·39행/좌표27을 독립 확인했다. 기존 원본·핀을 임의 교체하지 않는다.
