During endpoint feasibility inspection before the freeze, a selected-game schedule sample displaying a final score was printed; the fixed chronological rule and committed selection did not use it. ## Bounded lineup correction (v2)

The first supplement counted every completed play-by-play item as a batting turn. That fails when a caught stealing ends the half inning during a batter's unfinished PA: in game `777063`, Marcelo Mayer was at the plate for the caught stealing at `atBatIndex=25` and batted again at index 32. Game `777217` has the same type of non-PA item. The first supplement also treated observed batting stance as a fixed hitter attribute; game `777227` has one batter observed from both sides against different pitchers. These issues did not affect the original roster screen or decision selection.

`lineup_supplement_v2.json` preserves the first supplement and uses only complete **batter** PAs before the decision, skipping caught stealing/pickoff non-PA items. It applies a prior substitution only when the feed supplies a batting slot, new player ID, and replaced player ID that match the reconstructed slot; game `777126` records Edmundo Sosa replacing Alec Bohm in slot 4. It also inspects the current PA only through the first pitch and abstains if any nonpitching substitution precedes that pitch. No current or later PA outcome is used. This produced five verified ordered hitter-ID sets (`777094`, `777126`, `777143`, `777217`, `777227`) from the same six cached feeds, with zero new requests. Every slot's `stand_for_substitute` remains null because observed stance against earlier pitchers does not establish stance against a proposed replacement.

Game `777063`, the sole model-supported keep pitcher, remains null. At the selected PA (`atBatIndex=48`), Tanner Banks replaces Zack Wheeler, then Romy Gonzalez pinch-hits for Mayer before the first pitch. That batter change follows the pitching decision in the recorded action order. The decision-time counterfactual hitter is therefore unresolved even though the earlier batting slots can be traced. The v2 output records `current_pa_pre_first_pitch_nonpitching_substitution` as the missing reason. Actual replacement eligibility is still unverified in all six games. V2 artifacts: SSD `C-ROSTER-001/lineup_supplement_v2.json`, its manifest, and committed `results/EXP-C-ROSTER-001/lineup_supplement_v2_manifest.json`.

For game `777063` only, make a new `decision_anchor_777063.json` supplement at the event immediately **before** the first logged pitching-substitution action in selected PA `777063:49:1`. The event's structured timestamp/index and the prior complete PA sequence bound the evidence. This is the same frozen observed substitution, not a new game or outcome-based case selection. Keep pitcher 554430 (Zack Wheeler) comes from the frozen A/C packet. The announced next batter is the previously verified slot holder before any current-PA offensive substitution. Record later pinch-hitting only as an excluded audit event; never substitute that batter into the anchor lineup.

Build ordered slots from earlier complete batter PAs, excluding caught stealing or pickoff plays that did not complete a batter PA. Apply only structured substitution actions in earlier plays with verified slot and replaced/new IDs. For each slot, accept a `stand_vs_keep` only if that same batter has a recorded matchup against keep pitcher 554430 with a completed batter PA **before** the pitching-substitution event; preserve the supporting play index and observed stance. If any announced slot or its keep matchup stance is unverified, emit `lineup_as_of:null` with a machine-readable reason and do not offer a ready input to the inning evaluator.

First future cutoff check: every batting/order/stance source play index must be strictly less than the current PA's `atBatIndex=48`; the current PA may contribute only action fields through the pitching-substitution event. Second cutoff check: every source play end time must be no later than the pitching action start time, and each inspected current-PA action must precede or equal that action index/time. Reject missing, inconsistent, or later timestamps. The game state must be independently consistent between the selected first-pitch Statcast state and the pitching-change action count/scores; bases and outs must match the final prior-half transition or remain null with a reason. No later current-PA pitch/result, pinch-hit outcome, selected-game final boxscore, or future lineup is a feature.

The anchor is a conditional keep scenario with the opponent's announced lineup held fixed after the pitcher decision. It does not establish what the opponent would actually have done had Wheeler stayed, manager availability, replacement eligibility, causal or policy value.
