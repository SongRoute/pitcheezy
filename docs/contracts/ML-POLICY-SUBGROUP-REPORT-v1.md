# Descriptive policy and RL subgroup reports

This additive report closes the matrix's group reporting requirement using sealed artifacts. It does not modify policy preparation, fit, June selection, DEV stages or inference rules. No real-data execution is claimed by implementation or synthetic tests.

`report_ml_policy_groups.py --policy-run <policy run> --stage p0|dev-control|dev-candidate --output <new report directory>` reports P0's blend and DEV results or one policy DEV world. Add `--rl-run <RL run>` to a DEV command to include the matching completed RL evaluation. The output must be outside both input run trees and must not already exist. No pickle or model checkpoint is deserialized. The command verifies sealed stage file families and hashes, preparation-bound request/role metadata, execution identities, exact PA key/game ordering, and byte-equivalent RL planner arrays against the selected P2/P3 parent arrays. Every consumed artifact and reporting source is hashed in the new manifest; upstream model provenance remains represented by its sealed artifacts rather than fresh model inference.

All reports include overall, frozen TRAIN-role and pitcher groups. TRAIN role is a fixed player classification, not actual starter/reliever role in each observed game. P0 uses the exact archived action vocabulary and labels, counts requested pitches, supported requests, supported observed labels and unknown-pitcher fallback. BC and frequency conditional action NLL use the same supported observed-label subset. Their full-request NLL is null whenever any requested observed label is unsupported; missing labels are never dropped from denominators.

PA reports distinguish all original requested starts, preparation-selected starts, execution-selected prefix, starts outside that prefix, and supported/unsupported selected starts. Unsupported reasons are reported only where support was assessed. Neither unselected nor unsupported starts receive imputed WE. For each policy and group, report mean original defensive WE and rollout truncation rate on the same supported starts. Policy paired contrasts are P1−P0, P2−P1, P3−P2; RL contrasts are IQL−planner, CQL−planner, IQL−NNBC, CQL−NNBC. Archived RL seed policies receive descriptive means and truncation rates alongside ensembles. All differences use identical ordered PA/MC arrays.

There are no new confidence intervals, tests, N/G/P/R decisions, subgroup promotion rules or causal/OPE claims. Empty groups' values are null. Small-group estimates are explicitly descriptive. The primary control-world inference and candidate-world sensitivity retain their original interpretation; group reporting does not create another success family. Preserved rollout values carry the original truncation-tail assumptions; these group means do not establish untruncated improvement.
