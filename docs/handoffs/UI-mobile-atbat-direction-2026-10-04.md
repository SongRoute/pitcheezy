## 사용자가 정한 방향

- 실경기 중계를 보면서 옆에서 참고하는 모바일 웹이다.
- **현재 타석의 핵심 정보는 스크롤 없이 한 화면**에서 읽는다.
- 필수 텍스트는 유지하고 아이콘·그림·숫자로 우선 전달한다. 설명문·선수의 긴 기록은 한 번 선택한 뒤 제공한다.
- 실시간은 새 공·카운트·주자·투타자 정보를 자동 갱신한다. 과거 경기는 사용자가 눌러 다음 정보로 이동한다.
- 첨부 네이버 스포츠 문자중계 화면은 참고다. 넓은 경기장 배경·별도 선수 카드·타석 로그를 세로로 쌓는 구조를 그대로 복사하지 않는다.
- 연구는 병렬로 계속한다. 유의미한 결과는 개선 폭·여러 시드/범위에서의 일관성·학습 비용·검증 한계를 함께 보고한다. 단순 학습 종료를 성능 향상으로 알리지 않는다.

## 사용자 선택: 존 중심 + 타석 선택 + 후보 3개 비교

10/4 후속 피드백으로 존 중심을 선택했다. 홈에서 경기 자체를 선택하므로 경기 안에 실시간/과거 경기 전환 버튼을 반복하지 않는다. 상단은 **이 경기의 타석 선택**으로 바꾼다. 후보 1·2·3은 동시에 수치 비교하고, 공격 팀의 상징색을 점수판·타자·주자 표시에 일관되게 쓴다. 상세는 한 번 선택해 열고 충분한 정보를 안쪽 스크롤로 읽는다.

| 영역 | 항상 보이는 것 | 한 번 선택하면 |
|---|---|---|
| 상단 | 경기 내 타석 선택, 팀·점수·회차·공수·B/S/O·주자 다이아몬드 | 해당 경기의 타석 목록, 이닝별 점수, 주자·경기 기록 |
| 대결 | 투수·타자 이름, 좌/우투·좌/우타 | 선수 시즌/당일 기록, 구종 흐름 |
| 중앙 | 큰 스트라이크존, 번호가 붙은 현재 타석 실제 투구, 다음 공 추천 구역 | 선택한 투구의 구종·구속·결과, 추천과 비교 |

논의 시안에서 `추천 중심` 대안은 제거했다. 존에는 후보 ①②③의 점선 구역과 실제 투구의 채워진 번호 원을 구분한다. 후보들이 같은 구역을 제안하면 번호를 함께 표시한다.

### 수치 비교의 의미

- 현재 서비스 응답 `candidate.detail.probability`는 **정책 선택 비중**이다. 구종 실제 예측 확률·성공 확률·자신감·기대 실점 감소로 이름을 바꾸지 않는다.
- 기본 화면은 실제 상위 3개 비중을 그대로 표시한다. 합계를 100%로 재정규화하지 않는다. 상세에는 `그 외 구종`을 포함해 전체 비중을 설명한다.
- 상세 비교는 후보 정책 비중, `reference_probability` 기준 정책 비중, 두 값의 차이(%p)를 제공한다. 차이를 성능 향상으로 해석하지 않는다.
- 위치는 기존 실제 투구 분포 근사다. 구종 선택 비중을 해당 구역 명중 확률로 표시하지 않는다. 정책 우위·CV 높이·9구역 채택 판정은 그대로다.

### 팀 색과 상세 정보

- CHC의 파랑/빨강, SD의 갈색/금색 계열로 팀 정체성을 표현한다. 공격 팀 영역의 배경·하단 강조와 타자 표식에 반영하고 `공격` 및 ▲/▼도 함께 표시한다. 추천/실제 표식의 의미와 팀 색의 의미는 분리한다.
- 상세 헤더·닫기 버튼은 고정하고 본문만 스크롤한다. 후보 비교·해당 공 직전 상황·위치 의미·한계, 실제 투구 구종/구속/좌표/결과, 당일 확인된 선수 구종 구성과 투구 기록, 이닝별 점수·사건·승리 추정 변화를 제공한다.
- 시즌 통계·상대 전적·주자 이름·수비 배치 등 미연결 값은 임의로 채우지 않는다. 확인된 현재 경기 자료부터 풍부하게 제공하고 나머지는 실제 데이터 연결 후 추가한다.

## 갱신·탐색 규칙

1. 실시간 기본 화면: 투구 전 추천 → 피드 수신 뒤 결과를 짧게 표시 → 다음 공 대기, 타석 종료 시 새 타자로 자동 전환. 실제 수신 전에는 결과·카운트를 추측하지 않는다. 중복·늦게 도착한 응답으로 과거 상태가 덮이지 않아야 한다.
2. 상단 타석 목록은 진행 중인 경기에서도 이전 타석을 고를 수 있다. 선택한 타석과 당시 점수·카운트는 고정하고, 실제 수신 위치는 별도로 계속 갱신한다. `현재로`를 누르면 최신 도착 시점으로 돌아가 자동 갱신을 재개한다. 아직 시작하지 않은 미래 타석은 목록에 넣지 않는다.
3. 상세를 읽는 동안 본문과 그 기준 시점은 고정한다. 새 공은 `새 공 도착 · 현재 타석으로` 알림만 제공한다. 현재 타석에서 연 상세를 닫으면 최신으로 복귀하고, 지난 타석에서 연 상세를 닫으면 읽던 지난 타석을 유지한다.
4. 홈에서 종료된 경기를 선택했거나 진행 중 경기의 지난 타석을 탐색하는 경우 `실제 투구 공개` → `다음 공`으로 수동 진행한다. 공개 전 결과·실제 구종·좌표·결과를 암시하는 상태/사유를 숨긴다. 종료된 경기는 자동으로 다음 공을 공개하지 않는다. 종료 경기에는 `현재로` 버튼이 필요 없다.
5. 상태와 시간을 숨기지 않는다. 정상/지연/연결 끊김/이닝 교대를 짧은 문구와 표식으로 구분한다. 방송보다 앞선 정보 노출을 줄이기 위한 지연 맞추기는 상태 영역을 한 번 눌러 조절한다. 타이머만으로 실제 중계 동기화가 됐다고 주장하지 않는다.
6. 추천 미지원이면 존과 실제 타석 정보는 유지하고 `추천 없음`과 이유를 제공한다. 오래된 다른 공의 추천을 현재 추천처럼 남기지 않는다.
7. 10구 이상 긴 타석에서도 본 화면 높이를 늘리지 않는다. 최근 투구와 `전체 n구` 진입을 유지하고 전체 목록은 상세에 둔다.
8. 아이콘만으로 뜻이 모호한 추천/실제/추정·지연은 짧은 글자를 함께 쓴다. 색만으로 구분하지 않고 점선·번호·기호도 사용한다. 승리 추정과 추천 성공확률을 혼동시키지 않는다.
9. CV는현재확보된과거경기자료의가로위치만 공개후 표시한다. 실시간CV동작이나 의도/높이/9구역검증을 시안으로 암시하지 않는다.
