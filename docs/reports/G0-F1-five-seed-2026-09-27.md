## 해석·협업 경계

Claude Fable 5.1은 COOP-003 초기 초안을 작성했으나 세션 사용 한도로 자체 검사·계약을 완료하지 못했다. Claude Opus 5.5의 초기 독립 구현 검토 시도도 사용 한도로 끝났으며 **그 시도는 완료된 검토가 아니다**. 이후 GPT-6 Astra가 worker/scorer와 과학적 소스 검토를, GPT-6 Sol이 helper/supervisor 보완·합성 검사·단일 실행 큐를, 총괄 Codex가 계약·등록·통합을 맡았다. 등록 시 합성 검사 55개와 기존 C1 검사 14개, 실행 전 전체 검사 252개 통과는 코드 검증이다. 결과 배열에 대한 Astra의 독립 감사도 완료됐으며, 574개 고유 해시 경로와 18개 비용 기록에 차단 사항이 없었다. 한도 해제 후 Opus 5.5의 결과·문서 검토가 완료됐다. 당시 갱신 전 보고서의 미측정 표기를 차단 사항으로 지적해 이 최종 결과로 교체했고, 시계 교정의 측정 경계와 pitcher/batter volume 구분도 명시했다. 이는 문서·계산 검토이며 독립 예측 확인은 아니다.

F1은 이전에 노출된 동일 Cpanel DEV의 328경기·12,334구에서 얻은 개발 안정성 신호다. `independent_confirmation: null`, `held_out_confirmation: false`, `policy_effect: null`이다. Masked arm은 기존 17개 batter context 채널 묶음만 제거했고 H5 이력에는 타자 관련 신호가 남아 있다. 개별 채널의 원인 효과, 전체 MLB 일반화, 실제 정책 효과, 실경기 성과는 평가하지 않았다. 조건부 bootstrap은 학습·보정·선택 불확실성을 포함하지 않는다. 구조적으로 비어 있는 R 그룹을 보간하거나 확인 완료로 취급하지 않는다.

Opus의 동일 세션 재검토(attempt-003)는 **RESOLVED — no residual blockers**로 종료됐고 총괄이 수락했다. [원검토·재검토 기록](../reviews/COOP-004-Opus-5.5-result-review.md).
