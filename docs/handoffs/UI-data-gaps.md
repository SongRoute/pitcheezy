# 화면에 비어 있는 정보 — 향후 요청 목록

화면 시안을 정하면서 "—"나 "정보 없음"으로 보인 항목을 모은다. 새로 발견하면 아래에 한 줄씩 더한다.
근거는 재생 미리보기(실제 경기 849843 앞 65구)와 공개 화면 코드(`apps/observer/web/src/service`).
**실제 WS 발행에서 채워지는지는 확인하지 않았다(미측정).** 요청 전에 발행 파일로 먼저 확인한다.

## A. 계약(rev3)에 칸은 있으나 재생 자료에서 비어 있음 — 발행기가 채우는지 확인

| 항목 | 화면 위치 | 지금 표시 | 계약 필드 |
|---|---|---|---|
| 등번호 | 선수 시트 | `#–` / `—` | `jersey` |
| 경기 전 시즌 기록 AVG·OPS / ERA | 선수 시트, 타석 줄 | `AVG – · OPS –`, `ERA –` | `pregame.players[id]` era·avg·ops |
| 투수 자책 | 투수 오늘 기록 | `–자책` | boxscore `earned_runs` |
| 실책(E) | 이닝별 점수표 | `–` | teams `errors` |
| 경기장 | 경기 정보 | `경기장 정보 없음` | `venue` |
| 회전수·익스텐션 | 투구 상세 | `—` | `tracking.spin_rate_rpm`, `extension_feet` |
| 타구 속도·발사각·비거리 | 투구 상세(타격 공) | `—` | `tracking.exit_velocity_mph`, `launch_angle_deg`, `distance_feet` |
| 현재 승리확률 | 승리확률 시트 | `현재 승리확률 정보 없음` | timeline 승리확률 |

## B. 아직 연결되지 않은 기능·자료 — 새로 요청하거나 만들어야 함

| 항목 | 화면 위치 | 지금 문구 |
|---|---|---|
| 시즌별 구종 사용률·헛스윙률·피xwOBA | 구종 시트 | "아직 연결되지 않았어요" |
| 성분별 책임 분해·기대실점·타구 예상 결과 | 경기 기록 › 분석, 직전 타석 | "아직 연결되지 않았어요" |
| 공수 교대 중 다음 반 이닝 첫 타자(10/27 구현 중 발견) | 머리 3줄 공수 교대 안내 | `첫 타자 —` (`current_context.next_batters`가 다음 반 이닝 기준이라는 보장이 계약에 없음) |
| 타자 "오늘 첫 타석" 여부(10/27 구현 중 발견) | 머리 3줄 타자 칸 | `오늘 0타수 0안타` (첫 타석을 증명하는 필드가 없어 숫자만) |

## C. 상황에 따라 비는 값(정상 동작, 요청 대상 아님)

라인업·박스·진행 정보 없음(경기 전), 타석 방향·타자 미확인(교체 직후), 위치 정보 없음(좌표 없는 공).
