# 관전 화면 v3 (ui/v3)

2026-10 UI 명세(모바일 메인·존·이번 타석 목록·PC 4묶음·선수 정규/포스트 비교·상세 6종·값 표시 원칙)를 구현한 두 번째 화면 세트.
데이터 계층은 손대지 않는다: `src/service/api.ts`·`publish.ts`·`model.ts`를 그대로 쓰고, 공개 발행 파일 v1만 읽는다.

## 켜고 끄기

| 빌드 | 명령 | 내용 |
|---|---|---|
| 기존 화면 (공개) | `npm run build:public` | 바뀐 것 없음. `.env.public` |
| v3 화면 (공개) | `npm run build:v3` → `dist-v3/` | `.env.v3` (`VITE_UI=v3`, 시안 고정값 `VITE_V3_*`) |
| v3 미리보기 | `npm run build:preview` → `dist-preview/` | v3 + 픽스처 경기 재생 + 시안 설정 탭. 공개용 아님 |

`VITE_UI=v3`이면 vite가 진입점을 `src/v3/main.tsx`로 바꾼다. 그래서 v3 묶음에는 기존 화면과 그 스타일이 들어가지 않고,
기존 묶음에는 v3가 들어가지 않는다.

## 시안 (options.ts)

| 키 | 값 | 명세 항목 |
|---|---|---|
| `zone` | A 모두 번호 / B 직전만 번호 / C 번호는 오른쪽 라벨 | §3 투구 점의 투명도·크기·번호 |
| `list` | row 가로 한 줄 / stack 여러 줄 / side 존 옆 | §3 목록 배치 |
| `stats` | table 표 / card 나란한 카드 | §5 정규·포스트 비교 |
| `density` | full 기본 / lite 필수만 | 정보량 |
| `view` | catcher 포수 쪽 / pitcher 투수 쪽 | 존 시점 (아래 '결정 필요') |

공개 빌드는 `.env.v3`의 값으로 고정되고 페이지 주소로 바뀌지 않는다. 미리보기 빌드만 `?zone=&list=…`와 화면 오른쪽 탭으로 바꿀 수 있다.

## 미리보기 재생 (replay/)

실제 경기 849843(첫 65구, `tests/fixtures/service-849843.json`)을 한 공씩 잘라 라이브 게임 파일(game_pk 990003)로 만든다.
페이지 안에서 `fetch`의 `v1/*.json`만 대신 응답하므로 실제 읽기 경로(순번, 서버 시각, 지연 판정)가 그대로 돈다.
확인 중·자료 늦음·연결 끊김·정정·추천 없음은 일부러 넣은 예시 상태다(`synthetic` 표시). 주소로 시작 지점을 줄 수 있다:
`?game=990003&step=9&play=0&net=stall`.

## 지키는 규칙 (기존 화면과 같음)

- 발행 순번이 뒤로 가면 버린다, 서버 시각으로만 지연을 판단한다 (api.ts/publish.ts 그대로)
- `display_state.recommendation_shown=false`면 후보를 그리지 않는다
- 확인 중인 공은 위치·구종을 비우고 추천과 짝짓지 않는다
- 추천이 바뀌면 조용히 바꾸지 않고 "이전: …"을 남긴다 (D1)
- 없는 값은 `—`, 예시 숫자를 채우지 않는다. 비중은 "구종 선택 비중"이며 성공 확률이 아니다

## 결정 필요

- 승리확률·정규/포스트 분리 기록·회전수 등은 발행 파일 v1에 없다 → 자리만 두고 `—`.
