## 팬 이해 평가 준비

자동 브라우저 통과를 팬 이해로 세지 않는다. 팬에게 먼저 추천 화면에서 다음 공과 이미 던진 공을 구분하게 하고, 3구 비교에서 실제 구종과 저장 추천 구종을 각각 말하게 한다. 이어 `+1.20%p`가 실제 추천 효과/선수 책임인지 묻고, 교체 직전 화면이 실제 교체 효과를 제공하는지 답하게 한다. 판정 기준은 네 과제 모두 근거 위치를 가리켜 맞게 설명하고, 실제/추정/미측정을 섞지 않는 것이다. 정답률·소요 시간·혼동 지점을 별도로 기록해야 하며 아직 참가자 검사는 없다.

C 근거 감사 결과 동일 상태에서 지원되는 유지/교체 비교 쌍은 0개여서 이닝 화면은 기존 조건부 keep 결과를 유지한다. 새 모델의 추천 품질 우위와 CV 의도는 이번 UI 검증으로 판정하지 않는다.
