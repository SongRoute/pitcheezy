**오늘의 목표는 실제 상황을 입력받아 추천을 반환하는 작은 모델/API와 성능 근거를 확보하는 것이었다.** 기존 학습 결과를 재사용해 로컬 추천 번들을 만들고, 실제 역사 데이터 51개 상황에서 추천·재현을 확인했다. 신규 신경망 학습 없이 번들 생성과 평가에 14.6초가 걸렸다. 코드 작성·테스트 시간은 별도다.

- TRAIN 이닝으로 선정한 6명의 지원 구종, 전체 타석의 수비 승리 확률을 고려한 상위 후보.
- localhost HTTP `/health`, `/metadata`, `/recommend` 및 단일 JSON 요청 CLI.
- 핵심 번들 약 **13.0MB**. 51개 상황의 전체 카운트·후보 확률 계산 CPU 중앙값 **54.5ms**, p95 **73.9ms**. API 전체 지연·콜드 스타트와 구분한다. 예제 전체 추천은 **79.5ms**였다.

## WE와 최소 정책 비교

TRAIN으로 새로 적합한 경기 승리 확률 모델을 2025 DEV 전체 리그 87,559개 타석 시작 상태·1,161경기에서 확인했다. Brier **0.1540**, TRAIN 상수 확률 기준 **0.2495**, ECE10 **0.0142**였다. 최소 통과 기준을 충족했지만 주자 전이 전체의 보정을 검증한 것은 아니다.

정책 비교는 투수·경기당 하나, 투수당 최대 12경기를 사용해 총 51경기·51상황이다. 5회 이후 근소한 점수차·주자 상황을 우선했으므로 전체 투구의 평균 효과로 일반화하지 않는다. Burnes의 해당 DEV 표본은 없어 정책 비교에 포함되지 않는다.

| 비교 | 혼합 예측기로 평가 | 빈도 예측기로 재평가 |
|---|---:|---:|
| WE 타석 계획 − TRAIN 구종 빈도 정책 | +0.316%p | +0.298%p |
| WE 타석 계획 − WE 첫 구만 개입 | +0.272%p | +0.257%p |
| WE 타석 계획 − RE 타석 계획 | +0.0026%p | +0.0123%p |

빈도 예측기에서 마지막 비교의 기술적 95% 구간은 **−0.0015 ~ +0.0281%p**로 0을 포함한다. **WE가 RE보다 실용적으로 우수하다는 근거는 아직 부족하다.** 타석 계획은 이번 내부 비교에서 유망하지만, 최적화에 사용한 모델로 다시 평가하면 구조적으로 유리하다. 빈도 재평가도 TRAIN과 WE를 공유한다. 위 숫자는 현실의 승률 향상이나 독립적인 정책 효과 검증이 아니다.
