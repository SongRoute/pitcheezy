## 자율 진행 방식

1. 시연 전체 흐름에서 가장 큰 빈틈을 고른다. 서비스 개발과 근거 있는 연구를 병행한다.
2. 구현 → 다른 Opus 인스턴스 검토 → 수정 → 통합 검사 → 미리보기 반영 → 실제 동작 확인 → 기록까지 진행한다. 같은 모델 검토는 그대로 표시한다.
3. 일반적인 시연 수정은 위 조건을 통과하면 PM의 매번 승인을 기다리지 않는다. 현재 변경 소유자와 충돌하지 않는 한 지정 미리보기8771까지 위임한다.
4. 실험 종료 뒤에는 해석과 후속 가설 선택을 진행한다. GPU를 채우기 위한 중복 실험은 하지 않는다. 새로운 조합은 실행 전에 비교·예산·중단 조건을 기록한다.
5. 실제 아이폰 조작·사람의 영상 대조처럼 사용자 참여가 필요한 일은 링크/기대 결과/예비 경로를 갖춘 짧은 확인 묶음으로 준비한다. 그동안 독립 작업을 계속한다.
