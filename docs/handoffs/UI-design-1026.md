## 요소별 확정

### ① 머리 — 세 줄 (그림 01, 09~11)
- 1줄: 왼쪽 뒤로 · 가운데 점수 `CHC 0 : 2 SD`(약어 + 큰 숫자) · 오른쪽 상태 표시(⑥).
- 2줄: 왼쪽 회차 `2회초 ▾`(누르면 지금처럼 타석 선택) · 오른쪽 이닝별 점수표(1~9 + R). 지금 회 열 강조. 값은 지금 박스 자료 그대로, 없으면 빈칸.
- 3줄(흰 줄): 타자 | 카운트·주자·아웃 | 투수.
  - 타자: `타자 · 우타` / 이름 / `오늘 첫 타석` 등 오늘 기록
  - 가운데: 카운트 `2-1` 크게, 그 아래 주자 다이아몬드 + 아웃 점 3개
  - 투수: `투수 · 우투` / 이름 / `오늘 14구`
  - 이름 칸을 누르면 선수 시트(⑧-3) 해당 탭.
  - 360px 미만은 성만(Suzuki / King).
- 상태별: 공수 교대 = 3줄이 한 줄 안내 `공수 교대 · 다음 2회초 첫 타자 OOO`(그림 09) · 경기 전 = `CHC vs SD`, 2줄 `11:00 시작`, 3줄 없음(그림 10) · 경기 종료 = 최종 점수, 3줄 없음(그림 11).
- 폭이 넓은 화면(태블릿·PC): 점수 가운데, 내용은 960px 폭 가운데.
- 승리확률은 머리에 넣지 않는다.

### ② 존 (그림 12~15)
- 회색 배경 상자 없이 선만. 창 밖으로 많이 빠진 공은 지금처럼 가장자리 화살표.
- 추천: 위 추천 네모 규칙. 같은 칸 추천은 네모 하나로 합침(`1·2`, 가장 높은 순위 모양) — 지금 `groupTargets` 동작 유지.
- 실제 투구: 무채색 G1. **필요한 변경:** `Zone.tsx`의 `actuals`에 결과 종류(볼 / 스트라이크·파울 / 타격)를 넘겨야 한다(지금은 좌표·번호만). 결과는 투구 `description`에서 나눈다: `ball`·`blocked_ball`·`pitchout`·`hit_by_pitch` 등 볼 계열 → 볼, `hit_into_play` → 타격, 나머지 → 스트라이크·파울. 정확한 나눔표는 기존 결과 문구 코드에 맞춘다.
- 존 아래 한 줄 범례 `■추천 ○볼 ●스트라이크·파울 ●타격` + `투수 시점 · 우타자`.
- 여백 정리(존 확대)는 보류 — 지금 크기 유지.

### ③ 추천 후보 (그림 01)
- 머리 `추천 · 4구` + 오른쪽 `자세히`(추천 자세히 시트).
- 구분선 한 줄 세 칸: 순위 네모(존과 같은 모양) + 구종 이름. 위치·수치는 넣지 않는다(D49).
- 연결 끊김: `마지막으로 받은 추천 · N구`, 줄 흐리게. 확인 중·추천 없음: 세 칸 `—`.

### ④ 이번 타석 (그림 01, 16)
- 메인: `이번 타석 · N구 던짐` + 오른쪽 `펼치기 ▾` 한 줄만.
- 펼치면 그 자리에서 세로 목록: 맨 위 `N구 · 다음 공`(점선 네모), 그 아래 최근 공부터 `[G1 원] 구종 구속km/h ··· 결과`. 타석이 끝나면 맨 위가 결과 줄(굵게).
- 줄을 누르면 투구 상세(⑧-2). 그림 16의 머리는 옛 모양이니 목록 부분만 참고.

### ⑤ 메인에서 뺀 것
- `직전 타석 · 분석과 기록` 카드, `경기 흐름` 칸(승리확률·이닝별 점수표·최근 타석·오늘 구종 링크), 스포일러 안내 상자.
- 빠진 내용은 하단 메뉴 `기록`·`구종`과 머리 점수표로 간다. 승리확률 자리는 경기 기록 시트를 정할 때 결정(미정).

### ⑥ 상태 (그림 03~08)
- 화면 안 안내 문장 없음. 오른쪽 위 상태 표시 하나가 상태를 전부 보여 준다.
- 누르면 작은 풍선: 제목 + 지금 쓰는 안내 문장 그대로(그림 08). 위험 안내 줄 없음.
- 표시 대응(제안, Song 확인 필요 표시 ★):
  - `recommended`/정상 → 라이브
  - `feed_delayed` → 자료 늦음
  - `disconnected` → 연결 끊김 (존·추천 흐리게, "마지막으로 받은 추천")
  - `unconfirmed` → 확인 중 (추천 칸 `—`)
  - `unsupported` → 추천 없음 (추천 칸 `—`)
  - 정정(`Receipt.corrected`) → 추천 바뀜
  - ★ `ledger_unavailable`·`waiting`·`unavailable` → 시안에 없음. 기본은 `확인 중`/`추천 없음`과 같은 모양으로 두고 Song 확인
  - `pregame` → `경기 전`(회색 점), `final` → 표시 없음
- 상태가 두 개 겹치면(예: 연결 끊김 + 정정) 연결 문제를 먼저 보여 준다.

### ⑦ 하단 메뉴 (그림 01)
- 바닥에 꽉 찬 바, 머리와 같은 `#15191e`, 아이콘(선 그림) + 글자 4개: 추천 · 선수 · 구종 · 기록. 글자·아이콘 `#e6eaed`.

- 맨 아래 내용이 바에 가리지 않게 바 높이만큼 아래 여백.

### ⑧ 상세 시트
- **틀(C):** 처음엔 반만(화면 약 절반) 열려 존이 보인다 → 위로 끌면 전체. 손잡이 · 제목 · `닫기`(글자 버튼), 제목 아래 구분선, 표는 선만. 뒤 화면 어둡게. 키보드·스크린리더: 지금 `Sheet` 동작(포커스 가둠·Esc 닫기) 유지, 끌기 대신 `더 보기`/스크롤로도 펼칠 수 있게.
- **⑧-1 추천 자세히 (R1, 그림 17·18):** 제목 `다음 공 추천 · 4구`. 기록 시각 줄 → 표(순위 네모+구종 / 대략 위치 / 정책 선택 비중) → 안내 문장 → `직전 투구` → `기준과 한계 보기`·`속도 단위`. 반만 열림 = 표까지.
- **⑧-2 투구 상세 (P2, 그림 19·20):** 제목 `2회 초 · 1구 · 타자` + 오른쪽 `‹ ›`(앞뒤 공) `닫기`. 맨 위 실제 공 한 줄(G1 원 + `포심 152km/h` + `볼 · 존 바깥`) → 작은 존(공이 실제 자리에 오도록 넓은 창, 그 공의 추천 네모 함께) → 판정·원본 좌표 → 없는 측정값은 한 줄 `회전수·익스텐션·타구 속도·발사각은 이 공 자료에 없어요`(값이 있으면 줄로 보여 줌) → `이 공을 던지기 전 추천` 표 + 안내. 반만 열림 = 결과 줄 + 작은 존.
- **⑧-3 선수 (L1, 그림 21~24):** 탭 `타자 | 투수`. 이름 · 팀 · 타석/투구 방향 → 등번호 · 시즌 · 오늘(없으면 `—`). **투수 탭에는 `오늘 구종 · N구` 표(구종 / 투구 수 / 비율 / 평균 구속) 추가.** 안내 문장은 지금 문장.
- **⑧-4 구종 (G3, 그림 25·26):** 제목 `King 오늘 구종`. 반만 = 표. 끌어올리면 `오늘 던진 위치`: 한 존에 그날 공을 구종 첫 글자(싱·포·스·슬·체)로 표시 + 글자 범례 + 지금 안내 문장. 좌표 없는 공은 빼고 개수 문구에 반영.
- 아직 안 정함(다음 디자인 세션): 경기 기록 · 이닝별 점수 · 타석 선택 · 승리확률 시트. 구현 때는 **새 틀(C)만 씌우고 내용은 지금 그대로** 둔다.
