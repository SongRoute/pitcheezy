# 맥북 단독 예비 시연 (맥미니·Tailscale이 안 될 때)

맥미니 8771이 열리지 않을 때, 맥북 안에서 같은 시연 화면을 띄우는 예비 경로입니다.

## 쓰는 법 (맥북 터미널)

1. 묶음 파일을 맥북으로 옮겨 풀기: `tar xzf pitcheezy-offline-demo.tar.gz`
2. `cd pitcheezy-offline-demo/offline && python3 serve_offline.py`
3. Safari에서 `http://127.0.0.1:8790/showcase` 열기. 끝낼 때는 터미널에서 Ctrl+C.

## 무엇이 같고 무엇이 다른가

- 화면 코드: 8771이 서빙하는 빌드와 바이트가 같음(묶음 안 `dist/`).
- 경기 자료: 8771의 응답을 저장 시각(화면 맨 위 노란 줄)에 그대로 저장한 사본. 시작할 때 sha256을 확인하고, 하나라도 바뀌면 서버가 뜨지 않음.
- 저장된 것은 경기 849843의 시연 장면 39개(장면별 같은 타석 앞 공 + 공개 결과 + 요약)뿐. 다른 공으로 넘기면 "오프라인 예비 묶음에는 이 자료가 없어요"가 뜸. 지어낸 자료는 없음.
- 실시간 경기는 볼 수 없음(목록에 "실시간 경기 정보는 볼 수 없어요"로 표시).
- MLB 영상은 인터넷에서 받음. 인터넷이 없으면 영상 대신 화면 캡처로 설명.
- 아이폰은 이 맥북 서버에 붙지 않음(127.0.0.1 전용). 아이폰 쪽은 맥북 화면으로 대신.

## 다시 만들기 (맥미니)

`python3 capture_snapshot.py --base http://100.108.252.111:8771 --scenes ../src/showcase-scenes.json --out <빈 폴더>/offline/snapshot` 후 서빙 중인 빌드를 `<빈 폴더>/dist`로 복사. GET만 약 180번.
