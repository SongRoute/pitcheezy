## 위치 근사 실험: 예측 개선과 추천 개선의 분리

독립 평가기는 7월 1–21일 학습, 22–31일 보정했다. 8월 1–7일 후보 진단, 8–15일 점검, 8월 16일–9월 말 평가를 사용했다. 이미 열람한 기간을 다시 사용하므로 탐색적 후향 분석이다.

1. 독립 위치 조건부 평가기의 점검 로그손실은 위치 없는 평가기 1.499578에서 위치 포함 1.151584로 감소했다. 이것은 실제 도달 위치가 알려진 조건부 예측 비교다.
2. 기존 σ0.45를 σ0.30으로 좁히면 점검 로그손실은 낮아졌지만 게임 bootstrap 차이 구간이 0을 포함하고 지원률이 7.4%p 감소했다. 채택하지 않았다.
3. 지원이 충분할 때만 σ0.30을 쓰고 나머지는 σ0.45로 돌아가는 후보는 지원률을 유지하면서 점검 로그손실을 0.04081 줄였다. 이 표본은 432구·5경기에 불과하다.
4. 그러나 동일 실행 분포와 독립 평가기를 놓고 정책을 비교하자 483 요청 중 454타석·29경기에서 새 후보의 방어 측 WE가 기존보다 **0.019152%p 낮았다**. 게임 bootstrap 95% 구간은 **[-0.023578, -0.014801]%p**였다. 실행 σ0.30/0.65에서도 방향은 같았다.
5. 독립 평가기의 선택 행동 표본 수가 20 이상인 217타석에서도 -0.021208%p였다. 특정 희소 표본에만 의존한 현상으로 보기는 어렵다. 다만 이 값은 여전히 모델 내부 평가이며 실제 목표 개입의 인과 효과가 아니다.
6. 첫 선택이 같은데 이후 카운트 정책이 달라진 373타석도 손실을 보였다. 다음 공의 예측 적합도만으로 타석 전체 정책을 바꾸면 안 된다는 진단 근거다. 사후 하위집단 결과는 다중 비교 보정 없는 기술 통계다.

**결정: 서비스 σ0.45와 동결 모델 유지.** 새 후보의 예측 지표 개선만으로 추천 성능 향상을 주장하거나 교체하지 않는다.

## 영상 평가: 실제 클립, 임시 라벨, 명시적 기권

- 공식 [Logan Webb 삼진 영상](https://www.mlb.com/giants/video/logan-webb-s-seven-strikeout-performance)의 2025-08-17 경기 모음에서 투구 전 짧은 4구간을 선정했다. 파일·프레임 해시와 출처를 보존했다. 삼진만 모은 선택 편향이 있다.
- 시작 미트 ROI와 끝 프레임의 미트 중심 추정을 추적 출력/실제 투구 좌표 확인 전에 고정했다. 라벨은 **AI 시각 추정·사람 미검토**, 끝점 불확실성 약 ±10px다. 사람 정답, 실제 의도, 물리 좌표 정답이 아니다.
- 고정 템플릿 추적은 4구간 모두 끝점 이전에 낮은 일치도로 기권했다. 성공한 매칭은 각각 4/20/6/25프레임이었다. 끝점에 도달하지 않아 끝점 오차를 계산하지 않았다.
- 라벨은 별도 SQLite에 불변 버전으로 저장하고, 추적을 별도 버튼/API로 실행한다. 4개의 API 실행 결과가 CLI 추적 내용과 정확히 같았다. 추천 입력으로는 사용하지 않는다.
- 후속 단일 후보는 보수적인 광류 추적이다. 같은 4구간을 쓰는 탐색적 기술 비교이며 새로운 독립 시험셋이라고 부르지 않는다. 고정 사양 기록 뒤 실행한다.
