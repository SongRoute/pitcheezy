# 자율 개발 체크포인트

2026-09-22 마무리 갱신: 아래 표는 v1 당시의 결정 기록이다. 개선판에서는 이름 매핑·대결 회차/구속 관측·연구 환경과 분리된 런타임·추론과 DB 쓰기 분리·실제 짧은 영상/라벨 저장을 구현했다. 현재 결과는 `IMPROVEMENT_LOG.md`를 우선 참고한다. 라이브 공급, 운영 DB, 실제 팬 평가와 사람 검토 목표 라벨은 미완료 후속 과제다.

사용자가 잠든 동안 추가 질문 없이, 승인 범위 안의 대체 구현으로 진행한 결정이다.

| 문제 | 영향 | 이번 선택 | 다음 결정·작업 |
|---|---|---|---|
| PostgreSQL 실행환경 없음 | 운영 아키텍처와 로컬 저장소 차이 | SQLite WAL + 저장소 모듈 + 버전 검증 | 배포 시 PostgreSQL 이전·동시성 부하 검증 |
| 준비된 영상 없음 | 의도 자동 검출 정확도 검증 불가 | 마지막1구 작업·어댑터·no-media·수동 메모 | 사용 가능한 영상 확보, 좌표 보정과 미트 라벨 |
| 목표 위치·제구 라벨 없음 | 진짜 의도에 대한 개입 효과 식별 불가 | 관측된 joint delivery를 구역 근방으로 재가중 | 실제 목표 라벨, 제구 분포, 독립 평가 |
| 연구 번들 의존성 일부만 캡처 | 캡처본만으로 CLI import 불가 | 캡처본과 일치하는 로컬 소스 검증 후 유틸리티 사용·해시 고정 | 연구 CLI와 예측 라이브러리 의존성 분리 |
| Pro 사용량 절약 필요 | 대규모 재학습·탐색 범위 제한 | 기존5-seed 모델 재사용, Astra 코드·Sol 검증 | 모듈별 개선 실험은 사용 후 우선순위 확정 |
| 타자 이름 데이터 없음 | 타자 이름 대신 MLB ID 표시 | 타자 #ID, 투수 이름 표시 | 별도 선수 메타데이터 연결 |
| 관측 컨디션과 학습 특성 구분 | 투구 수로 피로·부상 단정 불가 | 현재까지 투구 수만 맥락으로 제공 | 타순 회차·구위 변화 모듈 확장 및 검증 |
| 원본 과학 패키지 재사용 | 웹 환경이 원본 `.venv`에 의존 | 별도 웹 패키지 환경 + 읽기 전용 참조 | 독립 배포용 완전한 lock·패키징 |
| 차가운 추천 계산 중 DB 쓰기 잠금 | 동시 사용자·CV 작업의 짧은 대기 가능 | 데모 사전 캐시 + 계산 재사용 | 실시간 확장 전 추론과 DB 트랜잭션 분리 |
| 내장 브라우저 도구 메타데이터 장애 | 내장 화면 자동화 실행 불가 | 독립 headless Chromium으로 로컬 앱의 실제 클릭·화면 검증 | 도구 복구 후 내장 브라우저에서도 확인 |

실제 CV 완료, 실제 정책 성능 향상, 모든 MLB 선수 지원, 운영 배포를 이번 완료로 표현하지 않는다. 기존 모델·데이터·실험 결과를 덮어쓰지 않는다.
