### 3.1 2021–22를 ‘독립 확인셋’이라고 부르기 전

미사용 연도라는 사실만으로 독립성과 시간 적합성이 생기지 않는다. **2023–25로 학습한 현재 모델을 2021–22에 적용하는 것은 과거로의 전이 점검**이다. 당시 알려지지 않은 선수 성향·스케일러·빈도·delivery 모형을 쓰면 투구 전 예측 검증으로 해석할 수 없다.

- 먼저 파일/라벨 열람 이력·기존 튜닝 관여·수집 가능 범위·키/라벨 정의를 감사하고 해시·노출 장부를 작성한다. 이 문서에서는 원자료 수집·열람하지 않았다.
- 시간적으로 유효한 과거 확인을 원하면 평가 이전 TRAIN/CAL과 모든 auxiliary의 as-of를 새로 구성하고 양쪽 후보를 같은 기간으로 다시 학습해야 한다. 사용 가능한 더 이른 TRAIN 존재·표본량·비용은 **미측정**이다. 이는 현재 P48 체크포인트의 정확한 독립 확인과 다른 질문이다.
- 현재 체크포인트의 독립적인 전향 확인은 조건을 갖춘 RS-03 2027 등록의 예측 층과 연결할 수 있다. 등록 시점·미개봉·채점 계약·as-of 조건은 D187을 그대로 따른다. 이번 3주 결과로 대신하지 않는다.
- 자료가 없거나 이미 노출되었으면 독립 확인은 ‘미완’으로 남긴다. 2026으로 빈칸을 채우지 않는다.

2. **동일 정보·정답:** 10-class, 같은 투구 키·결측 정책·지원 범위. 실제 현재 공의 구속/회전/좌표·결과는 입력 금지. 물리 조건부 후보이면 공통 TRAIN joint delivery 400 draws와 난수·conditioning을 고정한다. 과거 H5의 실제 관측과 현재 공의 미관측을 구분한다.
3. **재사용 우선:** G0·G15와 P48 동결 산출물/코드·환경을 먼저 대조한다. 구현과 평가 경로가 다르면 pipeline 대조군을 추가해 구조 효과와 분리한다. 기존 논문 재현 seeds 42~46를 새 screen 0~2, 최종 0~4와 혼동하지 않는다. P48의 0~4는 이미 재사용·노출된 seed다.
4. **선정:** 주 비교·최대 후보 수·CAL 최적화 범위·seed/ensemble 수·N/G/R/C 중 목적을 결과 전 고정. 기본 N은 ΔNLL≤−0.003, 짝 CI 상한<0, ΔBrier CI 상한≤+0.001, screen 2/3·최종 4/5 방향 조건. 새 다중 후보 묶음은 사전 다중비교 계획(Holm 등)을 기록한다. P48 단일 주 검정 예외를 복사하지 않는다.
5. **보고:** NLL/Brier/ECE·클래스별 calibration·희귀 결과·그룹 CI·전체 요청 분모의 지원/기권/fallback·seed별 차이. R의 집단·최소 표본량·다중 비열등 판정을 등록 전에 확정한다. 부족한 집단은 null/미측정으로 남긴다. P48 사후 R 감사와 새 사전 R 검증을 분리한다.
6. **불확실성:** 같은 투구 paired loss를 경기 단위로 bootstrap 10,000회, 투구 가중 평균. seed를 독립 경기로 합산하지 않는다. CI는 고정 예측 조건부이며 학습·CAL·선정 전체 불확실성을 담지 않는다고 표기한다. 두 겹치는 DEV를 독립 재현으로 세지 않는다.
7. **비용·실행:** 학습/보정/예측 생성/채점 시간을 분리하고 GPU시간·벽시계·최대 GPU/RAM·디스크·실행 장치·추론 p50/p95·batch/warmup을 기록한다. A5000 측정값으로 맥 전시 지연을 주장하지 않는다. GPU 수·공유 CPU/RAM/IO 병목을 확인한 후만 병렬도를 높인다.
8. **등록·검토:** 작성자와 다른 검토자의 설계/고정 커밋 검토 → 자료 역할·분할·지표·실행/저장 예산·ID·seed·config/data/source hash 등록 → 승인된 실행 → 실패 포함 기록·독립 결과 검토. `results/`, `docs/experiments.md`에 새 결과를 남기되 기존 봉인 파일은 덮어쓰지 않는다. 규칙·서비스·정책 결정은 Song 영역이다.

## 5. A5000 5장 기준 3주 계획

일정은 **실행 승인 후의 계획**이며 예약·실측 완료시간이 아니다. 가용성이 없으면 다음 단계가 밀리며 전시 동결은 미루지 않는다. A2b(11/16~29 계획)와 자원을 중복 예약하지 않고 실행 전 기존 소유자와 조정한다. `gpu st`/lock 확인 없이 ‘5장 확보’라고 보고하지 않는다.

| 주간 | 연구 산출물·배치 | 완료 조건·전시와의 경계 |
|---|---|---|
| 1주: 11/1~7 | 11/1~3 기존 P48/G15·노출·R metadata 감사와 B2/B3 등록 초안. 11/4~6 독립 검토·작은 비용 측정 설계, 11/6까지 Codex 검토/인계. 11/7은 승인·자료 적격성 대기 또는 수정 | 실행 결정이 없으면 문서 단계에서 멈춤. 2026 및 봉인 결과 추가 열람 없음. 반복 DEV라는 라벨 고정 |
| 2주: 11/8~14 | 승인된 B2 먼저, 결과/자원 판정 뒤 별도 B3. 저장 예측 재사용이면 GPU 0fit. 재학습이 따로 승인되면 최대 10fit을 5개씩 두 배치; 실제 메모리·시간 측정 후 다음 배치. 11/11 공동 연결시험(미확정)에는 서비스 자원 우선 | 시간 상한을 실행 전 등록하고 소진 시 중단. B2 결과를 본 뒤 B3 새 질문/분할을 조정하면 새 등록. 영상·호스트 담당 작업에 개입하지 않음 |
| 3주: 11/15~21 | 11/15~19 독립 결과 검토·R/지원·추론 비용·실패 정리, 후보 동결 또는 개선 미확인 보고. 후보 3의 새 fit은 검토·승인·예산이 모두 준비된 경우만 최대 8fit, 아니면 다음 기간 제안. 11/20 기능 동결, 11/21 읽기 전용 인계·리허설 지원 | 전시 모델 교체 없음. A2b와 GPU/CPU/IO 점유 조정 실패 시 연구 순연. 11/21~23은 전시 리허설 우선, 11/24 시연 |

5장에 seed를 하나씩 배치하는 것은 단일 학습의 5-GPU 분산 학습을 뜻하지 않는다. 총 GPU시간은 작업별 측정시간의 합, 벽시계는 배치별 가장 느린 작업과 공통 IO/채점 시간을 포함한다. 현재 후보의 벽시계·GPU시간·원화 비용은 **미측정**이다. D185의 과거 장치/모형 시간은 다른 후보의 완료시간 보증으로 환산하지 않는다. 이미 저장된 예측/체크포인트가 있으면 fit 예산을 억지로 소진하지 않는다.
