## 해석의 한계
- 반복 노출: dev·mlb_dev는 P24~P31에서 여러 번 본 자료다. seed 16~18은 새 모델 난수일 뿐 새 평가 자료가 아니다. 독립 확인 결과가 아니다.
- 사후 선택: counts 작업량, periodic 임베딩, 잔차 구조는 모두 앞선 가족 결과를 본 뒤 골랐다.
- 연산량·크기 불일치: periodic_residual은 대조군보다 params 1.73배, 학습 시간 약 2.6배다. periodic_counts보다는 params가 0.85배로 적지만 시간은 약 1.5배다. 크기를 맞춘 대조는 없다.
- dev는 경기 수가 적어서 구간이 넓다. 여섯 대비 중 dev에서 구간이 0을 넘지 않은 것은 셋(structure, input, embedding_type)이다. 그중 structure는 seed 방향이 엇갈렸다.
- 원 입력 flatten 팔이 context 53에 없어서 임베딩 × 구조 상호작용은 추정하지 않았다.
- 다른 가족(P30·P31, TabM 등)과는 대조군·코드·seed가 달라서 직접 비교하지 않는다.
- 혼합 전 직접 head 비교다. 6월 혼합·G0·G15·정책 효과가 아니다. 서비스 추천 정책의 이득을 주장하지 않는다.
