## 초안이 새로 밝힌 것
- **A2:** 현행 판정 규칙의 80% 검정력 최소 검출 효과는 시즌 규모 0.00274 WE/타석(편향 감안 0.00548)이고, 2026 규모 오차의 약 89%가 **검열 폭(판정 못 한 타석)** 몫으로 추정된다(독립 가정 아래 분산 잔차로 구한 근사치, 측정된 분해 아님 — 10/27 검토 지적 반영). 추정 잡음을 30% 줄여도 판정 MDE는 0.7%만 준다(점추정 MDE는 0.00023 → 0.00016). → 2027 판정량은 D186 3-①로 결정됨(점추정 판정 + 검열 몫 별도 보고; 현행 하한 끝점 규칙은 보조 행). **결과(10/27 23:28): NO_PRECISION_GAIN** — 반폭 30% 감소를 인증된 편향 안에서 이룬 쌍 없음(최대 ≈25%, R1-b×R2-1; 인증 INCONCLUSIVE: 2κ_p 정밀도 미달·2ζ_p 상한 > B); 2027 기본안은 현행 DR·실현 WE, RS-03 SW-EST·SW-A3 OFF.
