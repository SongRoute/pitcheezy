노션 02 결정 로그(ADR-1~4)는 여기로 이관했고 이후 노션은 쓰지 않는다.

- 2026-09-07 **D1** 실험설계 노트(현 docs/design.md)를 기준 설계로 채택.
- 2026-09-07 **D2** 2026 검증셋은 정규시즌 종료 직후 1회 갱신(`--freeze`) 후 고정. 포스트시즌 제외.
- 2026-09-07 **D3** 전이 모델 비교의 NLL·ECE는 학습 창 내 홀드아웃(2023–24 학습 → 2025). 2026은 OPE·분해 전용. 이유: 정책이 자기 시뮬레이터로 자기를 평가하는 순환을 끊는다.
- 2026-09-08 **D4** 인터페이스 스펙 v1 채택. 상태 288×K, 행동 225, 결과 11, float32, 마스크 3층, npy 디렉터리 저장. docs/interface-spec.md.
- 2026-09-15 **D5** 개인 개발로 전환. 트랙 A/B/C, 노션 SSOT, ADR 템플릿, 스펙 태그 절차, 리뷰어 요건 폐지. 레포가 유일한 출처. 이유: 협업 조정용 규칙은 혼자면 비용만 남는다. 과학적 타당성 규칙 5개(CLAUDE.md 절대 규칙)는 유지.
- 2026-09-15 **D6** 목표를 "기존 연구 대비 개선"으로 명시. 비교 대상 = SmartPitch(Otremba 2022), Takamido & Nakamoto(반사실 시퀀스 최적화). 같은 데이터 버전·같은 2025 홀드아웃·같은 2026 OPE에서 재구현해 비교. 논문 보고 수치는 우리 표에 옮기지 않는다. docs/baselines.md.
- 2026-09-15 **D7** 4자 책임 분해는 Phase 2 후순위. 설계(design.md §0-f, ⑥, ⑤)는 유지하되 추천 성능 확인 뒤 진행.
- 2026-09-15 **D8** Phase 1 첫 개선 축 = "직전 N구 시퀀스 맥락" (Takamido에서 착안, design.md §1-e 맥락 피처 후보에 이미 있던 항목). 스펙 v1의 context 축 삽입 규칙으로 처리. 이어서 xRE24 + 결과 공간 세분화, 투수별 구조 ⓑⓒ 순.
- 2026-09-15 **D9** 실험 ID에서 트랙 문자를 뺀다: `EXP-P{phase}-{seq}`. configs/는 평탄화 (`configs/{ID}.yaml`).
- 2026-09-15 **D10** 맥미니(M4, 24GB, 상시 가동)가 주 실행기. Colab Pro는 로컬 예상 2시간 초과 또는 메모리 24GB 초과 실험에만. 이유: Phase 0(투수별 집계·VI·IPS)과 B2 Transformer(표본 10만, 소형)는 로컬 CPU/MPS로 충분하고, Colab 세션 만료 문제가 사라진다. 데이터 원본은 Drive에 두고 맥미니에 동기화, 해시로 검증.
- 2026-09-15 **D11** 하루 루틴: 아침 새 세션 → 밤사이 실험 결과 확인(results/, runs/_logs/) → experiments.md 갱신 → 다음 한 가지 결정 → 진행 → 저녁에 다음 밤 실험을 걸어두고 종료. 실험은 Claude 세션 밖(tmux `runs` 창, nohup)에서 돌린다. 스크립트 scripts/dev.sh.
- 2026-09-17 **D12** 포스트시즌은 2026 freeze 홀드아웃에서 제외(D2 유지)하되, P0 결과표 이후 별도 "데모 슬라이스"로만 허용: 이미 학습된 레귤러 선발 풀에서 포스트시즌 진출팀 투수를 뽑아 포스트시즌 투구에 OPE를 한 번 더 돌린다. 채택 판단에는 쓰지 않는다. 이유: 투수별 모델(ⓐ)이라 학습 범위를 진출팀으로 줄여도 얻는 것이 없고, 타자 군집·RE24는 전체 데이터가 필요하며, 포스트시즌은 표본(~1만 구)이 작고 분포가 다르다. 필요 작업: fetch_data.py 포스트시즌 수집 옵션(10월 중순 이후).
- 2026-09-17 **D13** 인터페이스 스펙 v1 코드화 완료 (`src/pitcheezy/interfaces/`, 계약 테스트 101개). 규칙 마스크는 "3볼에 볼 불가·2스트에 스트라이크 불가"의 뒷면(BB 는 3볼, K 는 2스트에서만)까지 포함. Statcast 매핑은 종결=events, 비종결=description 으로 판정하고 피치클록 자동 볼/스트라이크는 카운트만 진행. 스키마 변경 없음.
- 2026-09-17 **D14** RE24·dRE24 표는 `data/re24/{re24_version}/` 에 커밋한다 (작고 모든 실험이 공유). 버전 = `re24-{시즌창}-{데이터 버전}-{계산 커밋}`. 계산 규칙: RE24 = 타석 시작 상태별 이닝 끝까지 득점 평균, dRE24 = 종결 투구 시점 상태 기준 RE[다음]+득점−RE[현재] 평균, 경기 마지막 하프이닝(끝내기 등 3아웃 전 종료 가능)은 제외. 첫 버전 re24-2023_2025-d20260911-s2325-82b008b (타석 521,935, dRE24 최소 셀 n=6).
- 2026-09-17 **D15** 레귤러 선발 풀 = 학습 창(2023–25) 안 어느 시즌이든 100이닝 이상인 투수, 그 투수의 창 안 모든 정규시즌 투구 사용 (`configs/pitchers_ip100.yaml`, `data/pitchers/pool-ip100-2023_2025-d20260911-s2325-2b19cc1`). 이닝 = 타석 사이 아웃 증가분 귀속 / 3 (Webb 2024 = 204.67, 공식 204⅔ 일치). 실측: 100이닝이면 시즌 126~128명·풀 219명·투구 110만 구로 design.md 의 "60~70명" 추정과 다르다. 그 인원은 150이닝(시즌 58~71명, 풀 130명)에 해당. 하한은 P0 결과 뒤 재검토 가능, 표는 table.md 에 있음.
- 2026-09-17 **D16 (잠정)** 전이 텐서 희소 셀은 계층 디리클레 평활: league(count) → league(count,action) → league(state,action) / league(count,구종) → pitcher(count,구종) → pitcher(state,action) (투수 편차를 비율로 곱함). 평활 강도 α 는 2025 홀드아웃 NLL 로 그리드 스크리닝(auto). 이유: 투수당 64,800 셀에 ~5천 구라 순수 집계는 거의 전부 빈 행. 첫 실행에서 league(count,action) 층을 넣자 NLL 1.29→1.22.
- 2026-09-17 **D17 (잠정)** 평가 정책 완화의 주 온도 τ=0.02 (RE24 단위). 상태별 Q 폭(max−mean 중앙값 0.07, 1위−2위 0.005)에 맞춤. 메뉴(greedy·topk·softmax·tilt 여러 τ)를 모든 실험에서 함께 기록하고 표에는 주 항목만.
- 2026-09-17 **D18 (잠정)** π_b 는 2026 로그에서 인수분해 계층 추정 π(구종|s,투수)×π(위치|구종,카운트,투수), 경기 단위 5폴드 교차 적합. 이유: 같은 데이터로 맞추면 로그 행동 확률이 부풀어 가중치 평균 0.05(이론 1)로 붕괴했고, 225행동을 한 축으로 평활하면 희귀 구종이 바닥 확률로 떨어져 비가 폭발했다.
- 2026-09-17 **D19 (잠정)** P0 OPE 저울 = 1스텝 편차 SNIPS (한 투구만 π_e, 나머지 π_b; 투구 비 클립 20; 공통 지지 = 학습 레퍼토리 ∩ 2026 에서 20구 이상 던진 구종). 궤적 IPS·SNIPS 는 설계상 e2e 저울이지만 225행동×타석당 ~4결정에서 ESS≈0 이라 기록만 한다 (tilt 정책은 ESS 1~2%). 경기 클러스터 부트스트랩 95% CI. 재검토: 궤적 저울을 살릴 방법(DR, 거친 행동 공간)은 P1 과제.
- 2026-09-17 **D20 (잠정)** 설계 ③ 보수화 축 "π_b KL 제약"을 P0 로 앞당겨 주 정책으로: π_e ∝ π_b·exp(Q/τ) (tilt). 이유: softmax(Q/τ)만으로는 노이즈 Q 가 π_b 가 안 던지는 셀에 질량을 줘 OPE 불가. tilt 는 "투수 자기 레퍼토리 안에서 모델 방향으로 조정"이라 배포 의미도 분명. 모델 내 가치(model_value)와 OPE 차이를 착취 폭 진단으로 함께 기록.
