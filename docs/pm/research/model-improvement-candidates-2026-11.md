## 3. 후보와 우선순위

아래 기대 효과는 검증할 **가설**이다. 새로운 ΔNLL·성공률·소요시간은 전부 **미측정**이며, fit 수는 측정 예측이 아닌 제안 예산 상한이다. B2/B3는 D188에서 보류된 예측 트랙 이름을 사용한다.

| 순서·후보 | 비교·가설 | 비용·A5000 5장 배치안 | 진행/중단 조건 |
|---|---|---|---|
| 0. P48 근거 감사 | G15/P48의 저장 예측·키·보정 순서·12집단 R·지원/기권·추론 비용을 같은 분모로 대조 | 재학습 0회. 지표 CPU; 추론 재측정은 1장부터. CPU시간·GPU시간·RAM·디스크 **미측정** | 저장 산출물/metadata가 없으면 미측정. 키/라벨/분할 불일치면 새 후보 채점 중지 |
| 1. B2 교차 가족 블렌드 | 기존 TabM residual와 periodic residual의 오차가 상보적인가. P48 단독 및 G15 고정 비교군 | 저장 예측이 완전하면 새 backbone fit 0회, CAL에서 제한된 혼합비만 선택. 예측 재생성은 기존 체크포인트 사용 우선. 재학습 필요 시 별도 등록, 2가족×5seed=10fit 상한 → 최대 5개씩 2회 배치 | DEV 보고 혼합비 조정 금지. N/Brier·지원·R·추론 비용을 함께 보고. 중복 후보/같은 계산은 재실행 안 함 |
| 2. B3 평균 뒤 보정 | seed 평균 후 단일 temperature가 평균 전 보정보다 calibration/NLL을 개선하는가 | backbone fit 0회 원칙. 고정 B1 또는 B2 하나에 보정 순서만 비교, CAL 계산 시간 **미측정**. GPU 5장 필요 없음 | 별도 CAL 역할·시점 고정 전 실행 안 함. B2와 함께 여러 축을 동시에 바꾸지 않음 |
| 3. 제한된 H5/표본량 상호작용 잔차 | 현재 공을 보지 않는 직전 이력·TRAIN 표본량 신뢰도 표현이 저표본·교체 구간 오차를 줄이는가 | 먼저 기존 residual/counts·workload/history 후보와 중복 감사. 미실험 축 하나만 2후보×3seed=6fit screen 상한(5+1), 최대 1후보의 seed 3·4 추가 2fit | 3-seed 평균 개선·Brier/지원 회귀가 없을 때만 등록된 추가 예산 사용. 실제 현재 투구 물리 금지. 이미 실험한 축이면 새 후보를 만들지 않고 종료 |
| 4. 2021–22 확인 자료 적격성 설계 | 과거 연도가 미열람인지, 같은 라벨·coverage·as-of로 재현 가능한지 | 이번은 메타데이터·분할 설계만. 수집/재학습 0회; 독립 확인 실행의 시간·비용 **미측정** | 아래 시간 역전 조건 해결 전 독립 확인 불가. 3주 안 완료를 약속하지 않음 |

추천은 **0 → B2 → B3**다. 후보 3은 중복 감사 결과 새로운 질문과 남은 사전 예산이 있을 때만 다음 묶음으로 제안한다. 대형 신규 backbone·새 의도 라벨·2026 fine-tune·계획 예산 확대는 이 3주 계획에 넣지 않는다. 예측 개선이 없으면 결과와 한계를 기록하고 현재 기준선을 유지한다.

### 3.1 2021–22를 ‘독립 확인셋’이라고 부르기 전

미사용 연도라는 사실만으로 독립성과 시간 적합성이 생기지 않는다. **2023–25로 학습한 현재 모델을 2021–22에 적용하는 것은 과거로의 전이 점검**이다. 당시 알려지지 않은 선수 성향·스케일러·빈도·delivery 모형을 쓰면 투구 전 예측 검증으로 해석할 수 없다.

- 먼저 파일/라벨 열람 이력·기존 튜닝 관여·수집 가능 범위·키/라벨 정의를 감사하고 해시·노출 장부를 작성한다. 이 문서에서는 원자료 수집·열람하지 않았다.
- 시간적으로 유효한 과거 확인을 원하면 평가 이전 TRAIN/CAL과 모든 auxiliary의 as-of를 새로 구성하고 양쪽 후보를 같은 기간으로 다시 학습해야 한다. 사용 가능한 더 이른 TRAIN 존재·표본량·비용은 **미측정**이다. 이는 현재 P48 체크포인트의 정확한 독립 확인과 다른 질문이다.
- 현재 체크포인트의 독립적인 전향 확인은 조건을 갖춘 RS-03 2027 등록의 예측 층과 연결할 수 있다. 등록 시점·미개봉·채점 계약·as-of 조건은 D187을 그대로 따른다. 이번 3주 결과로 대신하지 않는다.
- 자료가 없거나 이미 노출되었으면 독립 확인은 ‘미완’으로 남긴다. 2026으로 빈칸을 채우지 않는다.
