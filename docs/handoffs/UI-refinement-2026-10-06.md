## 반드시 보존할 의미

- 선택한 투구 직전의 경기 상황·누적 오늘 기록 등 기존 as-of 계약을 유지한다. 과거 타석에 최종 경기 기록·미래 결과·미래 교체 선수를 끼워 넣지 않는다. 결과·실제 투구 공개 시점과 기존 서버 시계/재생 상태 계약을 보존한다.
- 시즌 기록·라인업·오늘 기록은 확인 가능한 원천 자료를 사용한다. UI에 필요한 값이 현재 계약에 없다면 원천과 시점 기준을 검토하여 연결하고, 없는 숫자를 0이나 추정값으로 만들지 않는다. 결측과 실제 0을 구분한다. 추천 대기·불가·미지원 상태와 출처/상세 접근을 유지한다.
- CV는 기존 **포수 미트 가로 위치**의 공개 이후 보조 표시다. 높이·의도·제구 오차 검증으로 확대하지 않는다. 결측/기권은 표시하지 않으며 기존 출처·제한 설명과 좌표 방향을 유지한다. 참조: [미트 표시 계약](UI-setup-display-work-order.md) 및 현행 구현의 후속 수용 증거.
- 추천 비중을 예측 확률이나 과학적 우위로 재명명하지 않는다. 서비스 G0·연구 기준·과학 게이트·실라이브 허용 범위는 변경하지 않는다.
