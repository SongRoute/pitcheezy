## 읽는 법
- 순서는 랜덤 < 실제 투수 < 모델 세 개 (K=1 / K=6 / B1). 실제 투수와 모델 CI 는 겹치지 않는다 (+0.007/결정). 우리 모델(K=1·K=6)과 B1 은 서로 겹친다 → **주자·아웃 축도 타자 군집 축도 P0 저울에서 미검출**. 원인 후보: (1) 투구 결과 분포가 주자·아웃에 거의 안 달림, (2) tilt 는 π_b 위에서 조금만 움직여 보상 차이가 묻힘, (3) 셀 희소.
- 모델 내 가치(+0.11)와 OPE(+0.03) 차이 = 설계 0-e 의 모델 착취. greedy 는 모델 안에서 +0.17 이지만 OPE ESS 5%.
- 궤적 SNIPS 는 우리 모델 +0.0667 이지만 ESS 1.7% 로 신뢰 못 함. 이걸 살리는 것(DR·거친 행동 공간)이 P1 과제.

- Q=0 은 π_b 와 일치(+0.0200), −Q 는 π_b 보다 나쁨, 뒤섞은 Q 는 π_b 와 CI 겹침 → **추정량은 정상**이고 Q 에 방향 정보가 있다.
- **다른 투수의 Q 로 기울여도 진짜 Q 와 같은 이득**(τ=0.005: +0.0306 vs +0.0307) → 현재 모델의 이득은 전부 **리그 수준**(상태·행동 → 결과) 정보. 투수별 성분은 아직 기여하지 않는다 (α=50 평활에서 투수 표본이 리그 사전분포에 묻힘). 거친 행동 표와 합치면: "리그 평균적으로 좋은 세부 위치"를 아는 것이 이득의 전부. 투수별 구조 ⓑⓒ(P1 축)와 평활 재설계가 다음 과제.
