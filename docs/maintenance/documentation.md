# 문서 작성·연결 규약

상위: [운영 진입점](../pm/overview.md) · 지침 정본: [AGENTS](../../AGENTS.md)

2026-11-01 사용자 승인: 문서는 짧은 주제 단위로 연결하고 지침 중복을 없앤다. 길이 수치는 업계 표준이 아니라 이 저장소의 유지보수 기준이다.

- 일반 문서 목표는 **1,000~2,000자**, 상한은 **3,000자**다. 최소 길이는 없다. UTF-8을 읽은 Markdown 원문에서 공백·링크·코드·줄바꿈을 포함한 문자 수로 센다. 토큰 수와 혼동하지 않는다.
- 한 문서는 하나의 질문·행동·계약을 완결한다. 글자 수만 맞추려고 문장·명령·표를 중간에서 나누지 않는다. 긴 경우 의미 단위의 하위 문서로 분리하고 부모에 목적과 읽을 조건을 적는다.
- 지침·현재 상태·결정 이력·실행 증거를 분리한다. 정본은 하나만 두고 다른 문서는 요약과 링크를 쓴다. `CLAUDE.md`는 정확히 `@AGENTS.md`와 줄바꿈만 유지한다.
- 링크에는 관계가 드러나는 이름을 쓴다: 상위 안내, 선행 조건, 근거, 대체한 결정, 검증 테스트. 왕복 링크를 수동 복제하지 않는다. backlink와 그래프는 링크에서 생성하는 탐색물이다.
- 진입점에서 관련 문서까지 짧게 이동하게 한다. 모든 작업에 전체 문서 읽기를 강제하지 않는다. 새 계층은 실제 독자·업무 경계가 있을 때만 추가한다.

## 보존과 점진적 전환

고정 실험 등록·봉인 증거·과거 결정 원문·생성 파일은 길이 제한 예외다. 예외는 파일·이유·상태를 기록하며, 단순히 길다는 이유로 현행 안내를 예외 처리하지 않는다. 해당 원문을 짧은 안내 노드에서 참조한다. 이미 고정된 원문의 날짜·수치·판정을 다시 쓰지 않는다.

이동할 때 기존 경로·절 링크의 사용처를 조사한다. 필요한 경우 이전 경로에 안내와 기존 anchor를 남긴다. 원문은 고정 Git 커밋 또는 별도 불변 기록으로 추적 가능해야 한다. 상대 링크와 검사 명령은 새 위치에서 검증한다. 코드·실험·원자료를 문서 정리의 부산물로 삭제하지 않는다.

한 분야씩 전환하고 수정된 일반 문서부터 상한·링크·중복을 검사한다. 기존 미전환 목록과 이미 보존된 기록을 구분한다. 도구별 실제 지침 로딩과 대표 작업 검증 전에는 토큰·속도·정확도 개선을 주장하지 않는다.
