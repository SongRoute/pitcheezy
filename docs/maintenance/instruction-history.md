# 지침 변경 이력과 원문

현행 정본: [AGENTS](../../AGENTS.md) · 작성 기준: [문서 규약](documentation.md)

2026-11-01에는 사용자 승인에 따라 공통 지침을 AGENTS에 모으고 CLAUDE를 import 한 줄로 바꾼다. 날짜별 역할·모델·GPU 문구를 새 세션의 현재 권한처럼 반복하지 않는다. 역사적 지시·실험 계약·결과를 취소하는 변경이 아니다.

변경 전 원문은 Git 커밋 `6e2038fd`에 보존된다. 아래 링크는 변경되지 않는 전체 커밋에 고정한다. 과거 절의 링크를 추적할 때 해당 원문의 anchor를 사용한다.

- [AGENTS 원문](https://github.com/SongRoute/pitcheezy/blob/6e2038fd0010657e6f6f2d1e49820490f6195da4/AGENTS.md): 공동 작업, 역할, 자료/GPU, Graphify, Ponytail 및 연구 예외.
- [CLAUDE 원문](https://github.com/SongRoute/pitcheezy/blob/6e2038fd0010657e6f6f2d1e49820490f6195da4/CLAUDE.md): 같은 역할 이력과 프로젝트·실험·환경·세션 규칙.
- [협업 원문](https://github.com/SongRoute/pitcheezy/blob/6e2038fd0010657e6f6f2d1e49820490f6195da4/docs/AI_COLLABORATION.md): D68~D100과 COOP 실행 기록.
- [운영 진입점 원문](https://github.com/SongRoute/pitcheezy/blob/6e2038fd0010657e6f6f2d1e49820490f6195da4/docs/pm/overview.md), [작업 절차 원문](https://github.com/SongRoute/pitcheezy/blob/6e2038fd0010657e6f6f2d1e49820490f6195da4/docs/pm/workflow.md), [시작 프롬프트 원문](https://github.com/SongRoute/pitcheezy/blob/6e2038fd0010657e6f6f2d1e49820490f6195da4/docs/pm/kickoff.md).

현재 전시 방향은 [10/31 인계 §2·§5](../handoffs/CODEX-resume-2026-10-31.md), 현재 협업 책임은 [관리 세션 안내](../handoffs/OPUS-github-manager-prompt-2026-10-31.md)를 근거로 한다. 그 문서의 프롬프트는 역할을 실제 배정받았을 때 사용하며, 파일 존재만으로 해당 세션이 실행 중이라고 판단하지 않는다.

자료 권한의 과거 예외는 [공통 계약](../pm/contracts.md)과 해당 고정 등록에 남아 있다. 이번 전시·유지보수의 2026 학습·튜닝·모델 선택 금지와 구분하며, 이 정리는 새로운 fit·OPE·정책 승격·운영 교체를 승인하지 않는다.
