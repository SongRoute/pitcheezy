## 지표와 해석

- 선수·카운트별 표본/경기 수, 구종 빈도, 최대 비중, HHI, 자연로그 entropy, 실제 대비 total variation을 남긴다. 집중도가 낮다는 이유만으로 좋은 정책이라고 하지 않는다.
- 상위 3개 **행동**은 구종×구역 세 개다. 전체 지원 행동의 비반올림 Q를 내림차순 정렬하고 정확한 동률만 원래 행동 index로 정한다. 실제 구종의 최선 지원 구역에 대한 행동 순위와 서로 다른 구종 순위를 구분한다.
- 실제 구종 가치 차이는 `100 × (최고 Q − 해당 실제 구종의 최고 지원 Q)` %p. 실제 투수가 의도한 목표나 실제 위치의 가치 차이가 아니다. 지원 밖 실제 구종은 순위/차이 null과 사유를 남긴다.
- 전체 코호트 적격률, 진단 내 추천 준비율, 지원 구종·행동·실제 구종 비율과 구종×구역의 지원/ESS/질량을 구분한다. 커널 ESS는 OPE ESS가 아니다.
- 동결 ensemble과 실제 저장된 seed42–46 단독 구성원을 평가한다. 각 신경망 외 delivery/frequency/blend weight·입력·행동 지원은 고정하고 각 checkpoint의 기존 보정을 유지한다. 이는 기존 독립 학습 구성원에 대한 순위 민감도이며 독립 전체 파이프라인 재학습, 전달 표본의 불확실성 또는 통계적 신뢰구간이 아니다. 신규 전달 bootstrap은 이번에 하지 않는다.
- 모든 공에서 구성원간/ensemble 대비 최고 행동·구종 일치, 실제 구종 순위 범위, 공통 행동의 순위 상관을 기록한다. rank 동률과 지원 교집합을 명시한다. 작은 차이 기준 0.01/0.05/0.1 %p는 기술 요약만 하며 유의성/동률/채택 임계값이 아니다.
- 필요한 CI는 경기 단위 bootstrap(1,000회, seed20260924), 6경기 탐색 범위로만 표시한다. seed 간 분산을 표본 CI로 바꾸지 않는다.
