## 1. 원격 연결 (맥미니 재생 화면을 맥북에서 열기)

맥미니 쪽 재생은 대본 2.6절 명령으로 띄운다(맥미니의 Claude 세션에 맡기거나, 2번 단계의 SSH 셸에서 직접). 화면 판은 세 번째 인자로 고른다(기본 B: `…/bundles/B-color-only/site`).

1. 맥북 터미널 1(데모 내내 켜 둔다. 아무것도 출력하지 않는 것이 정상):
   ```sh
   ssh -N -o ServerAliveInterval=15 -o ServerAliveCountMax=2 -L 8876:127.0.0.1:8876 -L 8875:127.0.0.1:8875 <사용자>@<맥미니 이름>
   ```
   8876 = 장면 A, 8875 = 장면 B. 맥미니 서버는 127.0.0.1에만 열려 있고 이 터널로만 보인다.
2. 맥북 터미널 2(발행기 시작·중지용): `ssh <사용자>@<맥미니 이름>`
3. 맥북 브라우저 탭 두 개(맥미니에서 재생 명령을 실행하고 약 3초 뒤에 연다. 되감기·재시작 뒤에는 새로고침한다, 대본 2.6절): 11/17 주 방식은 `http://127.0.0.1:8876/?game=849799`(5차전 실제 속도 재생) 하나다. 고정 장면 예비(대본 2.6절)를 띄울 때만 `http://127.0.0.1:8876/?game=849843`(A), `http://127.0.0.1:8875/?game=849843`(B). 탭 세 번째: 예비(4절).
4. 확인: 공이 넘어갈 때 화면이 바뀌는지(맥미니 재생 간격은 한 구 약 10.1초, 11/15 측정). 화면은 10초마다 읽으므로 맥미니에서도 발행 파일보다 0~10초 늦게 바뀐다. 원격 지연은 그 위에 더해진다.
5. 창 높이: 브라우저를 전체 화면(⌃⌘F)으로 연다. 보이는 영역 높이가 약 760px(계산값)보다 작으면 "이번 타석" 줄이 하단 메뉴에 가린다(대본 6절 10). 창 높이를 바꿀 수 없으면 확대 비율(⌘−)로 맞춘다.

## 3. 지연·재연결 재는 법

- **지연**: 맥미니 화면(또는 맥미니에 붙인 모니터)과 맥북 화면을 나란히 두고, 다음 공으로 바뀌는 순간의 차이를 폰 동영상(초당 30장 이상)으로 찍어 센다. 나란히 둘 수 없으면 맥북 터미널 2에서 아래를 켜 두고, 출력 줄이 바뀐 순간과 맥북 브라우저가 바뀐 순간의 차이를 스톱워치로 잰다(브라우저 화면 갱신 주기만큼 늦게 보일 수 있다).
  ```sh
  while true; do date +%T; python3 -c "import json;d=json.load(open('<회차 폴더>/out/v1/game/849799.json'));print(len(d['pitches']))"; sleep 1; done
  ```
