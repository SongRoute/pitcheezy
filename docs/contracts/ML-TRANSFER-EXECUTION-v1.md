# T4 전체 MLB 이전 평가와 공통 후속 선택 규칙

2026-09-24, G DEV 결과를 열기 전 등록. 이 규약은 G의 TRAIN 선정48명에서 전체 MLB 정규시즌 선발·불펜으로 평가 범위를 넓히며 새로운 모델을 학습하지 않는다. T2/T3도 아래 같은 한 후보/대조군을 고정해 사용한다.

## 후보 동결

G의 사전 등록 N/G·측정된 R 실패 제외·NLL/논리적 의존 fit 비용 순위에서 첫 후보를 택한다. 대응 대조군은 G1→G0, G2→G0, G3→G2, G4→G2로 고정한다. 이 선정 결과와 G 분석/준비 SHA256을 각 실행 config에 기록한다.

승격 가능한 후보가 없으면 G1~G4 중 Cpanel 주 NLL이 가장 작은 한 후보(동률이면 의존 fit 시간)를 **진단용**으로 택해 같은 대조군으로 일반화 실패/미확정을 측정한다. 이 경우 승격/채택으로 표시하지 않는다. 전체 MLB나 stress 결과를 보고 후보를 교체하지 않는다.

## 자료와 예측

- 기존 G preparation의 `mlb_dev` 전체 적격 목록과 requested 분모를 그대로 사용한다. 준비 기록상 적격311,721구이며 최종 ordered key/hash를 검증한다. 현재 공 이후 조건에 의존하는 적격성 제한을 유지하고 어려운 행을 추가 제거하지 않는다.
- 두 모형×seeds0/1/2 총6개 추론. 신경망·군집·선수 프로필·delivery400draw·Cpanel May temperature·June ensemble 및 seed별 혼합 계수를 동결한다. 전체 MLB로 보정기를 재적합하지 않는다.
- G1/G4 개인 모형은 현재 패널의 적격11명만 존재한다. 다른 선수는 동결된 league/cluster 경로로 돌아가며 전체 MLB 개인화 모형을 새로 학습했다고 하지 않는다.
- 새 선수의 과거 합법적 DEV 이력은 기존 context 규칙대로 반영된다. 따라서 전체 MLB의 TRAIN0 그룹은 온라인 과거 관측이며 T2의 엄격한 선수 제외와 구분한다. G2/G3/G4의 unknown raw model이 공통 global로 같을 수 있고, 이후 온도/혼합 차이는 공유 구조의 이득과 다르다.
- 6개 예측의 키·라벨·확률·부모 모델/보정 해시가 모두 검증된 후 한 번에 점수를 연다. Cpanel을 포함하는 전체 MLB는 독립 확인셋이 아니다.

## 평가

- 전체 N과 저표본 TRAIN 투수 G의 주 NLL 가설2개에 Holm.05. N은 ΔNLL≤−.003,95% 상한<0,보정p≤.05,ΔBrier95% 상한≤.001,2/3seed 개선. G는 저표본 N과 전체 NLL/Brier95% 상한≤.001.
- R: 역할2·좌우2·TRAIN volume4·스트라이크상황2·주자상황2의12그룹×2지표=24 단측 Bonferroni 상한, alpha.05,100,000 경기 bootstrap, seed20260924. 상한 NLL≤.010/Brier≤.002.30경기·500구 미달은 미확인; 측정 실패 우선.
- N/G bootstrap10,000회. whole-game resampling, pitch-weighted paired 평균. 추가로 Cpanel/비패널, seen/unseen 투수·타자, 월별, 선수별 및 선수 동일가중 macro 지표를 기술적으로 보고한다. 이 추가 지표로 새 성공을 선택하지 않는다.
- 표본 수·지원/제외·delivery fallback·개인/군집 경로 범위·클래스별30사건 기준·확률 보정·시간/메모리도 보존한다. 독립 최종 확인과 정책 효과는 여전히 별도다.

## 자원

G의 실제 panel 추론 시간을 전체311,721구로 외삽하고 단일7,200초/총28,800초 예산과 비교한다. 첫 모델 한 seed의 실제 비용으로 확인하되 성능은 열지 않는다. heavy lock으로 한 번에 하나 실행한다. 초과 예상 시 실행 전에 계획을 수정하고 표본/seed/draws를 몰래 줄이지 않는다.
