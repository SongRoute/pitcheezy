## 실제 확인할 것

- [ ] 맥북에서 공식 영상 로딩·재생·장면 이동을 확인한다. 현재 영상 파일은 보유하지 않으며 외부 영상을 버튼으로 불러온다.
- [ ] 사람 확인으로 영상 장면과 타자·회·공 번호를 맞춘 장면을 적는다. 기존 39구 앵커는 AI 표식이며 자동 동기화 검증이 아니다.
- [ ] 선택 장면마다 추천이 먼저 보이고, 공개 버튼 전 실제 공·결과가 보이지 않는다.
- [ ] 아이폰에서 서버 주소에 접속된다. 현재 100.108.252.111은 Tailscale 주소라 Wi-Fi나 셀룰러만 켠 것으로 접속이 보장되지 않는다.
- [ ] 아이폰 Safari에서 공개 버튼·스크롤·복사 링크가 동작하고 가로 넘침이 없다.
- [ ] 두 기기의 투구가 같은지 확인한다. 장면 변경은 두 기기 사이에서 자동 동기화되지 않는다.
- [ ] 실제 5분 안에 마친다. 영상 오류가 나면 저장 경기 `/watch`의 수동 비교로 전환하며 영상 시연 미완료임을 알린다.

## 설명의 경계

- 추천은 서비스 G0 기준이며 연구 G15 mix를 이미 적용했다고 말하지 않는다.
- 2026 정규시즌 1회 추천 정책 평가: 개선 근거 없음. 해로움이 없다는 증명도 아니다.
- 승리확률 전후 차이는 사건에 따른 모델 추정 변화이며 그 추천의 인과적 기여도가 아니다.
- 실제 투구 분포로 어림한 추천 위치와 CV가 본 포수 미트 위치는 서로 다르다. 세로 미트 위치·의도 정확도가 검증되었다고 말하지 않는다.
- 39구는 공식 압축 영상 일부이며 전체 경기/타석의 연속 영상이 아니다.
- 연구 진단의 실행 성공, 합성 테스트 통과, 최종 성능 우위를 구분한다.
