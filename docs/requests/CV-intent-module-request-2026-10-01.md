## 팀원께 요청
1. 의도(포수 미트 셋업 위치) 모듈이 있다면 레포·브랜치·커밋 위치
2. 출력 스키마: 투구별 `pitch_id`(game_pk, at_bat_number, pitch_number), 셋업 프레임 시각, 미트 픽셀 좌표, 홈플레이트 보정을 거친 plate 좌표(x, z, 피트) 또는 9구역, 불확실성·기권 여부. 우리 `IntentEstimate`(apps/observer/backend/observer_app/intent.py)와 맞추면 바로 연결 가능
3. 한 줄로 실행되는 엔트리포인트(입력: mp4 또는 클립 URL + 투구 목록 → JSON)와 필요한 환경(OS·GPU)
4. 가중치 파일(LFS 또는 링크)과 라이선스
5. MLB 클립 20~50개에 대한 샘플 출력
6. 사람이 라벨링한 셋 기준 정확도(픽셀·피트 오차, 기권률), 가능하면 다른 경기·방송사에서 측정
7. 처리량(투구당 초, 장비)
8. 보유 영상·라벨 범위(경기 수·시즌·방송사)와 대량 수집 경로(Savant 투구 클립 등)의 사용 가능 여부
