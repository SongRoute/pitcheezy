# 분리 평가기 최소 수정 — 첫 진단 후, 최종 평가 전

`service-validation-v1`의7월 학습 빈도 계층은 진단 로그손실1.526382 대 카운트1.518059, 검증1.513273 대1.507846으로 최소 예측 기준에 실패했다. 이 평가기의 정책 수치로 추천 효과를 주장하지 않는다. 원 실행·소스·진단은 보존한다.

수정은 한 개뿐이다. 카운트 기준 로그확률에 구종 효과와 경기 상황·연속 타자 성향을 공유하는 작은 정규화 다항 로지스틱 보정을 더한다. 카운트 기준과 보정은 **7월1–21일** 적합, 두 확률의 혼합 계수만 **7월22–31일** 로그손실로 정한다. L2는0.05 고정이며 설정 탐색과8월 학습은 하지 않는다. WE·주자 전이는 기존의 별도7월 모델을 유지한다. 타자성향·주자아웃을 삭제하는 개선이 아니다.

새 실행 `service-validation-v2`에 원 진단을 복사하고, 자료 출처·원 실행 해시와 수정 코드를 기록한다. 8월1–7일/8–15일 진단·검증 점수를 공개한다. 최종8월16일 이후 자료를 보고 평가기를 수정하지 않는다. 검증에서 같은7월1–21일 카운트 기준선보다 로그손실이 낮고 WE 최소 기준을 통과해야 평가 준비 완료로 표시한다. 실패하면 결과를 평가 준비 부족으로 남기며 다른 후보를 탐색하지 않는다.

원 추천 모델의 클래스 절편 후보는 기존 설계대로8월1–7일 적합,8–15일 채택 판단한다. 평가기의 적합·보정 경기와 겹치지 않는다. 새 평가기는 기존 신경망의 학습된 파라미터·확률표를 재사용하지 않는다. 과거 타자 프로필의 정보 원천과 평가 방법 가정은 공유하므로 현실의 인과적 정책 효과를 검증하는 것은 아니다.
