# B 다음 실험 고정 — EXP-B-PAHISTORY-002

2026-09-23. **설계 고정, 미실행.** 이번 사용자 요청은 첫 후보 악화 진단 뒤 다음 실험을 고정하는 것까지다. 공통 비교 결과에 맞춰 아래 규칙을 사후 수정하지 않는다.

## 근거와 질문

기존 61개 prior-family 조건부 셀은 TRAIN 578구/145타석에서 중앙 셀 크기 4구, singleton 12개였다. 첫 공 151개는 `NONE=첫 공=0-0`으로 부모의 카운트 정보와 중복인데 별도 평활 표를 적합해 DEV 전체 NLL 악화의 약 18.1%를 만들었다. 나머지 악화를 모두 이것으로 설명할 수는 없다. TRAIN 경기 제외 진단도 +0.010208 악화여서 7월 분포 변화만을 원인으로 단정할 수 없다. 회계 분해/모델 부작용 근거이며 인과 원인 증명은 아니다.

다음 질문은 **알려진 구종 행동을 조건으로 하는 강한 빈도 기준선에도 과거 구종 family가 추가 정보를 주는가**다. 단순히 이전 후보의 pseudo-count를 7월 점수에 맞춰 조정하지 않는다.

## 고정한 설계

- 같은 A의 선정 TRAIN/DEV·지원 행·10결과·합법성 투영을 쓴다. 부모는 이미 존재하는 global→count50→type50 계층이다. 투수 ID 추가 축은 이번 후보에서 바꾸지 않는다.
- 현재 행동 구종/카운트/좌우/이전 family 셀에 부모 pseudo-count 50을 적용한다. 첫 공 `NONE`와 미관측 셀은 부모 확률로 **정확히** 돌아간다.
- 추가 신호 강도 alpha만 `[0,.25,.5,.75,1]`에서 TRAIN 안의 두 시간순 검증 블록으로 고른다. 4/1~2→4/7~8, 4/1~8→4/13. 각 fold의 부모·자식은 앞 기간만 적합한다. 미래 4월 경기로 이전 경기의 부모를 적합하는 leave-one-game-out을 선택용으로 사용하지 않는다.
- pooled NLL 최소(동률 작은 alpha), 두 블록 모두 비악화/pooled 개선일 때만 nonzero 허용한다. 그렇지 않으면 **alpha=0**, 즉 과거 정보 추가를 기각한다. 무조건 개선 후보를 만드는 실험이 아니다.
- TRAIN 선택 결과·최종 checkpoint를 커밋한 다음에만 DEV 평가를 허용한다. alpha=0이면 중복 DEV 실험을 생략한다. nonzero여도 같은 7월은 노출된 개발셋이며 확인적 결과가 아니다.
- 전체/2스트라이크 예측을 구분한다. 정책 가치·OPE·제구 효과는 미측정으로 남긴다. 실제 행동 이후의 결과를 예측에 쓰지 않는다. 예측 모델 통과 뒤 추천에 연결하려면 모델이 생성한 future action으로 prior 상태를 갱신하는 별도 PA 계획 검사가 필요하다.
