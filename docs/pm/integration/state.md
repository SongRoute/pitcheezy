# 통합 PM 현재 상태

갱신: 2026-11-01 · PR44~64의 main 병합·검사 완료. [통합 기록](../../handoffs/CODEX-integration-2026-11-01.md)에 고정 커밋과 증거 범위를 남겼다. 새 실험·배포·정책 수용 판정은 하지 않았다.

## 지금 읽을 순서

1. [10/31 전시 인계 §2·§5](../../handoffs/CODEX-resume-2026-10-31.md): 현재 방향·역할·일정과 작업 경계의 출발점이다. 최신 사용자 지시가 우선한다.
2. [공동 작업큐 #37](https://github.com/SongRoute/pitcheezy/issues/37)의 전체 최신 댓글과 [작업 절차](../work-queue.md): 실제 파일·자원 소유권과 인계를 확인한다. 이 문서나 큐 본문을 현재 점유 증거로 삼지 않는다. 이슈 발신 금지 작업은 읽기·로컬 범위 기록만 남긴다.
3. [상황판 #35](https://github.com/SongRoute/pitcheezy/issues/35): 목표·검토·막힘 요약을 읽고 고정 커밋·등록·검토 근거로 내려간다. 다른 담당자의 기존 점유와 통합 책임은 명시 인계 전 유지한다.
4. [서비스 상태](../service/state.md)와 [연구 상태](../research/state.md): 전시 준비와 별도 연구를 구분한다.

## 전시 방향과 남은 확인

10/31 인계 기준 마감은 11/24, 기능 동결은 11/20, 리허설은 11/21~23이다. 관전 본체는 UI-1026이며 전시 G0 모델은 동결한다. 모니터 1은 발행기 재생·고정 빌드, 모니터 2는 같은 경기 영상, 관람객 폰은 QR 경로다. 역할·사이트 분담의 세부는 인계 원문을 따른다.

영상 소스 확정·팀원 호스트 연결시험·폰 검수·런북·포스터 정정의 완료 여부는 해당 작업의 종료 증거로 확인한다. 10/31 인계의 체크리스트를 이번 문서 정비로 완료 처리하지 않는다. [고정 빌드 기록](../service/exhibition-build-2026-10-31.md)은 당시 번들의 재현 근거이며 현재 배포 상태를 뜻하지 않는다.

## 유지하는 경계

2026 자료를 학습·튜닝·모델 선택에 쓰지 않는다. 등록·독립 검토·봉인/OPE·자료 역할·[자원 보호](../resources.md)와 [공통 계약](../contracts.md)을 유지한다. 요청이나 합성 검사 통과를 원본 수리·정책 채택·운영 GO로 확대하지 않는다. 성능·분모·지연을 새로 재계산하지 않았으며 현재 실기기·호스트 상태는 **미측정**이다.

## 과거 관측·체크포인트

[변경 전 전체 원문](https://github.com/SongRoute/pitcheezy/blob/9eddc42fa3a9f33c28e1d2d0a1a2585c323215d4/docs/pm/integration/state.md)에는 10/19 진입점과 10/11 이하 실행·검토·인계 기록이 그대로 있다. NaN clock·deferred target 요청을 포함한 당시 미완 사항은 현재 큐와 종료 근거로 대조한다. 오래된 진행 중·PID·역할·미승인 문장을 현재 상태로 복사하지 않는다. 통합 원문의 자원 상대 링크 수정도 이 고정 커밋에 보존한다.
