## 고친 문제와 확인한 경로

Sol이 발견한 TRAIN 행 수/개수표 불일치, 잘못된 마스크 dtype·BC 지원 밖 action, member의 실제 seed 불일치를 Opus가 수정했다. 또한 충돌 재시도 뒤 미중단, 일부 실패가 원장을 빠져나감, 호출자가 전달한 BC·지원 배열 변경으로 같은 runtime SHA 아래 확률이 바뀌는 문제를 수정했다. 최초 검토·합성 재현·수정·실패/성공 로그를 보존했다.

최종 독립 검사는 **G0 factory → TRAIN BC 복원 → P3/기준/전체 어휘 로깅 확률 → 원장 기록·재생**을 확인했다. 5개 member의 보정 확률 평균 후 앙상블 가중치를 적용하며, seed 가중치 평균이나 3개 member만 사용하는 변이를 검사로 잡는다. 실제 `SharingPredictor`가 합성 입력의 마지막 7개 routing 열을 제거하는 경로도 확인했다. 미지원 요청·마스크 밖 정당한 ρ=0·무결성/런타임 실패·재시작·중복 집계를 구분한다.
