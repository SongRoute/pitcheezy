상세 결과에는 초기값별 점수, 혼합 전 점수, 투수별·신규 타자별 표본 수와 점수가 들어간다.

## 고정 실험 설계

- 타자 표현6종: 성향6개+신뢰도6개, soft 군집 단독 K=3/5/10/20, 기존 성향12+군집5(reference).
- 각 표현을 동일 타석의 이전0구/5구로 비교한다. 5구 조건의 기존 모델60개를 재사용하고, 0구 모델60개만 신규 학습한다.
- 2024/2025 두 평가 연도 × 표현6종 × 신경망 초기값42–46. MLP 폭128, 최대30epoch, patience5, optimizer batch1024, AdamW 학습률0.0005.
- 학습 이닝으로 고른 선발6명, 동일 TRAIN/조기 종료/온도/혼합/평가 표본, 동일 정규화·군집·400개 공동 물리 표본·상황 빈도 기준선을 유지한다.
- 기본 경기 입력11개(볼·스트라이크·아웃·이닝·점수차·홈원정·주자3개·타자/투수 좌우)는 모두 유지한다. 타자 성향은 전날까지의 과거로 갱신한 기존 자료를 그대로 사용한다.
- 0구는 과거5개 슬롯의 물리량과 유효 마스크를 모두0으로 만든다. 전체6슬롯과 해당 표현의 파라미터 수는5구 모델과 같다. 현재 후보 투구는 유지하고, 실제 현재 공을 평가 입력으로 사용하지 않고 TRAIN 물리 표본으로 적분한다.
- 따라서0구도 카운트·타자 과거 성향·현재 구종 조건의 정보는 사용한다. 모든 역사 정보가 없는 모델이라는 뜻은 아니다.
- 2023–2025 승인 원본만 사용한다. 2026 자료를 열지 않는다. 추천 안정성·제구·정책 최적화·오프라인 정책 평가는 포함하지 않는다.

## 기존 결과 재사용

기본 참조:

- `temporal-blend-20260921T050400Z`: 전체 입력 MLP, 기본 표본·전처리·빈도 예측.
- `representation-history-20260921T054642Z`: 연속 성향·군집 단독의 모델과 학습된 문맥 변환기.

실행기는 두 실행의 아티팩트/소스 해시, 독립 감사 통과 여부, 동일한 base 연결 관계, 데이터 identity를 확인한다.
연도별 TRAIN 및 모든 보정·평가 키와 정답을 확인하고, 재사용한 예측을 다시 앙상블·혼합했을 때 기존 결과가 재현되는지 확인한다.
기존 예측은 이미 온도 보정되어 있으므로 다시 온도를 적용하지 않는다. 0구 모델은 자신의 May16–31 온도와 June 혼합 비율을 따로 맞춘다.
최적 군집 수를 평가 결과에서 선택하지 않고6종을 모두 공개한다. 이력1~4구, 개인 ID, 좌·우타만 조건은 이번에 재학습하지 않는다.

## 비교 및 해석

주 지표는 혼합 예측 로그손실, 보조 지표는 Brier다. 단독 신경망 점수와 혼합 비중도 공개한다.
연도별로 같은 경기 bootstrap2000회를 이용해 다음 비교군 각각의 동시95%구간을 계산한다.

1. **이력6개 비교**: 각 표현의0구−5구. 양수이면5구가 더 좋다.
2. **타자 표현10개 비교**: 각 이력에서 reference/K3/K5/K10/K20−연속 성향. 음수이면 해당 표현이 더 좋다.
3. **상호작용5개 비교**: `(해당 표현0구−5구)−(연속 성향0구−5구)`. 양수이면 해당 표현에서 이력의 이득이 더 크다. 이는 이번 교차 설계의 손실 차이이며 새 상호작용 신경망을 추가하는 실험이 아니다.

상호작용은 투구별 손실의 차이를 먼저 계산한 다음 동일 경기 재표집으로 추정한다. 신뢰구간 끝점을 빼지 않는다.
보정 범위는 각 연도·비교군 안이다. 모든 연도·지표·비교군을 아우르는 전역 보정이라고 부르지 않는다.
군집 초기값은 기존42 고정이다. 구간은 고정된 모델·온도·혼합에 조건부이며 전체 학습/모델 선택 불확실성을 포함하지 않는다.
두 연도 자료는 이미 관측했고 TRAIN 구간도 중첩되므로 독립된 미관측 확인 시험이 아니다.
군집별 모델 크기와 사용 가능한 이력 길이 신호도 달라진다. 순수한 정보량의 인과 효과로 해석하지 않는다.

투수별(평가 표본0명도 유지), TRAIN에 있었던/없었던 타자별, 이전 투구가 있는/이전5구 이상인 집단별 점수를 기술 통계로 출력한다.
이 집단들에서 새 승자를 골라 확증 결과로 보고하지 않는다. 모든 평가 표본은 원래 사후 적격 필터를 유지한다.
기존 결과를 재분석하는5구 타자 비교는 새로운 독립 재현 실험이 아니다.

## M4 자원과 중단 후 재개

- MPS GPU로 학습·추론을 한 번에1개 실행한다. 여러 실행 디렉터리 사이에도 이 실행기의 공통 OS 잠금을 사용한다. 다른 종류의 학습 스크립트와 동시에 실행하지 않는다.
- NumPy/BLAS 전처리 스레드는 기본 최대8개. 기존 학습 코드의 CPU 스레드는4개로 유지한다. 데이터 로더 프로세스를 중복 실행하거나 메모리 제한을 해제하지 않는다.
- 기본 추론 batch8192, 물리 표본 확장 chunk128행(최대51,200후보). 최적화 배치1024와 학습 조건은 바꾸지 않는다. 온도 logits는 SSD 메모리 맵, 평가 예측은 청크별로 처리한다.
- `--cpu-threads`, `--inference-batch`, `--delivery-chunk`로 조절한다. MPS가 없으면 자동으로 느린 CPU 학습을 시작하지 않고 중단한다. CPU 실행을 원할 때만 `--allow-cpu`를 명시한다.
- 설정은 실행 시작 때 고정한다. 실행 도중 다른 설정으로 바꾸려면 새 `--output`을 사용한다. 하드웨어별 최적 batch를 실측한 결과는 아니며 GPU 사용률100%를 보장하지 않는다.
- 각 seed의 fit → 온도 보정 → June 예측 → 평가 예측을 별도 원자적 디렉터리로 저장한다. 완료 단계는 해시 확인 후 재사용한다. fit 중단 시 그 seed의 fit부터 다시 시작하며 epoch 중간 재개를 주장하지 않는다.
- 실행 소스·프로토콜·참조 매니페스트를 고정해 저장한다. 완료 실행은 최종 해시 검증만 하고 종료한다. 이전 결과는 수정하지 않는다.
