1. 프로젝트 개요 

1.1 시스템명

AI 투구 추천 야구 관전 보조 시스템(Pitcheezy)

1.2 시스템 개요  

시스템은 MLB Statcast 투구 기록과 MLB 공식 경기 피드를 바탕으로, 투구 전 상황(볼카운트·주자·아웃·투수·타자)에서 수비 팀의 기대 승리확률을 가장 높이는 구종과 목표 구역 상위 3개를 추천한다.

사용자는 중계를 보면서 보조 화면(‘두 번째 전광판’)으로 추천을 확인하고, 실제 투구(구종·구속·도착 위치·판정)와 추천의 차이를 비교한다.

시스템은 추천 근거(선택 비중, 지원 여부, 추천 출처)를 함께 표시하고, 지원하지 않는 투수·상황은 숨기지 않고 ‘미지원’으로 알린다.

예측 성능(결과 확률 모델의 NLL·보정)과 추천 정책 효과(오프라인 정책 평가)는 분리해 검증하며, 2026 시즌 자료는 사전 등록한 정책 평가에만 쓴다.

2.1 액터 목록  

시스템의 액터를 [표 1]과 같이 정의한다.

| 액터명  | 역할 | 참고  |
| --- | --- | --- |
| 야구팬(User) | 중계를 보며 보조 화면으로 투구 전 추천·실제 투구 비교·경기 상황을 조회하는 일반 사용자 | 주요 액터 |
| 운영자(Operator) | 발행기·공개 호스트를 운영하고 시연·재생을 제어하는 팀원(송동선 : 맥미니 발행기, 조현준 : 공개 호스트·비상 안내) | 관리자 |
| 연구자(Researcher) | 자료를 수집하고 결과 확률 모델·추천 정책을 학습·평가·동결하는 팀원(송동선) | 관리자 |
| 라벨 검토자(Labeler) | 중계 영상의 포수 미트·존 위치를 표시하고 CV 추정 결과를 검토하는 팀원(조현준) | 보조 액터 |
| MLB Stats API | 실시간 경기 이벤트(투구·판정·주자)를 제공하는 외부 시스템(GUMBO feed/live) | 외부 시스템 |

| CV 의도 모듈 | 끝난 경기의 포수 미트 셋업 가로 위치를 추정해 제공하는 팀원 저장소 모듈 | 외부 시스템 |

2.3 사용사례 목록    

[그림 1]의 각 사용사례를 [표 2]와 같이 설명한다.

| 사용사례 | 관련 액터 | 설명 |
| --- | --- | --- |
| UC-01 경기를 선택한다 | 야구팬 | 야구팬은 홈 목록에서 날짜와 경기(진행 중·지난 경기)를 골라 관전을 시작한다. |
| UC-02 투구 전 추천을 조회한다 | 야구팬, MLB Stats API | 시스템은 투구 전 상황에서 추천 상위 3개(구종·선택 비중·목표 구역)와 지원 여부·추천 출처를 표시한다. 미지원 투수에게는 과거 구종 빈도 참고 카드만 보여 준다. |
| UC-03 실제 투구와 비교한다 | 야구팬 | 시스템은 투구 후 실제 구종·구속·도착 위치·판정을 공개하고, 추천과의 일치 여부(✓/✕)와 포수 시점 존 그림을 표시한다. |
| UC-04 경기 상황을 조회한다 | 야구팬 | 시스템은 상황 머리글(이닝·점수·주자·볼카운트), 선수 카드, 박스스코어, 타석 투구 띠, 다음 타자, 홈 승리확률을 표시한다. |
| UC-05 지난 장면·사건 분석을 조회한다 | 야구팬 | 시스템은 타석별 지난 장면과 주요 사건의 승리확률 변화를 보여 준다. 요인별 분해(사건 기여도)는 설계·뼈대 구현 상태로 출시 범위에서 제외한다. |
| UC-06 지난 경기를 재생한다 | 야구팬, 운영자 | 시스템은 저장된 경기 피드를 실제 속도로 재생하고, 운영자는 시연 운영자 화면에서 재생·일시정지·배속을 제어한다. |
| UC-07 실시간 경기를 수집·발행한다 | 운영자, MLB Stats API | 발행기는 경기 피드를 10초 주기로 읽어 추천을 장부에 기록한 뒤 JSON 파일로 발행한다. 운영 감독기가 시작·재시작·알림을 맡는다. |
| UC-08 자료를 수집·버전 관리한다 | 연구자, Baseball Savant | 연구자는 Statcast 자료를 시즌 단위로 수집해 행 수·해시로 버전을 기록하고, 2026 홀드아웃을 고정한다. |
| UC-09 모델을 학습·평가·동결한다 | 연구자 | 연구자는 설정 파일로 결과 확률 모델·추천 정책을 학습하고, 사전 등록한 지표(NLL·보정, 정책 평가)로 평가해 동결본(G0, ARM-B)을 서비스에 연결한다. |
| UC-10 포수 셋업 라벨을 검토한다 | 라벨 검토자, CV 의도 모듈 | 라벨 검토자는 중계 영상에 미트·존 위치를 표시하고, CV 추정 결과를 계약 검사(validate_intent_estimate)로 받아 서비스에 연결한다. |
