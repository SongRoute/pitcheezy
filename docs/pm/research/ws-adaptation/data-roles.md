# 자료 역할과 시간 경계

상태: **실행 전 등록 요건**. 구체 날짜·키·자료 버전·컷오프는 데이터 가용성과 기존 노출 계보의 제한된 점검 후 고정한다. 지금 이 문서만으로 새 fit/자료 접근을 시작하지 않는다.

## 등록해야 하는 최소 장부

각 소스에 경로/버전/hash, 수집·당시 가용 시각, 경기/투구키, 허용 열, 품질·중복 기준, 기존 FIT/선택/CAL/평가/특징통계/수동열람 이력을 적는다. 불명은 unknown이지 untouched가 아니다. 한 경기와 타석을 서로 다른 역할에 쪼개지 않는다. 종료 후 정정된 피드와 당시 도착한 스냅샷을 구분한다.

시계열의 각 origin에서 **FIT → SELECT → CAL → TEST**를 서로 다른 경기·날짜 구간으로 고정한다. 가중학습·인코더·표준화·유사도 학습·선수 임베딩의 추정 파라미터는 FIT에서만 학습한다. 기본 정적 이력은 FIT 원천 중 각 query 이전에 가용한 기록으로만 구성한다. 동결 컷오프가 query보다 늦은 학습행에서도 query 이후 자료를 이력에 넣지 않는다. 이후 인과적으로 가용한 이력/경기상태 갱신은 아래의 별도 등록 모드로만 허용한다. SELECT로 사전 후보 중 선택하고 CAL에서 선택 모델의 보정만 한다. TEST로 재선택/재보정하지 않는다. 이번 모델들의 보정 순서도 서로 같게 유지한다.

- **과거2026 rolling origin:** 이전시점부터 이후로 진행하는 개발 견고성 비교다. 날짜 구간은 출시 후보의 역할과 함께 등록한다. 이전 fold의 평가행이 이후 fold에서 FIT이 될 수는 있지만 순서를 공개하고, 두 평가를 서로 독립인 새 표본으로 합산하지 않는다.
- **최근 고정 구간:** 선택/CAL/TEST의 경계를 점수 열람 전에 고정한다. 이미 OPE나 수동 검토로 노출된 기간은 노출된 개발 평가로 표기한다. 새 이름이나 새 split으로 독립성이 회복되지 않는다.
- **미래 LCS/WS:** 실제 투구 결과 이전에 모델/config/hash·입력스냅샷·시각·예측을 기록한 행만 prospective 평가 대상으로 삼는다. 시작 전 관측·예측가용 기준, 재전송/수정·누락/기권 처리, 분모와 경기키를 고정한다. 앞으로의 모든 행이 자동으로 untouched라고 약속하지 않는다.

## 대상 선수와 정보 가용성

실행 시점에 이용 가능한 공식 후보 로스터의 playerID·출처·관측시간·팀을 고정한다. 확정되지 않은 다음 라운드 라인업·미래 등판·경기 결과로 평가 가중치를 바꾸지 않는다. 과거 fold의 as-of 대표 평가 대상은 그 origin에 알려진 명단이다. 현재 잔존팀 선수로 과거를 다시 묶는 분석은 별도 회고 cohort이며 생존/선택 편향 한계를 표시한다.

현재2026선수명단을 정하는 운영 사실과 실제 모델 특징으로 최근2026성적을 사용하는 것은 구분한다. 새 권한 안에서 후자는 가능하지만 반드시 행별 as-of와 특징 계약을 등록한다. 현재 투구의 실현 구속·궤적·타구/결과를 그 투구 전 입력에 넣지 않는다. 선수 프로필·당해구종 사용률·최근성도 query 이전에 도착한 자료만 사용한다. 지원 없는 신인·새구종은 넓은 비교군으로 불확실성을 남기거나 기권한다.

기본 첫 비교는 **FIT 컷오프에 동결한 역사 특징**을 쓴다. 이후 CAL 기간 등의 이전 관측을 다음 투구의 이력 특징으로 갱신하려면, 모델 파라미터를 그대로 두더라도 별도의 등록된 prequential 특징 갱신 모드다. 당시 알려진 정보만 사용하고 평가 행의 자기 결과·미래 결과를 넣지 않으며, 정적 동결 이력 실험과 같은 추정대상으로 합치지 않는다. 이번에는 그 추가 변형을 실행하지 않는다.

## 월드시리즈 모델 운영 제안

주 평가는 시리즈 전 고정한 단일 모델·보정·후보자격·입력 갱신 규칙을 사용한다. 매공 카운트 등 상태 갱신과 모델 재학습을 구분한다. 최근이력 자동 갱신을 허용한다면 그 계산·도착시점도 freeze에 포함한다. 경기 중/간 shadow재학습은 별도 등록된 prequential 실험으로만 두고 주 모델을 자동 교체하지 않는다. 뒤늦은 예측 생성으로 실시간 평가를 대체하지 않는다.
