# 전시 포스터 구성안 — 시안 2026-10-31 제출 · 전시 2026-11 말

작성: 2026-10-07, 대화 PM(Fable). 레포 문서 5묶음을 읽고 4관점 구성안 → 3심사 → 종합 → 주장 85건 반박 검증(통과 71·수정 14) → 누락 점검을 거친 결과다. 커밋하지 않은 초안이며 Song 확인 뒤 고정한다. 주최·규격·관람객 성격은 레포에 기록이 없어 **미확인**이다.

원칙: 2026 시즌 자료는 OPE·화면 표시·시간 측정 전용. 시드·데이터 버전·커밋 없는 수치는 쓰지 않는다. 추천 우위·팬 이해 통과·라이브 운영 합격·기존 연구 능가는 선언하지 않는다. 본문 수치는 소수 4자리, 전체 정밀도는 캡션·각주.

## 0. 한눈에

- **헤드라인**: 다음 공, 무엇이 최선일까? — 야구 중계 옆 '두 번째 전광판' Pitcheezy (실험판)
- **30초 요약**: 투수가 공을 던지기 전에 "어떤 구종을 어디로 던지는 게 수비팀이 이길 확률을 가장 높일까"를 MLB 공개 기록으로 배운 모델이 보여 주고, 공이 들어오면 실제 공과 같은 그림 위에서 비교한다. 홈런·삼진 같은 큰 사건에서 '계획·제구·타자 몫'을 나누어 보여 주는 것이 최종 목표다. 다음 공 결과 예측은 기준선보다 좋아졌지만(개발 평가), 그 추천이 실제로 더 나은 선택인지는 2026 시즌 오프라인 평가에서 "개선 근거 없음"이었다. 된 것과 안 된 것을 같은 크기로 적는다.
- **구조**: 3초(제목+그림 한 장) → 30초(세 질문) → 3분(본문 7칸). 모든 수치·기능 옆에 상태 배지 [구현됨] [측정됨] [미검증]을 색+모양+글자로 붙인다.

### S2. 팬이 한 화면에서 답하는 세 질문 (9%)
- ① 다음 공: 어떤 구종을 어느 구역에 던지는 게 가장 유리한가? (포수가 사인을 내기 전, 팬도 같이 수싸움)
- ② 실제 공: 실제로 어떤 공이 어디로 들어왔고, 추천과 어떻게 달랐나?
- ③ 중요 사건: 홈런·삼진·볼넷이 났을 때 계획·제구·타자 중 어디서 차이가 났나?
- '유리하다' = 이 공을 던진 뒤 수비팀이 경기를 이길 확률(WE)을 가장 높이는 선택. 결과를 매번 맞히는 것과 좋은 선택을 하는 것은 다르다.

### S3. 왜 어려운가 — 기록에는 '어디를 노렸나'가 없다 (8%)
- Statcast에는 공이 '어디로 갔는지'는 있지만 '어디를 노렸는지'는 없다. 노린 곳을 모르면 계획 오류와 제구 오류를 가를 수 없다(과녁 없이 화살 자국만 보고 사수를 평가하는 셈).
- 그래서 중계 영상에서 포수가 투구 전 미트를 둔 위치(셋업)를 '노린 곳의 대리값'으로 쓴다. 별도 팀원의 CV 모듈. 우리는 입출력 계약과 검사기(계약 테스트 28개)로 연결한다. [구현됨]
- 주의: 미트 위치는 대리값이고 지금은 가로 위치만 쓴다. 미트 높이는 실제 공보다 중앙값 1.35ft 낮아 높이 대리값으로 못 쓴다. [측정됨: 팀원 보고] 경기 뒤 사람이 돌리는 작업이라 실시간이 아니다.
- 그림: 비유 2컷(과녁 없는 화살 자국 / 포수 미트 = 과녁) + 좌표 4단계 사슬 소도식. [만들어야 함]

### S4. 어떻게 고르나 — 공 하나의 가치를 '이길 확률'로 잰다 + 공정한 검증 규칙 (12%)
- 흐름: 투구 전 상황(카운트·주자·아웃·투수·타자) → 가능한 구종×목표 구역 → 실제로 도달하는 위치·구위의 흩어짐 → 결과 확률(공통 계약 기준 11가지: 볼·스트라이크·파울 + 삼진·볼넷·사구·1루타·2루타·3루타·홈런·인플레이 아웃) → 타석 뒤 승리 가치 → 추천. 구종과 위치를 '함께' 고른다.
- 예측 모델: 투구 전 정보만으로 다음 공 결과 확률을 맞히는 신경망(전체 공유 MLP, G0)에 직접 예측 head를 반반 섞은 G15 mix가 현재 연구 기준. [측정됨: 개발 평가]
- 자료: 모델 학습·평가는 MLB Statcast(pybaseball)만. 학습 창 2023-05-15~2025-04-30 1,252,824구·4,671경기 / 개발 평가 2025-07~09 전체 MLB 311,721구·1,161경기 / 2020 단축 시즌 제외. 실시간 경기 상황은 MLB Stats API 공개 피드(GUMBO).
- 규칙 1: 2026 시즌 자료는 학습·튜닝·모델 선택에 쓰지 않는다. 사전등록한 오프라인 평가(OPE) 1회와 화면 표시·시간 측정에만 쓴다. (각주: 초기 P0·P1 단계에서 2026 짝지은 OPE 20건을 후보 판정에 썼고 노출 이력을 D87로 공개했다.)
- 규칙 2: 시드·데이터 버전·커밋 없는 수치는 결과로 치지 않고 '미측정'이라고 쓴다.
- 규칙 3: 기존 연구(SmartPitch 2022, Takamido & Nakamoto)는 논문 숫자를 베끼지 않고 같은 자료·같은 저울로 다시 구현해 비교한다. 논문 보고값은 출처를 붙인 참고 표로만.
- 규칙 4: '예측이 맞나'(NLL·Brier·보정)와 '추천이 더 나은가'(OPE)는 다른 질문이라 따로 판정한다.
- 그림: 가로 흐름도 6단계 / 데이터 시간축 띠(학습 → 조기종료·보정 → 개발 평가 → 2026 자물쇠) / 규칙 4개 아이콘. [만들어야 함]

### S5. 화면 — 중계 옆 두 번째 전광판, 공보다 먼저 떠야 한다 (16%)
- 화면은 두 가지를 섞지 않는다. ① `/game` 경기 페이지(8770, demo/ui-frame)는 다섯 줄 틀(상단/점수판/무대/공 순서/버튼 셋, D140) 1·2단계 구현. ② 8771 `/watch` 관전 화면은 10/6 SVC-008로 스크롤 없는 한 화면 재배치(HEAD 5488c93, 프런트엔드 한정). 포스터·번호 주석·스크린샷은 **Song이 고른 한 화면**에만 붙인다(결정 2·3).
- 무대 상황이 저절로 바뀜: 다음 공(추천) → 방금 던진 공(실제 구종·구속·위치, 구종 ✓·위치 ✕) → 결과 확인 중 → 타석 끝 → 공수 교대 → 추천 없음(2025년까지 기록이 부족한 투수). 비교 시간은 10/6 시연(8775)에 적용된 값이 일반 공 5초·타석 끝 10초이고, 10/2 틀의 6초·10초는 별도 제안값(실제 폰에서 다시 정함).
- 쉬운 말: 위치는 '몸쪽·바깥쪽, 높게·낮게', 구종 이름을 누르면 한 줄 풀이, km/h↔mph. '구종 ✓'는 실제 공이 추천과 같았다는 뜻일 뿐 추천이 좋았다는 뜻이 아님. 모든 화면에 '실험판'.
- 느린 건 우리가 아니라 공개 피드 [측정됨: 2026 서비스 시간 측정 전용]: 공을 놓은 뒤 기록이 뜨기까지 중앙값 19.2초(10% 13.5, 90% 26.3), 다음 공까지 중앙값 20.5초(849844, 277구). 우리 추천 계산은 공당 중앙값 0.13~0.14초(경기 첫 준비 5~6초).

### S6. 지금까지 확인한 것 — 좋아진 것과 아직 근거 없는 것을 같은 크기로 (15%)
- [측정됨: 개발 평가] 공 결과 예측 NLL(낮을수록 좋음), 2025-07~09 전체 MLB 311,721구: 상황 빈도 기준선 1.5041 → G0 1.4904(차이 −0.0137 [−0.0144, −0.0129], 5/5 seed) → G15 mix 1.4863(G0 대비 −0.0041 [−0.0044, −0.0038], 5/5 seed). 여러 번 열람한 개발용 평가라 독립 확인은 아님.
- [측정됨] 모든 면에서 우위는 아님: 보정(ECE10)은 빈도 기준선 0.0017이 G15 mix 0.0042·G0 0.0087보다 좋다.
- [배운 것] 구조보다 자료: 모델 구조 6종(선형·LightGBM·LSTM·GRU·Melville·Transformer)과 선수 정보 공유 4종 모두 기본 MLP를 못 이김(0/6, 0/4). 학습 자료 25%→100%에서 −0.0032 [−0.0053, −0.0010], 3/3 seed 개선(C6 DEV 5,048구·60경기). 타자 성향 입력 17개를 빼면 NLL 1.4833→1.4885로 나빠짐(5/5 seed).
- [미검증 = 개선 근거 없음] 추천이 실제로 더 나은가: 2026 정규시즌 2,429경기·184,288타석으로 사전등록 OPE 1회 → 추천 정책 − 기준 정책의 수비 승리확률 차이 [−0.0012, +0.0009]/타석 → 개선 근거 없음(해로움도 없음). 서비스 추천 정책은 채택하지 않았고 그래서 '실험판'.
- [카드] 예측 ≠ 추천: P1 후보 7개는 모두 OPE에서 기준과 구분되지 않아 기각. 그중 신경망 4개는 NLL이 1.2100→약 1.176으로 크게 좋아졌는데도 OPE는 같았다(집계 맥락 3개는 NLL도 그대로). 예측기를 G15 mix로 바꿔도 추천 변화(평균 TV 0.0323)가 난수만 바꾼 변화(0.0497)보다 작아 정책 재검증은 닫음(D155).
- [참고, 별도 트랙] 앞선 연구와 비교: 연구 동결 RE24 트랙(기대 득점 단위, 투수 219명)에서 우리 P0-009가 SmartPitch류 축소 재구현 B1보다 +0.0026 [+0.0007, +0.0045] 실점/결정(5 seed). '축소 재구현 기준선 대비'이며 'SmartPitch를 이겼다'가 아님. Takamido류 Transformer를 우리 과제로 재학습하면 NLL 1.0614, 투구 전에 고를 수 없는 물리 피처를 빼면 1.1697 — 격차의 73%가 그 피처 몫.
- [참고 표, 우리 점수와 다른 표] 논문 보고값: Takamido & Nakamoto AUC 0.811·정확도 0.756·F1 0.812(2018~2025, 100,669타석). SmartPitch 2019 자료 70/30, cross-entropy·Brier.
