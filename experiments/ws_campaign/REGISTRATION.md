## A: fixed mechanisms

T is frozen N1 Transformer construction; R is its two-layer width64 LSTM over reverse chronological token order; C uses the same LSTM and reverses valid tokens to chronological order without moving padding into the valid prefix. G replaces that recurrence with a two-layer GRU. K uses five causal residual Conv1D blocks, width64, kernel3, dilations1/2/4/8/16, GELU/dropout0.1; right future tokens cannot affect earlier outputs. Every context variant uses masked mean pooling, the same no-context vector, trunk, token attributes and hierarchical heads. Shared initial tensors are same-seed identical across T/R/C/G/K except the encoder. Parameter counts need not match.

N0 has no context. T-recent4 masks older slots. C-shuf deterministically permutes valid tokens by stable game/PA/pitch key and token position; the full token including relative-position attribute travels together. The permutation is fixed across epochs/seeds; suffix padding remains. T−N0 tests context availability, T−recent4 length, R−C order holding LSTM fixed, C−C-shuf order sensitivity. T−C confounds architecture and order. No Transformer-shuffle arm.

T-leaf7 replaces hierarchical heads with one seven-class softmax and one CAL temperature. T-tokdrop independently drops entire context tokens with p0.15 during training only. T-histmask masks the entire declared pitcher-history feature block to normalized zero with p0.1 per training row; evaluation is unmasked. Its exact70 expanded199-column indices are frozen in config and HISTMASK-MANIFEST.json following separately registered, independently reviewed inspection of the hash-bound original encoder JSON. The22 raw columns are50–58 (own physics),66–77 (own outcome history) and90 (similarity abstention dependent on own physics); all corresponding hinge terms are included. No normalization statistics or knot values are reported. No guessed indices or silent omission. Identifiers, current pitch attributes and batter-only features remain outside that block.

## B: pretraining, robustness and distillation

Mask pretraining predicts earlier-token parent10 outcomes after removing that token's outcome embedding. It masks valid positions independently p0.15 and always includes the most recent valid token, so every nonempty query has a supervised masked position. No current-query outcome enters this objective. Later tokens within that already-past context retain their ball/strike attributes, which can reveal a masked earlier outcome (a count-based shortcut). This is a limitation of masked-event difficulty, not future/current-query outcome leakage; no claim that this measures pure event reconstruction or general latent temporal understanding is permitted. Contrast pretraining uses two independently token-dropped views of one strictly-prior context, normalized pooled embeddings and symmetric in-batch cross entropy at temperature0.2. This is a time-context contrastive variant inspired by TS2Vec, not its exact reproduction. Empty contexts are excluded; batches with fewer than two eligible queries are skipped.

Each objective/seed has its own pretraining job: two FIT passes, at most512 optimizer steps, batch256, AdamW lr0.001/weight_decay0.0001. Only token embeddings, encoder and no-context parameter transfer; supervised trunk/heads retain same-seed scratch initialization. The pretraining prediction head is discarded. No SELECT/CAL/EVAL values train pretraining parameters.

The chosen matching rule is optimizer-step count only, not compute, wall time, FLOPs or sample count. Pretraining batch256 differs from supervised batch2048; receipts record actual sample presentations and objective targets as well as step counts. Each pretrained supervised model runs15 complete FIT epochs; its distinct scratch comparator runs exactly those supervised steps plus the actual prerequisite pretraining steps. These paired arms do not early-stop, but SELECT chooses the best checkpoint at each epoch/final partial epoch. Scratch/pretrained total optimizer steps match exactly; sample exposures and per-step costs need not match; measured wall is recorded and is explicitly not matched. Separate scratch controls exist for the two objectives. This is an explicit budget choice, not artificial runtime padding.

GroupDRO groups use cumulative strictly-prior FIT pitch count by pitcher, boundaries0/10/100/1000, minimum32 FIT rows. A separately reviewed, hashed `fit-prior-support.npy` uses actual game dates then stable game/PA/pitch ordering; game identifiers alone are not a chronological proof. Ascending under-supported groups merge into the next group; an under-supported final group merges downward. The rules use FIT counts only. Per-minibatch hierarchical row loss scales each conditional-head term by minibatch support, matching the ordinary average hierarchical loss; group mean loss drives multiplicative weights eta0.01. Group weights initialize uniformly, update on detached clipped-above50 group loss, normalize, and absent minibatch groups have no gradient. EVAL unseen-to-fit strata are not learning groups.

Three teacher jobs infer FIT logits separately from fixed A-T seeds0/1/2, with no EVAL selection. Every N0-distill seed depends on all three teachers. Soft targets are mean of the three parent softmax(logits/2) and binary sigmoid(logits/2) probabilities (not mean logits). Student loss is0.5 ordinary hierarchical loss +0.5 distillation, parent KL and masked binary soft-label cross entropy scaled by temperature squared4. Keys and dependency hashes must match. There are only three teacher inference jobs; all three students reuse the same fixed teacher ensemble.
