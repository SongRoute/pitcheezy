## D162 — 도전적 시연 완성도 목표

- 실제 경기 영상을 재생하며 추천·실제 투구를 비교하는 경험을 필수 흐름에 추가한다. 맥북/아이폰의 영상·서비스 배치와 영상 출처는 후속 확인한다.
- PM은 기본 시연을 확보하면서 사건 분석 등 최종 목표의 부분 구현과 성능 개선을 적극 시도한다. 실험으로 확인된 개선은 적용 후보까지 준비한다. 기존의 일괄 기능 제외·새 모델 적용 시도 제외 제안은 D162로 대체한다.
- 실제 투구 전 추천과 사후 분석을 구분하고 영상 시각·투구 ID의 일치를 검증한다. 이미 던진 공을 다음 공 추천처럼 보여주지 않는다.
- 개발 중 더 나은 시연 후보를 검증할 수 있으며, 검증된 기존 시연 버전은 복구 가능한 상태로 보존한다. 미검증 기능을 완성 기능처럼 표시하지 않는다.
- 영상 접근 방식과 사용 가능한 연산 자원·비용 범위 확인이 필요하다. 기존 판정·연구 계약·운영 기록 보호는 유지한다.
