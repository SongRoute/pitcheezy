사전 등록 기준(메뉴 중 ESS ≥ 30% 인 가장 작은 τ, 006 s0 메뉴 ESS 기준)으로 τ=0.005(ESS 33.5%)를 골라 같은 5개 짝을 두 τ 로 쟀다 (`runs/_diag/compare/*_tilt_t0.005.json`).

| 짝 | τ=0.02 Δ [CI] | τ=0.005 Δ [CI] |
|---|---|---|
| 009 − 002(B1) | +0.0026 [+0.0007, +0.0044] | +0.0059 [+0.0015, +0.0105] |
| 006 − 002 | +0.0022 [+0.0002, +0.0043] | +0.0038 [−0.0007, +0.0085] |
| 009 − 006 | +0.0003 [−0.0010, +0.0017] | +0.0021 [−0.0016, +0.0059] |
| P1-001 − 006 (s0/s1/s2) | +0.0000 / −0.0003 / −0.0006 (반폭 ~0.0024) | −0.0008 / −0.0001 / −0.0012 (반폭 ~0.0055) |
| P1-001 − 002 (s0/s1/s2) | +0.0023 / +0.0020 / +0.0017 (반폭 ~0.0018) | +0.0030 / +0.0037 / +0.0026 (반폭 ~0.0045) |

- 이유: τ 를 줄이면 Δ 가 약 2배 커지지만 CI 반폭은 2.5배 넓어진다(ESS 60%→33%). Δ/반폭 비는 1.4 → 1.3 으로 오히려 조금 나빠짐. 유의했던 짝(006−002, P1-001−002 s0·s1)이 τ=0.005 에서는 유의하지 않게 된다
